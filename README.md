# Open-SCORE v5.1

研究已知固定对手下的动态分组。六任务分别迁移真实 rollout、MCTS-DPW、PPO 与自回归构造、Expert Iteration、BRIDGE 上层合并及配对价值学习。所有方法共享规则底层、原生终局奖励和最多 50 个物理步。

当前 [执行方案](动态分组_六任务并行复现与诊断执行方案_v5.md)、[实验记录](实验记录.md) 和 [运行指南](Open-SCORE/README.md)。唯一训练种子 `20260907`；五种红方规模 × 三档蓝方人数，共 15 格等权混合。正式配额由联合短测确定后冻结，约 20 小时用于规划，没有到点停止。

在本工作区 VS Code 按 `Ctrl+Shift+B` 运行默认的“v5.1 启动或恢复六任务”；实时汇总每 10 秒输出一次。另有“实时进度（仅监控）”任务，关闭监控不会终止训练，重新监控不会重复启动。

训练前必须完成准备、联合校准、正确性验证与源码冻结；默认运行器会拒绝未冻结或源码不一致的正式目录。入口为 [run_research_v5.py](Open-SCORE/scripts/run_research_v5.py)。
