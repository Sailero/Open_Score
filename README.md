# Third Paper workspace

本工作区已按研究范围拆分为两个相互独立的目录：

- `01_original_saga_iclr/`：原始 SAGA 全量方案归档，包含 ICLR 级研究设想、论文草稿、理论、原型、输出和审计文档。原有相对目录保持不变。
- `02_q2_scale_opponent_generalization/`：面向 1–2 个月投稿周期的二区简化方案。经二次否证式调研，主线已从通用“规模 × 对手联合泛化”收缩为**对抗减员/增援下的阵容—策略混淆诊断与 CDOC-HPN 轻量修复**；目录包含最新价值复核、论文草稿、三版路线、实验/投稿计划，以及 HPN/OC-HPN 基线骨架。

推荐先读 `02_q2_scale_opponent_generalization/README.md`。原始 demo 如需运行，请先进入 `01_original_saga_iclr/`，再使用其 README 中的命令。
