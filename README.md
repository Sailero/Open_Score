# Third Paper workspace

本工作区按研究阶段分成两个独立目录：

- `01_original_saga_iclr/`：原始 SAGA 大设想与全部论文、理论、原型和审计材料，保持归档结构。
- `02_q2_open_population_adversarial_allocation/`：当前面向 1–2 个月投稿周期的 Q2 研究阶段，聚焦**开放人口攻防中的上层对抗分配与跨对手泛化**。

当前主问题不再是“辨识减员还是对手换策略”，也不是一般动态聚类，而是：双方会伤亡/增援且都会反编组时，如何在统一冻结下层执行器上学得跨规模、低经验可利用的上层任务分配。

推荐先读 [当前阶段 README](02_q2_open_population_adversarial_allocation/README.md) 和 [三个候选研究内容](02_q2_open_population_adversarial_allocation/docs/03_三个候选研究内容.md)。上一版 CDOC 已由本地 Git 提交 `f281296` 保存。
