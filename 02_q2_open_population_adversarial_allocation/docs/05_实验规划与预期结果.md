# 实验规划与预期结果

## 1. 实验要回答的四个问题

- Q1：开放事件和智能反编组是否让普通合作式/最新对手式分配器出现端到端性能缺口？
- Q2：OPAA 是否在不改变下层能力的情况下改善最坏对手表现？
- Q3：改善能否零样本延伸到未见人数、兵力比和增援日程？
- Q4：收益是否值得额外训练与推理成本？

## 2. 场景矩阵

### 训练域

- 人数：4v4、6v6；必要时加入 6v8。
- 事件：无事件、单次随机减员、单次增援、双方异步增援。
- 目标：歼灭、拦截突破、保护资产三个任务族中至少两个。
- 对手：最近目标、集中突破、诱饵分兵、普通 self-play。

### 测试域

- 数量 OOD：3v5、5v8、8v8、8v12 等未训练组合。
- 事件 OOD：更早/更晚事件、两波增援、连续小规模伤亡。
- 对手 OOD：留出的脚本、其他 seed 的 self-play、专门训练的经验最佳响应。
- 组合 OOD：未见兵力比 × 未见对手 × 未见事件同时出现；这是主表而非附录。

训练/验证/测试事件种子必须在生成器层面分离，禁止只改变随机种子但复用相同事件模板。

## 3. baseline 公平性

所有上层学习方法统一：

- 相同冻结下层检查点；
- 相同全局/局部可观测信息；
- 相同上层决策频率或相同最大决策预算；
- 相同训练环境步数和超参数搜索预算；
- 近似相同 encoder 宽度，额外报告参数量和 FLOPs。

启发式不使用学习方法不可见的未来事件；oracle 只作为上界，不能混入主 baseline 排名。

## 4. 指标层级

### 一级：决定论文是否成立

- win rate / normalized team return；
- interception rate / protected asset survival；
- worst-case performance over held-out opponents；
- empirical exploitability 或 best-response gain。

### 二级：解释为什么成立

- 事件后 25/50 个低层步的 return AUC；
- time-to-recover 到事件前 90% 性能；
- unassigned critical targets、over-concentration rate；
- reallocation count / oscillation rate。

### 三级：成本

- 每次上层决策延迟、GPU/CPU 显存、训练环境步数；
- 对手池大小和快照存储；
- 不同人数下的延迟增长曲线。

论文绝不能用二级指标替代一级指标。

## 6. 消融

- OPAA without opponent pool：等价普通 self-play，验证池本身；
- uniform pool vs hard-opponent weighting：验证采样权重；
- no population randomization：验证跨规模训练支持；
- fixed vs event-driven upper calls：判断收益是否来自更高决策频率；
- frozen vs short joint fine-tune：检查冻结下层假设；
- current observation only vs one-step event memory：只有 P0 显示部分可观测问题时才做。

不需要做 encoder 层数、激活函数等大量弱消融。

## 7. 统计协议

- P0 可用 3 seeds，正式主表至少 5 个训练 seeds；
- 每个 checkpoint 对每个 matchup 至少 200 个配对测试回合；
- 报告均值、95% bootstrap confidence interval 和原始 seed 点；
- 主比较预先指定为 OPAA vs plain self-play、ALMA-style、DT-GAT-style，并对多重检验使用 Holm 校正；
- 超参数只在 validation opponent set 选择，test opponent 不参与挑 checkpoint。

## 8. 预期结果不是承诺结果

以下是继续投稿所需的 go/no-go 门槛，而不是尚未产生的实验结论：

- ID 胜率相对最强 baseline 降幅不超过 2 个百分点；
- held-out opponent 的 worst-case 胜率绝对提高至少 5 个百分点，或 normalized return 提高至少 8%；
- empirical exploitability 相对 plain self-play 降低至少 15%；
- 在至少两个未见兵力比上方向一致，且 95% CI 不完全覆盖零差异；
- 额外上层推理延迟不超过低层控制周期的 10%。

若只改善重编组次数而不改善一级指标，则转为方向 B 并重写研究问题；若只在一个自造脚本上有效，不投稿。

## 9. 最小算力估算

P0 以向量化 SwarmBattle/JAX 环境为目标：7 个方法不应全部从头训练，先跑 heuristic、plain self-play、OPAA 三者。正式阶段再加入三种论文 baseline。以 5 seeds × 6 学习方法 × 2 主环境计算，必须采用早停、共享冻结低层检查点和统一日志；否则两个月周期会被低层重复训练耗尽。
