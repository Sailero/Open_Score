# 三个候选研究内容

下面每个问题先用一句话说清“做什么—为什么—预期效果—如何证明”，再给最小技术路线。

## 方向 A：开放人口对抗分配（推荐）

**一句话：在冻结相同下层技能的攻防博弈中，我们让双方上层在伤亡与增援后同时重编组，并用历史对手池训练规模无关的任务分配器，以降低对未见兵力比和反编组策略的最坏损失，最终用跨策略联赛、经验可利用度和端到端胜率证明。**

### 研究问题

合作式 ALMA/PLATO/DT-GAT 分配器面对会观察并反制其编组的对手时，是否会产生比同分布测试更大的性能坍塌；轻量对手池自博弈能否直接修复这个问题？

### 最小方法

- 使用置换等变的活动实体/任务编码，输出队员到局部目标的分配分数；结构不以网络新颖性为卖点。
- 红蓝双方拥有同构上层策略，分别在较慢时间尺度输出分配，下层共享预训练技能并在主实验冻结。
- 训练时从历史上层策略快照池采样对手，而不是只打当前版本；可采用均匀采样 + 针对最难对手的优先采样。
- 损失只包含团队回报、合法分配约束与极小的熵正则；不加入对手类型分类器。

### 预期与证明

- 预期：同分布性能不显著下降，未见对手/未见兵力比上的最坏胜率提高，经验最佳响应增益降低。
- 证据：完整 payoff matrix、cross-play Elo、worst-case return、训练固定步数的 empirical best response、事件后 return AUC。
- 失败条件：若对手池只提高对已见快照的胜率，或最坏收益不优于普通 self-play，则核心主张不成立。

### 评价

- 创新风险：中低；现有工作分别处理开放、层级和竞争，但尚少有交集。
- 工程风险：中；需要双边上层训练和稳定的对手池。
- 论文价值：最高，直接回应“中间辨识没有意义”的质疑。

## 方向 B：价值触发的最少重编组（保守备选）

**一句话：我们让上层只在新编组的预测任务收益超过保留当前编组的收益与换组代价之和时触发重分配，以在伤亡/增援后保持相近或更高战果的同时减少无效换组和通信，并用端到端任务结果—重编组次数的 Pareto 曲线证明。**

### 研究问题

固定周期或每步重分配会造成目标来回切换、执行窗口过短和额外通信；能否学习“什么时候不动比重新优化更好”？

### 最小方法

- 复用 ALMA/DT-GAT 上层，增加 keep/reallocate 二元 gate。
- 估计保留与重分配的 option value，差值超过带迟滞的阈值才更新；换组成本同时计入路程、技能切换时间和通信次数。
- 不改变分配网络和下层技能，确保贡献只来自触发决策。

### 预期与证明

- 预期：在相同胜率下减少至少 30% 重分配，或在相同重分配预算下提高事件后任务回报。
- 证据：win/interception 与 switch count、message count、recovery time 的 Pareto frontier；比较固定周期、每步、随机和 oracle trigger。
- 失败条件：如果简单固定周期调参后已落在同一 Pareto 前沿，则学习 gate 没有研究价值。

### 评价

- 创新风险：中高；ATA-HRL 已做条件重分配，DT-GAT 已做双频和振荡抑制，必须强调机会损失与对抗事件。
- 工程风险：低；最适合快速形成结果。
- 论文价值：工程意义清晰，但上限低于方向 A。

## 方向 C：联盟边际价值与约束匹配（工程备选）

**一句话：我们学习每个队员加入某个“友军—敌军—目标”局部联盟的边际战果，再用容量约束匹配器生成始终可执行的编组，使小规模训练能零样本处理更大和未见兵力比，并用可行率、推理时延与端到端胜率证明。**

### 研究问题

独立 pointer 容易多人冲突或过度集中，直接枚举联合分配又随规模指数增长；能否把长期联盟价值学习与多对一容量求解解耦？

### 最小方法

- 用集合网络估计把智能体加入当前目标组的 counterfactual marginal value。
- 将边际值输入 min-cost flow、容量 Hungarian 或 entropic optimal transport，满足每人至多一任务、每任务上下限和关键目标覆盖。
- 固定下层并在小规模训练，直接测试更大活动集合。

### 预期与证明

- 预期：分配合法率达到 100%，大规模推理明显快于 autoregressive enumeration，未见规模端到端性能优于独立 pointer。
- 证据：feasibility、constraint violations、latency/memory scaling、zero-shot win/completion、边际值消融。
- 失败条件：若手工效用 + 同一求解器已达到相同战果，则学习边际价值没有必要。

### 评价

- 创新风险：中；REDA 已做“学习价值 + 最优分配”，CIAO 已引入合作博弈，必须突出多对一联盟互补与敌方编组。
- 工程风险：中低；训练比方向 A 稳定。
- 论文价值：适合偏工程期刊，但对“开放博弈”的表达较弱。

## 综合排序

| 方向 | 创新性 | 实际价值 | 1–2 月可行性 | 与用户原始想法一致性 | 推荐 |
|---|---:|---:|---:|---:|---:|
| A 对抗分配 | 4.5/5 | 5/5 | 3.5/5 | 5/5 | 首选 |
| B 最少重编组 | 3/5 | 4.5/5 | 4.5/5 | 4/5 | 首选失败后的备选 |
| C 联盟值匹配 | 3.5/5 | 4/5 | 4/5 | 4/5 | 工程期刊备选 |

推荐只把 A 写成主论文；B 可作为 A 的一个代价正则/消融，但不能同时再把 C 整套塞进去。
