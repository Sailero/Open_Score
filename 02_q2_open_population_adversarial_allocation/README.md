# 开放人口攻防博弈：上层对抗分配与泛化

## 最终建议的一句话

**我们把伤亡与增援下的编组从“对固定目标做合作分配”改写为双方同时重编组的开放人口上层博弈，在冻结相同下层技能后用规模无关的对抗训练分配器直接优化任务胜负，使策略面对未见兵力比和反编组对手时仍不易被利用，并用跨策略联赛、经验可利用度与端到端胜率证明。**

工作题目：*Who Should Fight Whom When Teams Change? Robust Upper-Level Allocation in Open-Population Team Games*。

## 为什么改题

旧版 CDOC 研究的是“不要把减员误识别成对手换策略”，但它只是对手建模链条中的中间诊断；如果这种辨识不能稳定提高最终胜率，论文价值有限。新调研还发现，单纯做动态分组、图注意力、变长输入或切换惩罚也已经拥挤：ALMA、PLATO 与 2026 年 DT-GAT-MARL 分别覆盖了层级分配、智能体/任务同时开放、动态拦截与抑制振荡。

因此本阶段只保留一个尚未被这些工作同时解决的问题：**双方都有智能上层决策且双方人数都可在回合中变化时，如何学习可跨规模、低可利用的实时编组策略。**

## 研究边界

- 研究上层：队员分到哪个局部任务、对手或目标，以及何时重分配。
- 固定下层：攻击、拦截、护卫等技能先预训练并在主实验中冻结，所有上层方法共用同一检查点。
- 主指标必须是最终胜负、拦截率、资产存活率和最坏对手收益；分组纯度、角色识别率等只能作为机制诊断。
- 主论文不再提出新的对手识别模块，不把“又一个 GNN/Transformer”写成贡献，也不同时学习通信、角色、世界模型和下层控制。

## 三个候选方向

1. **开放人口对抗分配（推荐）**：双方上层同时编组，以对手池自博弈学习在未见规模和反编组策略下仍稳健的分配器。
2. **价值触发的最少重编组（保守备选）**：只在预计收益增量超过换组代价时重分配，以相近或更高战果显著减少振荡与通信。
3. **联盟边际价值与约束匹配（工程备选）**：学习队员加入局部战斗的边际战果，再由容量约束求解器产生始终可执行且可外推的分配。

先执行方向 1 的两周 P0；若对手池训练相对普通自博弈不能改善最坏对手端到端表现，再转向方向 2，而不是继续堆模块。
