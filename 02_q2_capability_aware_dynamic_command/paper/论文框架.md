# SCORE 论文框架（单篇收束版）

> 论文范围锁定：**核心贡献是“选择失效问题 + 同态势双边配对干预协议 + 预测—决策—闭环证据链”；算法层只保留 pilot-selector-focused 拟合与 selector-aware 经验修正，S1 冻结，S4 不进入本文。**
>
> 一句话：**本文研究如何让多目标防御指挥官在战损后在线重编组时，少选“预测安全、实则失守”的分兵方案。**

## 2. 核心论文命题

本文只回答一个问题：

> 当上层指挥官从有限但反复比较的候选编组中挑选模型预测最优的方案时，普通结果模型的误差会不会被选择过程和对手最坏响应共同放大；若会，能否通过同态势双边分叉实验、选择器条件学习与独立经验修正，将预测可靠性转化为更低的决策遗憾和任务失败率？

### 主张—证据契约

| 论文主张 | 必须出现的证据 | 不足时如何降级 |
|---|---|---|
| 选择过程放大乐观误差 | 随机候选与 selected candidates 的 false-safe / calibration gap | 删除“selection-induced”主叙事 |
| 双边分叉数据改善候选比较 | 同预算日志/单边/非配对数据对照与同快照排序 | 仅称普通结果预测器 |
| 选择校准经验修正有决策价值 | 独立真值矩阵上的 regret 与最坏响应收益 | 不将经验修正列为贡献 |
| 离线改进转化为任务价值 | 动态闭环、Opponent-OOD 的最坏成功率 | 结论收缩为离线决策方法 |
| 方法不依赖 HAD 动力学 | Open-SMAX-AD 上核心效应方向一致 | 明确限定为 Open-HAD 案例 |

以上每项都必须由真实实验决定；在实验完成前，不能把假设写成结论。

## 3. 摘要

### 3.1 六句摘要结构

1. **场景与价值：** 多目标攻防中，战损持续改变可用单位，指挥官必须在对手分兵未知时反复重分配兵力，否则一个薄弱目标即可导致整体任务失败。
2. **现有缺口：** 现有层次多智能体方法主要学习单边任务分配或端到端策略，却通常不检验结果模型在被规划器极值选择之后是否仍可靠。
3. **关键问题：** 一个在随机测试候选上准确且校准的模型，仍可能对最终被选中的编组系统性乐观，使上层决策被对手最坏响应利用。
4. **方法：** 本文提出 SCORE，在冻结下层执行器的条件下，从同一态势分叉执行双方完整编组，以固定 continuation 评价首个宏动作在滚动结果窗口内的二元任务失守风险；分组交叉拟合只让结果拟合对准冻结 pilot 关注的区域，独立 lineage 再用于校准与经验修正，最终访问分布由封存 Test 审计。
5. **决策与实验：** SCORE 用经验保守修正后的失守分数构造有限双方收益矩阵，在线求单步 maximin 重编组；在 Open-HAD 和 Open-SMAX-AD 上，以预测、决策和闭环三层实验对照 rank-augmented point planner、adapted ALMA-AQL、adapted GAT-PPO 及采样/解析基线。
6. **结果与意义：** 仅在实验完成后填写“selected false-safe、decision regret、最坏对手成功率和代价”的真实效应量及置信区间，并据此说明选择后可信结果接口是否确实改善动态指挥。

### 3.2 可直接改写的摘要草稿（结果占位版）

多目标攻防中的伤亡会持续改变双方可用兵力，使集中式指挥官必须反复重编组；由于任一关键目标失守即可导致整体失败，平均分兵或仅按当前威胁贪心分配容易暴露最薄弱防线。现有层次多智能体方法已经能够学习任务分配与下层执行，但较少检验一个更基础的问题：当上层规划器从有限候选矩阵中反复选择预测最优方案时，结果模型在随机样本上的准确性是否仍能代表被选方案的可靠性。本文提出 SCORE（Selection-Calibrated Outcome-Guided Reallocation）。在冻结任务条件执行器后，SCORE 从可恢复的同一态势出发，对双方完整数量编组进行配对分叉执行：候选编组先执行控制周期 $H_c$，随后由固定、版本化且方法无关的 continuation $\kappa$ 延伸到结果窗口 $H_o=K_oH_c$（默认 $K_o=3$），主模型只预测该窗口内是否发生任一目标失守；随后利用按 root-episode lineage 分组的交叉拟合，使结果拟合与排序对准冻结 pilot 关注的候选区域，并在互不重叠的 Selector-Cal 与 Bound-Validate lineages 上分别做温度校准和 selector-aware 经验保守修正。在线阶段，SCORE 将修正后的任务失守分数写入至多 $16\times8$ 的完整双方收益矩阵，求解单步 maximin 混合编组，只执行首个 $H_c$ 后以模型预测控制方式重新规划。我们在 Open-HAD 与 Open-SMAX-AD 上按照预测、离线决策和动态闭环三层协议进行评估，并将 rank-augmented point planner、adapted ALMA-AQL、adapted GAT-PPO、稀疏配对 MC/Wilson upper 与解析双边 maximin 作为主要近邻。**[实验完成后填入：相对最强基线的 selected false-safe、decision regret、Opponent-OOD 最坏成功率及 95% CI；若相应门槛未通过，则删除对应结论。]** 本文不预设 SCORE 已知实际部署访问分布，也不提供逐点或最终决策保证；最终价值只由封存测试中的决策和闭环证据决定。

## 4. Introduction：五段逻辑

### 第 1 段：用一个具体失败场景提出问题

从三目标防御场景切入：攻击者可集中打击任一目标，防守者必须保护全部目标；战斗中的死亡使开局分配迅速失效。双方指挥官每隔固定控制周期 $H_c$ 同时重新分配当前存活单位，下层单位只执行收到的目标任务；周期内死亡只更新 active mask，并在下一个固定边界反映到候选集合。强调实际困难不是“每个智能体再学一个动作”，而是**上层如何在兵力持续变化、对手本步分兵不可见的条件下，在线判断哪种完整编组最不容易被击穿**。

### 第 2 段：承认现有工作已解决什么

ALMA 已研究上层任务分配与下层执行的联合学习，DT-GAT-MARL 等方法已覆盖动态节点和分层指派，REFIL、FlickerFusion 等工作也说明可变实体集合与人口泛化不是空白。因此，本文不把“层次控制、动态图输入、战损后重分配、任务 token 或 maximin 求解”单独包装为创新。现有工作的共同不足应精确写成：它们通常没有建立一个面向**双方完整分配**、可由同态势真实执行验证、并在规划器选案后仍受审计的结果接口。

### 第 3 段：提出 selection gap 这一中心矛盾

普通结果模型在随机候选上取得较低 Brier/NLL，并不保证它能支持规划：优化器会偏向预测极值，估计误差因此可能被选择过程放大，这与 optimizer's curse 的一般现象一致 \citep{smith2006optimizers}。对抗矩阵中的均衡支撑和近边界候选还会受到最坏响应筛选。由此提出可证伪假设：随机候选上的良好平均校准与 selected candidates 上的低 false-safe 之间存在 selection gap。若实验不能稳定观察到该 gap，本文就不应声称解决了选择后可靠性问题。

### 第 4 段：给出 SCORE 的一条方法主线

SCORE 固定下层能力，贡献聚焦于“评估—决策”接口。首先，从完全相同的快照和随机带出发，仅替换双方首个控制周期的数量编组 $(x,y)$，再由固定 continuation $\kappa$ 延伸到 $H_o=K_oH_c$，得到可配对比较的二元任务失守标签；其次，在双方完整分区上直接预测联合任务失败，并利用 OOF pilot selector 确定模型应重点学习、排序和校准的候选区域；再次，在模型、校准器和 selector 全部冻结后，用独立 lineage-cluster bootstrap 估计分层平均低估的经验保守修正；最后，把该修正写入小型完整收益矩阵并求单步 maximin。标准实体编码、温度缩放、bootstrap、Hungarian 和线性规划都是可替换组件，不单列贡献，公式本身也不提供逐点或最终决策保证。

### 第 5 段：贡献与证据概览

正文贡献写成三条：

1. 定义动态人口多目标攻防中的双边编组结果接口，并用随机候选与 selected candidates 的差异刻画选择后可靠性问题；
2. 提出面向完整双方编组的同态势配对分叉与 selector-conditioned 结果学习接口，联合优化二元结果概率和同态势排序，并用独立数据估计经验保守修正；
3. 将该修正嵌入有限完整矩阵的 maximin 重编组，并用预测—决策—闭环三层证据检验其真实价值。

最后一段必须说明边界：S1 冻结，S4 不属于本文；本文只求有限候选矩阵上的单步 maximin，不声称求解原动态博弈的纳什均衡，也不声称 OOD 形式安全保证。

## 5. Related Work：只保留三类

### 5.1 层次多智能体任务分配与动态指挥

围绕 ALMA \citep{iqbal2022alma} 组织：ALMA 是本文最重要的结构锚点，它以高层 AQL 分配和低层执行处理多军团任务及伤亡后的重分配。随后用 DT-GAT-MARL \citep{jia2026dtgat}、C2 opponent modeling \citep{c2opponent2026} 和 Dynamic Alliance \citep{dynamicalliance2026} 说明动态图指派、指挥/执行分层和故障后重组已有充分先例。落脚到本文差异：SCORE 不再发明一个上层网络，而是研究冻结执行能力下，双方编组结果在被 selector 使用后是否可信。

### 5.2 结果建模、结构化分配与决策导向学习

用 structured prediction MARL \citep{carion2019structured}、decision-focused learning-to-rank \citep{mandi2022decision} 和 bi-level MRTA \citep{lin2025adaptive} 说明“学习评分后再做组合优化”和“用任务成功概率辅助分配”并非新概念；decision calibration 也已表明校准可以直接围绕下游决策定义 \citep{zhao2021decisioncalibration}。本文新增的问题不是把预测器接到求解器，而是：训练数据如何用同态势双边主动分叉覆盖完整分区，预测器如何针对冻结 pilot 关注区域学习排序与概率尺度，以及所有方法如何在独立真实 rollout 矩阵上比较 decision regret。

### 5.3 动态人口泛化与选择后决策可靠性

REFIL \citep{iqbal2021refil}、UPDeT \citep{hu2021updet} 与 FlickerFusion \citep{koh2025flickerfusion} 支撑可变实体输入、成员加入/退出和跨规模泛化，因此这些能力只作为 S1 和编码器条件。概率校准 \citep{guo2017calibration} 解决整体概率尺度，但普通全局校准并不自动处理规划器诱导的分布偏移。SCORE 将这两个方向连接到一个窄问题：在动态兵力候选空间中，对准 pilot 关注区域拟合，并在封存数据上审计最终被指挥官选择的方案。

### 最小相关工作对比表

| 工作/家族 | 动态人口 | 双方完整分配 | 选择后可靠性 | 与 SCORE 的核心差异 |
|---|:---:|:---:|:---:|---|
| ALMA | 伤亡后重分配 | 否，仅我方 | 否 | 学习层次分配，不审计结果模型选案后误差 |
| DT-GAT / Dynamic Alliance | 是 | 否 | 否 | 关注动态图指派与重组 |
| Bi-level MRTA / structured prediction | 部分 | 否 | 部分 | 学评分/成功率后优化，非双边选案后风险 |
| REFIL / FlickerFusion | 是 | 否 | 否 | 关注实体与人口泛化 |
| SCORE | 是；增援仅压力测试 | 是 | 是 | 同态势分叉、选择条件可靠性与经验保守决策 |

## 6. Preliminaries

### 6.1 动态人口多目标攻防博弈

在宏观时刻 $t$，指挥层可用态势写为

$$
s_t=(\mathcal U_t^D,\mathcal U_t^A,\mathcal G_t,\xi_t),
$$

其中 $\mathcal U_t^D$ 与 $\mathcal U_t^A$ 是双方当前存活实体集合，$\mathcal G_t=\{g_1,\ldots,g_M\}$ 是关键目标集合，$\xi_t$ 包含剩余时间和上一宏步编组。主实验只研究自然战损导致的成员退出；增援事件作为 held-out stress test，而不是首篇成立条件。

首篇固定 $M=3$，防守方在时限前保护全部目标或消灭全部攻击者即成功；任一目标先失守则任务失败。这是 weakest-link mission，不等同于各目标成功率独立相乘。

### 6.2 宏动作与固定落地器

双方同时选择数量编组

$$
x=(x_0,\ldots,x_M),\quad \sum_{m=0}^{M}x_m=|\mathcal U_t^D|,
$$

$$
y=(y_0,\ldots,y_M),\quad \sum_{m=0}^{M}y_m=|\mathcal U_t^A|,
$$

其中 $m=0$ 是可选预备队。固定匹配器 $H_\psi$ 用距离、任务适配与换组代价，把计数向量映射为实体任务 token；冻结下层执行器 $\pi_L$ 在一个控制周期 $H_c$ 内执行这些 token。所有方法共用 $H_\psi$、$\pi_L$、固定决策时钟和部署可用信息，以隔离上层方法差异。

### 6.3 双时间尺度结果变量与决策目标

候选 $(x,y)$ 只控制首个 $H_c$；若任务尚未终止，双方随后都由固定、版本化且方法无关的 continuation rule $\kappa$ 接管，直至结果窗口

$$
H_o=K_o H_c,\qquad K_o=3\ \text{（默认起点）}.
$$

从同一快照同时施加双方首个宏动作，主结果为

$$
Z_{H_o}\sim P(Z\mid s,do(x),do(y);\pi_L,H_\psi,\kappa,H_c,H_o),
\qquad Z_{H_o}\in\{0,1\},
$$

其中 $Z_{H_o}=1$ 表示 $H_o$ 内任一目标失守。结果模型直接输出

$$
\hat p_\phi(s,x,y)=
P_\phi(Z_{H_o}=1\mid s,x,y;\kappa,H_c,H_o).
$$

首个失守目标、战损和目标剩余耐久只作数据诊断，不增加预测头，也不进入 S3。$H_c$、$K_o$ 与 $\kappa$ 在 E0 后、E1 前一次冻结并写入数据版本；在线部署采用模型预测控制（MPC），每次只执行首个 $H_c$，随后从新态势重新规划，而不是承诺执行完整 $H_o$。这里的 $do(x),do(y)$ 仅表示模拟器中主动设置且可重放的首宏动作分叉，不宣称从一般观测日志识别个体反事实或跨环境因果效应。

### 6.4 关键符号

| 符号 | 含义 | 是否学习 |
|---|---|:---:|
| $s,\mathcal U^D,\mathcal U^A,\mathcal G$ | 指挥态势、动态双方实体和目标集合 | 否 |
| $x,y$ | 双方完整数量编组候选 | 否 |
| $H_\psi,\pi_L$ | 固定实体匹配器与冻结下层执行器 | 本文中否 |
| $H_c,H_o,K_o,\kappa$ | 控制周期、结果窗口、窗口倍数与固定 continuation | 否 |
| $\hat p_\phi,\hat p^{\mathrm{cal}}$ | 二元失守概率与校准概率 | 是 |
| $c_b,p^+,A,\mu$ | 经验保守修正、风险分数、收益矩阵与混合编组 | 估计/求解 |

## 7. Method: SCORE

### 7.1 方法总览

全文只保留一条可证伪的证据链：

$$
\text{同态势双边首宏动作分叉}
\rightarrow
\text{pilot-focused 结果模型与经验修正}
\rightarrow
\text{风险矩阵}
\rightarrow
\text{单步 maximin 重编组}.
$$

建议总图只画三条实线模块：冻结 S1、核心 S2、核心 S3；S4 用灰色虚线框标注“future work”，不画回主算法。

### 7.2 S1：冻结执行器只是稳定能力接口

$\pi_L(u_i\mid o_i,a_i)$ 接收局部实体观测和目标任务 token，完成接近、拦截、集火或守点。它可由 MAPPO \citep{yu2022mappo}、REFIL 或 UPDeT 思路训练，也可在早期使用稳定脚本；训练完成后连同匹配器 $H_\psi$ 一起冻结并记录版本哈希。本文只验证其能服从不同任务与规模，并且不同上层分配会产生可区分结果，不提出新的下层网络。

### 7.3 S2-A：预注册 roll-in 与同态势双边配对分叉

根状态不能来自任意日志切片。Fit-base 的 roll-in commander 由随机可行编组、static uniform、force-ratio 和 adapted AQL 的预注册 mixture 组成；若 adapted AQL 尚未就绪，则用冻结威胁启发式替代并记录。只从早、中、晚阶段的非终局固定宏边界分层取样，不在周期内伤亡时刻额外抽样。

对每个可恢复快照 $s_g$ 生成并采满至多 $16\times8$ 的防守—攻击候选矩阵。对每个 $(x_i,y_j)$ 恢复完全相同的环境状态，只改变首个 $H_c$ 的 assignment；若未终止，则双方均由同一个固定 continuation $\kappa$ 延伸到 $H_o=K_oH_c$。相同重复编号使用共享随机带 $\omega_r$：

$$
Z_{gij}^{(r)}=\operatorname{Rollout}
(s_g,do(x_i),do(y_j),\omega_r,H_c,H_o,\pi_L,H_\psi,\kappa).
$$

在 Fit-base 上完成 lineage-safe 交叉拟合并得到 OOF pilot 后，最终结果模型只用 Fit-base 的 OOF 权重从头训练一次，不把 planner 生成的新状态回流 Fit。随后将模型和 pilot planner 冻结，用预注册的“基础 mixture + pilot”roll-in 分别生成互不重叠的 Selector-Cal 与 Bound-Validate root lineages，并采满各自小矩阵；最终 SCORE 引起的 state-visitation shift 只在封存 Test 上审计。共享随机数的作用只是降低候选差值方差；同快照主动分叉的价值是密集覆盖、公平配对和可重放比较，二者都不被表述为一般因果识别定理。所有同源快照、候选和随机重复按完整 root episode lineage 分组，不能跨 split 泄漏。

### 7.4 S2-B：最小联合结果模型

模型输入双方完整实体分区及目标状态，不把各战线独立处理。最小网络只含共享实体 MLP、按任务的 sum/mean pooling、一层 masked set-attention \citep{lee2019settransformer}，以及一个 $H_o$ 内 mission-breach logit。首个失守目标、战损和目标耐久只作为数据诊断，不进入模型主输出或 S3 收益。

主损失是分类负对数似然

$$
\mathcal L_{\mathrm{out}}=
-Z_{H_o}\log\hat p_\phi-(1-Z_{H_o})\log(1-\hat p_\phi).
$$

同一快照内，固定一方编组并比较另一方候选，用 pairwise logistic ranking loss 辅助学习局部顺序；近似平局不构造排序对。若 DeepSets \citep{zaheer2017deepsets} 已能得到相同性能，优先采用更简单的 DeepSets，不为复杂网络本身建立创新叙事。

### 7.5 S2-C：selector-conditioned cross-fitting 与校准

Fit 数据按 lineage 做 $K_{fold}$ 折交叉拟合（默认 $K_{fold}=5$，与结果窗口倍数 $K_o=3$ 区分）。每个 pilot 模型只对未见折产生 OOF 收益矩阵，聚合一次 OOF 预测后冻结唯一的 pilot selector，再把矩阵单元预先划为 core、near 和 background。训练分布保留非零均匀成分：

$$
q_g(i,j)=(1-\rho)q_{\mathrm{uniform}}(i,j)+\rho q_{\mathrm{focus}}(i,j).
$$

由此得到裁剪后的 selector 权重 $w_{gij}$，用于加权 BCE 和同快照排序损失。最终模型只在 Fit-base 上用 OOF 权重从头训练一次，不循环刷新 selector，也不加入缺乏 OOF 权重的 planner roll-in 训练集。模型冻结后，只在独立 Selector-Cal 上拟合失守 logit 的加权温度：

$$
\hat p^{\mathrm{cal}}=\sigma\left(\operatorname{logit}(\hat p)/T\right).
$$

温度校准修正概率尺度而不改变排序；排序改进来自配对分叉数据、完整双边输入和 ranking loss。

### 7.6 S2-D：selector-aware 经验保守修正

在训练、校准器和 selector 全部冻结后，对 Bound-Validate 中每个 lineage、每个 selector 层 $b$ 聚合真实失守率与校准预测的残差 $R_{g,b}\in[-1,1]$；一个 lineage 对每层最多贡献一个残差。设层数 $B\le3$，在查看标签前预注册 lineage-cluster bootstrap \citep{efron1979bootstrap} 次数 $A=2000$ 和上尾经验分位水平 $1-\alpha/B$（默认 $\alpha=0.05$）。每次只重采样完整 lineage，令 $U_b^{\mathrm{boot}}$ 为 bootstrap 均值的相应经验分位数，并定义

$$
c_b=\max\{0,U_b^{\mathrm{boot}}\}.
$$

部署时使用

$$
p^+_{ij}=\operatorname{clip}
(\hat p^{\mathrm{cal}}_{ij}+c_{b(i,j)},0,1).
$$

必须准确陈述其含义：它是 Bound-Validate roll-in 分布上、selector 同一层候选**平均低估残差的经验性有限样本近似**。cluster bootstrap 不是 distribution-free coverage 定理；经分层、截断和再次选择后，$p^+_{ij}$ 既不是每个矩阵单元的 pointwise 概率上界，也不给最终 maximin 决策任何形式保证，更不继承到任意 OOD 对手或候选集外行为。其价值只能由封存 Test 上的 selected false-safe 与 decision regret 下降证明。

### 7.7 S3：有限候选上的风险 maximin 重编组

每个宏步依据当前存活单位数生成计数候选。Day-0 小规模 oracle 可枚举全部整数拆分；主训练和部署使用固定比例网格，并加入均分、集中、延续上一编组和威胁比例模板，冻结为 $|\mathcal X|\le16$、$|\mathcal Y|\le8$ 的完整小矩阵。每个训练快照采满全部矩阵单元，每个候选只通过固定 Hungarian/min-cost matcher 落实到具体单位。

对防守方构造单一任务收益

$$
A_{ij}=1-2p^+_{ij},
$$

不再混入战损、距离等人工奖励。求解

$$
\mu^*=\arg\max_{\mu\in\Delta(\mathcal X)}
\min_j\sum_i\mu_iA_{ij}.
$$

从 $\mu^*$ 采样数量编组，使用固定匹配器生成实体任务，只执行 $H_c$ 后从新态势滚动重规划；离线 continuation $\kappa$ 不替代在线 MPC。该 LP 是标准求解器，不是算法创新；本文只声称在当前有限候选矩阵上取得单步 maximin 解。

### 7.8 Algorithm 1：离线训练与在线部署

~~~text
Input: frozen executor πL, fixed matcher Hψ, candidate generators,
       preregistered roll-in mixture, continuation κ,
       Fit / Selector-Cal / Bound-Validate lineage groups, Hc, Ho=Ko·Hc (Ko=3 default)

Offline:
1  Generate Fit-base lineages with the frozen random/static/force-ratio/AQL mixture;
   at fixed macro boundaries, restore each snapshot and collect every cell of ≤16×8.
2  For each (x,y), execute it for Hc, then use the shared κ until Ho; record binary breach.
3  Group-cross-fit pilot models on Fit-base; obtain OOF roles and OOF cell weights.
4  Train one final model only on Fit-base with OOF-weighted BCE and ranking; freeze it.
5  With a preregistered base-mixture + frozen-pilot roll-in, independently collect
   disjoint Selector-Cal and Bound-Validate root lineages; keep Test sealed.
6  Freeze model and pilot selector; fit temperature T only on Selector-Cal.
7  On Bound-Validate, aggregate one residual per root lineage and pilot stratum;
   compute c_b from a preregistered lineage-cluster bootstrap mean quantile.

Online at macro step t:
8  Generate count allocations X_t (≤16) and possible opponent allocations Y_t (≤8).
9  Map each allocation to entity tasks with the shared fixed matcher Hψ.
10 Batch-predict p_cal(s_t, x_i, y_j), assign stratum b(i,j), and add c_b.
11 Set A_ij = 1 - 2 p^+_ij and solve the finite maximin LP for μ*.
12 Sample x_t ~ μ*, execute πL for exactly Hc steps unless terminal, then replan.
~~~

### 7.9 为什么没有 S4

更新 $\pi_L$ 会同时改变分叉标签、结果模型的能力边界和 selector 访问分布，使当前校准对象非平稳。如何检测这种漂移并安全地共同更新上下层，是第二篇论文的问题。本文方法在第 12 步结束，不执行下层更新、端到端反传或交替优化。讨论部分可用一段话说明 S4，但主方法图、Algorithm 1、主消融和贡献列表都不得把它写成已解决模块。

## 8. Experiments

### 8.1 研究问题

- **RQ0（必要性）：** 场景中是否存在足够的 oracle headroom 与随对手编组变化的最优分配反转？
- **RQ1（预测）：** 普通模型在 selected candidates 上是否出现 selection gap，SCORE 能否降低 false-safe 并改善同态势排序？
- **RQ2（决策）：** 预测可靠性是否在独立真实 rollout 矩阵上转化为更低 decision regret 和更高最坏响应收益？
- **RQ3（闭环）：** 在自然战损、未见规模/兵力比和未见对手分配策略下，SCORE 是否减少任务失败且在线代价可接受？
- **RQ4（外部有效性）：** 核心效应是否能在另一套动力学中复现？

### 8.2 环境及角色

| 环境 | 论文角色 | 必要改造 | 不承担什么主张 |
|---|---|---|---|
| Open-HAD | E0–E3 主环境、机制与 oracle 证据 | 精确 clone/PRNG、双方 assignment、三目标、固定 $H_c$ 与 $\kappa$ | 当前原始代码不能直接作为可复现 benchmark |
| Open-SMAX-AD | E4 跨动力学确认 | 基于 JaxMARL/SMAX \citep{rutherford2024jaxmarl} 增加资产、双边编组和同构双时间尺度 | scoped 新任务扩展，不称现成标准 benchmark |
| ALMA sc2multiarmy | 公开层次分配复现锚点、AQL 来源 | 锁定上游版本并审计 adapted AQL | 不生成 SCORE 的核心同快照分叉数据 |

主实验固定三目标、同质单位和自然战损；初始训练规模使用 $6v6$、$8v8$、$10v10$，未见比例/规模、伤亡组合、对手策略家族作为 OOD。决策只发生在固定 $H_c$ 边界，周期内死亡只改变 active mask；增援只在 stress test 的宏边界激活。

“未知对手”在首篇中只指**宏观 allocator 家族或训练谱系未见**；对手下层策略与实体 matcher 固定，不能同时把未知执行技能、未知通信和未知动力学混入一个 OOD 标签。预注册 Opponent-OOD 主池中的每个实际宏动作必须能映射到当步注册候选 $\mathcal Y_t$，并逐策略报告 candidate coverage；主池要求 coverage 为 100%。输出候选集外动作的对手只进入 Candidate-outside stress，不与主终点混算。

### 8.3 数据划分与防泄漏

| Split | 比例起点 | 唯一用途 | 明确禁用 |
|---|---:|---|---|
| Fit | 60% | 交叉拟合、网络训练和开发集调参 | 最终经验修正 |
| Selector-Cal | 15% | 冻结模型后的选择器条件温度校准 | 网络选择与反复复用 |
| Bound-Validate | 10% | 一次性估计预注册 $c_b$ | 任意调参 |
| Test/Oracle | 15% | 最终预测、真实矩阵与闭环评价 | 训练与阈值选择 |

最小独立单位是完整 root episode lineage；其全部快照、候选、CRN 重复与同谱系 checkpoint 必须位于同一 split。Fit-base 使用预注册 roll-in mixture；OOF pilot 只生成 Fit-base 权重，最终模型仍只在 Fit-base 训练。模型冻结后，预注册的 base-mixture + pilot roll-in 才分别生成互不重叠的 Selector-Cal 与 Bound-Validate lineages；OOD 家族在开发前整体留出，最终 SCORE 的状态访问分布不回流训练，只在 Test 审计。

### 8.4 Baselines

| 类别 | 方法 | 证明什么 |
|---|---|---|
| 启发式 | static uniform、force-ratio、Hungarian/min-cost | 是否超过简单可部署规则 |
| 点模型消融 | bilateral learned point、unilateral outcome model | 隔离双边输入、选择校准和经验修正 |
| 决策导向近邻 | rank-augmented point planner | 同数据和排序损失下，selector 条件可靠性是否额外有用 |
| 学习式层次分配 | adapted ALMA-AQL、adapted GAT-PPO | 是否超过 AQL 与动态图高层策略范式 |
| 采样/解析近邻 | sparse paired MC + Wilson upper \citep{wilson1927probable}、analytic bilateral maximin | 与少量在线分叉及手工双边矩阵比较 |
| 非部署上界 | small exhaustive MC oracle | 计算真实 regret，不参加公平预算排名 |
| 系统参考 | end-to-end MAPPO \citep{yu2022mappo}（可选） | 只作整体参考，不用于组件归因 |

公平比较统一的是信息、动作语义、下层能力和预算，而不是强迫不同算法使用同一内部求解器。所有可部署方法共用部署观测、冻结 S1 checkpoint、固定 $H_c$、计数分配语义、实体匹配器和换防约束；矩阵方法共用同一 $16\times8$ 候选集，直接策略方法输出同一可行动作空间。学习方法对齐环境交互步、训练 seeds 和开发试验数；Sparse MC 另按额外在线 rollout 数给预算—性能曲线。ALMA 原生 `sc2multiarmy` 复现与 **adapted ALMA-AQL** 必须分开：在正式报告 adapted baseline 前，至少完成一个官方配置的 anchor，记录上游 commit、依赖、训练曲线及复现偏差；adapted 版本只移植 AQL 思想到统一接口，不冒充官方 ALMA 结果，也不要求与 SCORE 共用结果矩阵或 LP。adapted GAT-PPO 同样标作公平移植而非 DT-GAT 官方复现。

### 8.5 必要消融

主文只保留两项**方法级消融**：

1. `w/o Pilot-Focused Fitting`：用同一 Fit-base 做均匀 BCE/全局校准，不使用 OOF pilot 权重；
2. `w/o Empirical Correction`：保留 pilot-focused 拟合与温度校准，但用点概率直接构造矩阵。

双边主动分叉的价值通过两个**数据协议审计**单列验证：一是保留双边干预但取消 CRN 配对，二是改用单边或自然策略日志。Hungarian、温度缩放、lineage split、bootstrap 与 maximin LP 是协议/实现件，不扩成并列算法模块；纯 argmax 只作决策规则对照。隐藏维度、attention heads、ensemble 数等工程超参数移至附录。

### 8.6 E0–E4 执行顺序

| 实验 | 核心动作 | 阶段验收量 | 通过后才允许做什么 |
|---|---|---|---|
| E0 Day-0 | $4v4/5v5$ 穷举矩阵，并冻结 $H_c,K_o,\kappa$ | oracle headroom、rank reversal、非饱和比例 | 训练 S2 |
| E1 预测 | 比较随机与 selected candidates | Brier/NLL、false-safe–coverage、ranking | 声称结果接口可信 |
| E2 决策 | 用独立大样本 $U^*$ 评价所有方法 | decision regret、最坏响应收益、时延 | 声称预测改善决策 |
| E3 闭环 | 动态战损与 ID/OOD 对手池滚动评测 | **唯一统计主终点：Opponent-OOD 固定有限池最坏防守成功率** | 声称动态指挥有效 |
| E4 外部验证（可选） | 门槛全通过后做 Open-SMAX-AD 核心复验 | decision regret 的效应方向与 CI | 声称跨动力学决策结论 |

实验顺序不能倒置。E0 没有可决策空间则停止方向；E1 只有平均 Brier 改善但 selected false-safe 不降，则删除选择后可靠性主张；E2 regret 不降则不能用闭环胜率掩盖接口失败；E3 不通过则论文核心主张不成立。E4 与 end-to-end MAPPO 仅在上述门槛全部通过且资源仍允许时启动，不属于 1–2 个月 MVP；MVP 只覆盖 E0–E2 的 Go/No-Go 与 pilot 证据。

### 8.7 三层指标

**预测层：** 随机/selected Brier 与 NLL、selection gap、false-safe–coverage、同快照 pairwise ranking、各 selector 层平均低估残差与经验修正紧致性。bootstrap 分位数只作经验保守修正，不能报告为逐点 coverage 或安全保证。

**决策层：** 在独立真实 rollout 收益矩阵 $U^*$ 上计算

$$
v(\mu;s)=\min_y\sum_x\mu(x)U^*(s,x,y),
\qquad
R(s)=v^*(s)-v(\mu;s).
$$

主报 mean/median decision regret、有限对手集最坏收益、p50/p95 规划时延和预算—遗憾曲线。任何方法都不能用自己的预测矩阵给自己评分。

**闭环层：** 预注册 Opponent-OOD 固定有限对手池中的最坏防守成功率是全文**唯一统计主终点**；同时报告实际执行候选 false-safe、由同一冻结独立 Test/Oracle 评估器计算的失守风险恢复、换防比例、转场距离、实际宏决策次数、求解超时/降级次数与 p95 时延。只写有限对手池 worst response，不写“精确 exploitability”或 NashConv。E4 的确认量是 decision regret，第二环境闭环成功率只作辅助外部证据。

### 8.8 统计协议

- 调试使用 3 个 seeds，不进入主表；正式学习方法至少 5 个独立训练 seeds，功效不足时增加到 8–10 个。
- 每个固定 matchup 每个训练 seed 至少 500 个配对 episode；最终数量由 pilot 功效分析上调。
- 方法共享根状态、对手与随机带；95% CI 使用“训练 seed → root episode”的两级 paired hierarchical bootstrap。
- 主端点预先固定为 Opponent-OOD 固定有限对手池的最坏防守成功率；三个核心对比 rank-augmented point planner、adapted ALMA-AQL 和 adapted GAT-PPO 使用 Holm 校正，point/unilateral 属于机制或协议审计。
- 报告失败 run、剔除规则、环境步、根快照数、candidate pairs、重复 rollout、硬件与完整 wall-clock。

## 9. Results 的建议叙述顺序

本节待实验后撰写，顺序固定为：

1. **场景诊断：** 先证明存在非平凡编组空间、对手相关 rank reversal 和可利用的 oracle headroom；
2. **选择偏差：** 展示随机候选可靠性曲线与 selected candidates 曲线的分离；
3. **方法归因：** 逐项证明双边分叉、selector-conditioned 学习和经验保守修正分别改变了什么；
4. **决策价值：** 用真实 rollout oracle 说明预测改进转化为 regret，而非只改善 NLL；
5. **闭环价值：** 最后报告 ID/OOD 最坏成功率、固定边界后的恢复和在线规划代价；
6. **外部有效性：** 以 Open-SMAX-AD 的 decision regret 作为确认量，检验决策结论是否依赖 HAD。

每一小节先给效应量与 CI，再解释机制；不要使用“显著优于所有方法”一类没有对应统计检验的句子。

---

## 10. Discussion

### 10.1 真正的新意

本文的新意不是新的层次系统，也不是 bootstrap 或 LP，而是一个针对规划器误差放大问题的窄接口：**用同态势首宏动作分叉学习双方完整编组结果，在 selector 诱导的分布上独立校准并估计经验保守修正，再用封存 rollout 真值检验这种修正是否真的改善稳健分配。**

如果 E1–E3 均成立，论文可以合理声称：随机候选上的平均准确不足以支撑动态指挥；对准被选候选的可靠性能够减少 false-safe，并在有限对手集上降低真实决策遗憾和任务失败。不能扩展为“解决开放博弈”“保证任意未知对手安全”或“求得动态博弈均衡”。

### 10.2 为什么冻结 S1 反而更科学

冻结执行器、匹配器和 continuation 让 $P(Z_{H_o}=1\mid s,do(x),do(y);\pi_L,H_\psi,\kappa)$ 的标签含义稳定，使结果模型误差、选择偏差和上层收益可以被清楚归因。首篇不追求系统性能上限，而追求一个能被证伪、可在重新采集后迁移到不同执行器的上层可信决策结论。

### 10.3 S4 的未来问题

当执行器在线更新时，能力边界与 selector 分布共同漂移，原校准和经验修正失效。后续工作可研究漂移检测、受约束的上下层交替更新与重新校准；这不是本文未写完的工程模块，而是一个独立的非平稳学习问题。

## 11. Limitations

1. **有限候选支持：** maximin 只覆盖枚举的攻击编组；候选外行为可能利用系统。
2. **没有形式保证：** $c_b$ 是 selector 层内平均低估残差的 cluster-bootstrap 经验修正；它既不保证每个 $(s,x,y)$ 的概率上界，也不保证截断、再次选择后的最终 maximin 决策。
3. **分布依赖：** 经验修正依赖 Bound-Validate 与部署 roll-in 足够相近，以及 selector 与数据版本冻结；OOD 只提供经验压力测试。
4. **单步规划：** 每个宏步滚动求解有限矩阵，不等价于原 POSG 的多步最优或纳什均衡。
5. **信息与时序：** 本文假设双方本步同时行动；不覆盖对手看到本步具体分兵后响应的 Stackelberg 场景。
6. **冻结能力边界：** $\pi_L$ 变化后必须重新采集或处理策略漂移，本文没有解决在线共同适应。
7. **数量抽象：** 上层只决定每组人数，具体实体由固定匹配器分配；高度异质单位下，该抽象可能不足。
8. **仿真外推：** HAD 与 SMAX 扩展仍是仿真环境，不能直接宣称真实作战部署有效或安全。

---

## 12. Conclusion 的最短写法

结论只回收三件事：是否观察到 selection gap、SCORE 是否降低独立 oracle 上的 decision regret、这种下降是否转化为动态闭环最坏成功率。不要在结论中重新引入 S4、对手身份识别、多步世界模型或新的下层策略。

可在真实结果完成后按下列模板填写：

> 本文研究了动态人口多目标防御中，结果模型被上层 selector 使用后产生的可靠性失效。SCORE 通过同态势双边首宏动作分叉、选择器条件结果学习和独立 lineage 经验保守修正，把冻结执行能力映射为可审计的有限收益矩阵，并据此以 MPC 方式滚动求解 maximin 重编组。实验表明 **[填写 selection gap 的真实发现]**，SCORE 相对 **[最强基线]** 将 **[selected false-safe / decision regret]** 改变了 **[真实效应量与 95% CI]**，并在 Opponent-OOD 上将最坏防守成功率改变了 **[真实效应量与 95% CI]**；Open-SMAX-AD 上的 decision regret **[填写真实外部确认结果]**。这些结果支持 **[仅填写证据覆盖到的结论]**；经验修正不提供逐点或最终决策保证，候选外对手与上下层共同适应仍待后续研究。

## 14. 最终贡献声明与一句话价值

### 可以写进论文的贡献声明

1. **问题与诊断：** 提出并实证检验动态对抗重编组中的 selection gap，即随机候选准确不代表被指挥官选中后可靠。
2. **方法：** 提出 SCORE，以同态势双边首宏动作分叉形成可配对的二元结果数据，并以 OOF pilot-focused 拟合和独立 lineage 经验修正处理被选择候选上的乐观误差；最终访问分布仅由封存 Test 审计。
3. **决策与证据：** 将该结果接口嵌入有限候选 maximin 重编组，并用预测、独立 oracle 决策和动态闭环三层证据检验价值。

### 不能写成贡献的内容

层次架构、任务 token、实体注意力、DeepSets、Hungarian、温度缩放、cluster bootstrap、线性规划、可变长度输入、固定周期重规划及 S4 设想，都不能分别宣称为新算法。

### 一句话价值

**本文研究如何让多目标防御指挥官在战损后在线重编组时，少选“预测安全、实则失守”的分兵方案。**
