# 相关工作与研究空白

## 1. 文献地图

本研究横跨五条已有方向。单独落在任何一条里都很难形成新意，必须说明它们为何尚未提供本文所需的可信执行—指挥接口。

### 1.1 可变实体与开放团队执行

- [UPDeT, ICLR 2021](https://openreview.net/pdf?id=v9c7hr9ADKx) 用 Transformer 形成适配不同实体和动作配置的通用 MARL 策略。
- [GPL, ICML 2021](https://proceedings.mlr.press/v139/rahman21a.html) 在队友进入/离开的开放临时团队中用图网络建模他者和联合价值。
- [COPA, ICML 2021](https://proceedings.mlr.press/v139/liu21m.html) 用全局 coach 向动态组成的队伍发送策略，并展示新队伍构成上的零样本泛化。
- [REFIL, ICML 2021](https://proceedings.mlr.press/v139/iqbal21a.html) 用实体注意力和随机子群辅助目标提升不同实体构成下的泛化。
- [FlickerFusion, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/94359ca6e248af69b8b6854668ae9782-Abstract-Conference.html) 已明确研究推理期间实体突然增加/移除，包括动态战斗。

这些工作说明阶段 1 应复用集合/注意力结构；“支持伤亡和增援”“同一网络处理变长实体”不能作为贡献。

### 1.2 分层 commander 与任务分配

- [Carion et al., NeurIPS 2019](https://proceedings.neurips.cc/paper_files/paper/2019/hash/3c3c139bd8467c1587a41081ad78045e-Abstract.html) 学习 agent–task / pairwise score，再由线性或二次优化得到分配。
- [ALMA, NeurIPS 2022](https://proceedings.neurips.cc/paper_files/paper/2022/hash/2f27964513a28d034530bfdd117ea31d-Abstract-Conference.html) 显式学习高层子任务 allocation 和低层 execution，并验证组合泛化。
- [HHMARL air combat](https://arxiv.org/abs/2309.11247) 先预训练 fight/escape 下层，再训练高层 commander。
- [C2 hierarchical opponent modeling](https://doi.org/10.1007/s40747-025-02128-9) 已将空防任务分解为上层分配与下层执行，并做他者建模与交替训练。
- [DT-GAT-MARL, 2026](https://doi.org/10.1038/s41598-026-55576-9) 用动态图 GAT 分配拦截目标、MAPPO 执行，并采用不同更新频率。
- [Dynamic Alliance Operations, 2026](https://doi.org/10.1016/j.ast.2026.113058) 已在 UAV 攻防中做动态联盟和分层决策。

因此，本文不是提出 commander–executor 架构，而是改变两层之间传递的量：从一个未校准的隐式 value，变成由真实下层干预数据验证的多维结果分布。

### 1.3 学习能力、成功概率和 assignment value

- [Engagement Decision Support for BVR Air Combat](https://arxiv.org/abs/2111.03059) 用仿真样本训练 XGBoost 预测交战质量，说明“从战斗前态势监督预测结果”已有直接先例。
- [Fu et al., 2022](https://arxiv.org/abs/2211.03286) 从团队配置—任务表现学习能力和任务需求的线性约束，再嵌入优化分配。
- [Learning the Value of Teamwork, AAAI 2020](https://doi.org/10.1609/aaai.v34i05.6192) 从历史表现预测团队价值并优化组队。
- [Adaptive Bi-Level MRTA, AAMAS 2025](https://www.ifaamas.org/Proceedings/aamas2025/pdfs/p1336.pdf) 根据执行结果更新任务完成概率与置信下界，再做概率约束分配。
- [REDA, AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34852) 先学习 assignment value，再用优化器求大规模分配。

本文的区别不能只靠网络更深，而必须靠数据和评价语义：同快照主动干预多个完整双边编组、重复 rollout 获得分布标签、在上层选择后再检查校准与遗憾。

### 1.4 联盟形成与对抗分兵

[Duan et al., ESWA 2025](https://www.sciencedirect.com/science/article/pii/S0957417425008930) 是最直接的博弈论近邻：它把警用 UAV 与恶意空中目标之间的联盟形成写成队内势博弈与队间竞争，通过迭代 best response 和 fictitious play 求解。它已经覆盖“双方联盟相互影响”和动态目标重分配，但收益来自显式态势优势/威胁建模，不是下层学习执行器在候选编组上的校准结果分布。

所以本文不能声称首次做竞争联盟；Double-IC 必须进入 baseline 或至少进入小规模可比实现。

### 1.5 校准与不确定性

- [On Calibration of Modern Neural Networks, ICML 2017](https://proceedings.mlr.press/v70/guo17a.html) 给出温度缩放等后验校准基线。
- [Deep Ensembles, NeurIPS 2017](https://proceedings.neurips.cc/paper_files/paper/2017/hash/9ef2ed4b7fd2c810847ffa5fa85bce38-Abstract.html) 是实用认知不确定性基线。
- [Set Transformer, ICML 2019](https://proceedings.mlr.press/v97/lee19d.html) 提供集合交互的置换不变建模结构。
- [Conformalized Quantile Regression, NeurIPS 2019](https://proceedings.neurips.cc/paper_files/paper/2019/hash/5103c3584b063c431bd1268e9b5e76fb-Abstract.html) 可作为伤亡/耗时区间基线，但普通交换性保证不能直接外推到自适应 commander 选择和 OOD 对手。

校准方法本身也不是创新；创新假设是：**在组合优化器会主动利用模型高估的场景中，校准和选择后补数据是否能改善真实分兵。**

## 3. 三篇核心参考论文

### 核心 1：ALMA（NeurIPS 2022）——层次骨架与最强复现锚点

- 复用：高层任务分配、低层任务条件化执行、子任务 mask、多军团 StarCraft 场景和 heuristic/COPA baseline。
- 不复用为创新：层次分解、伤亡后再分配、联合训练。
- 本文增加：双方战略性 allocation、回合内双方增援、独立校准战果接口、选择后可靠性。

### 核心 2：Carion et al.（NeurIPS 2019）——最关键结构化学习 baseline

- 复用：learned score + constrained inference 的可扩展思想。
- 必须超越：它已证明从小规模到五倍 agents/tasks 的零样本分配。
- 本文增加：双边完整 partition、战果分布与校准、动态 population 事件、风险而非平均 score。

### 核心 3：Double-IC（ESWA 2025）——最关键对抗联盟 baseline

- 复用：双方联盟相互制约、迭代 best response / fictitious play 的博弈视角。
- 本文增加：手工效用改为冻结下层的干预式经验战果，并评价 OOD 对手、false-safe 和端到端关键点结果。

阶段 2 的直接审稿威胁是 Fu 2022 与 AAMAS 2025 bi-level MRTA，必须在 Related Work 和结果模型 baseline 中显式回应。

## 4. 精确研究空白

本文不说“没人做过动态分组”，而说：

> 现有层次 MARL 多用隐式 value 或端到端回报学习 allocation；结构化分配和竞争联盟方法又依赖 learned score 或手工效用。对于双方兵力在 episode 内变化的多线对抗，仍缺少证据表明：由固定下层真实执行干预得到的、经校准的完整编组结果分布，能否作为一个可审计接口，减少上层在未见兵力和对手下的危险高估，并改善最终任务结果。

这是一条可证伪的经验研究空白，而不是未经系统综述证明的“世界首次”。

## 5. 检索边界

本轮检索截至 2026-08-27，覆盖 NeurIPS、ICML、ICLR、AAAI、AAMAS、IEEE/Elsevier/Springer 相关论文、官方项目页和代码仓库。投稿前仍需用 Web of Science / Scopus / Google Scholar 对以下组合做一次更新检索：

- calibrated outcome model + adversarial task allocation；
- execution-aware coalition value + dynamic combat；
- open-population competitive Markov game + hierarchical allocation；
- counterfactual assignment outcome + multi-agent。

若出现同时覆盖完整交集的新工作，应把贡献进一步收缩到数据协议、选择后校准或 optimizer-aware 数据聚合，而不是忽略它。
