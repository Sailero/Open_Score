# 工作量、论文档位与收缩边界

## 1. 当前判断

收缩到局部最多4v4、S2小MLP、S3小型LP后，方法比上一版清楚很多，但完整S1–S4仍不是1–2个月可完成的工作。其论文水准取决于是否击败端到端和ALMA-style强baseline，而不是阶段数量。

## 2. 工作量估计

| 工作包 | 人日 | 最小交付 | 最大风险 |
|---|---:|---|---|
| S1 HAD QMIX | 15–24 | 双边训练、16规模、3 seeds | 环境吞吐/探索 |
| S1 PSRO | 10–18 | payoff、BR、3–8轮 | 近似BR不稳定 |
| Open-HAD复现接口 | 10–18 | 私有PRNG、clone、测试 | 改变旧环境语义 |
| S2 | 12–20 | 数据集、MLP ensemble、校准 | root数据泄漏 |
| S3 | 15–25 | 候选、匹配、LP、闭环 | 局部风险不等于全局价值 |
| S4 | 20–35 | residual、交替更新、guard | 非平稳/重复采样 |
| SMAClite-AD | 15–25 | 双边API、目标、关键复验 | C++/Gym兼容 |
| 正式实验与论文 | 22–35 | 5 seeds、统计、复现包 | baseline重跑 |

总计约119–200人日。单人约7–12个月；两人存在串行依赖，约4–7个月。

## 3. 近期可执行周期

S1的合理周期是5–8周：

| 周 | 代码 | 实验 | 决策门 |
|---|---|---|---|
| W1 | 双边runner、buffer | 随机动作/吞吐 | 环境语义正确 |
| W2 | sequence QMIX | 1v1、2v2过拟合 | 双方都能学习 |
| W3 | 多规模factory | 插值协议 | 同一网络跨规模 |
| W4 | baseline/evaluation | 16格胜率矩阵 | 最坏表现可接受 |
| W5 | payoff evaluator | self-play vs population | 是否启用PSRO |
| W6–7 | PSRO 3轮pilot | NashConv/BR曲线 | 是否扩大到8轮 |
| W8缓冲 | 性能与失败seed | 最终S1报告 | 继续或停止 |

用户最初的1–2个月目标可以完成S1及PSRO pilot，不能承诺四阶段论文投稿。

## 4. 论文档位

| 完成范围 | 可能形态 | 合理档位 | 主要缺口 |
|---|---|---|---|
| S1 HAD | 技术报告/预实验 | 不足Q2 | QMIX+PSRO新意有限 |
| S1–S3 HAD | 可解释开放分组 | Q2候选 | 单一自建环境 |
| S1–S4 HAD | 完整共同适应 | 强Q2候选 | 外部有效性 |
| 双环境且胜过端到端 | 统一系统论文 | 强Q2/弱Q1边缘 | 理论保证有限 |

如果S4不能稳定提高最终胜率，最诚实的论文范围是S1–S3；如果S3的显式博弈也不如高层MAPPO，则需要重新定位为“可解释性/稳健性换取部分峰值性能”，不能继续声称性能改进。

## 5. 一篇还是两篇

首选仍是一篇统一论文，因为四阶段共同回答“局部能力如何组成开放人口下的全局博弈”。但可按失败模式拆分：

- 论文A：S1–S3，局部能力预测驱动的稳健分组；
- 论文B：策略种群变化下的能力—指挥共同适应。

不建议单独发表“S1 = QMIX + PSRO”，除非发现新的跨规模种群训练机制或形成公开benchmark。

## 6. 投稿方向

期刊分区每年变化，投稿时必须重新核对JCR/中科院和单位口径。方法如果以多智能体系统为主可考虑 JAAMAS；偏算法与复现可考虑 Applied Intelligence；偏工程仿真可考虑 Engineering Applications of Artificial Intelligence。不能用当前文档保证具体分区或审稿速度。
