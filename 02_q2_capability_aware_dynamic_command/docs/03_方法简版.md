# SCORE 方法简版：选择校准结果模型引导的重编组

> 推荐名称：**SCORE (Selection-Calibrated Outcome-guided REallocation)**
> 本文贡献边界：**把双边动态编组中的选择失效定义为可证伪问题，提出配对干预数据协议，并建立从随机候选误差到选中假安全与决策遗憾的完整证据闭环。**校准、pairwise ranking、maximin 与线性规划均为标准组件，不单独称为创新。S1 是冻结的任务条件执行器；S4 联合优化不属于本文算法，只在文末作为第二篇工作方向。

## 1. 一句话方法

**在同一战场态势上配对试验敌我双方首个控制周期的不同编组，用统一 continuation 生成结果标签并审计规划器搜索造成的假安全，再以经验保守分数和 maximin 在线选择较不易被有限对手候选针对的重编组。**

## 2. 论文场景与研究问题

本文聚焦一个具体而有限的问题：在多目标点攻防中，双方单位会因战损而持续变化；防守指挥官每隔固定控制周期 $H_c$，需要把当前仍存活的单位重新分到若干目标点任务中，而攻击方也可能集中、均分或转移兵力。伤亡会立即改变存活状态和可行动作，但不触发周期外的上层决策；增援若用于 OOD 测试，也只在周期边界激活。下层智能体只负责执行已分配的任务，上层真正困难的是：**在不知道对方本周期会从预注册候选集中选择哪种编组、又不能在线穷举仿真的情况下，如何判断哪种己方编组在经验上更稳健？**

设宏决策时刻的指挥态势为 $s$，防守方数量编组为 $x\in\mathcal X(s)$，攻击方可能编组为 $y\in\mathcal Y(s)$。冻结的下层执行器记作 $\pi_L$。候选编组先执行一个控制周期 $H_c$；若评估尚未终止，双方随后都使用固定、版本化且方法无关的 continuation rule $\kappa$，直到结果窗口 $H_o=K_oH_c$（默认 $K_o=3$）。本文要近似并利用的是

$$
P(Z_{H_o}=1\mid do(x),do(y),s;\pi_L,\kappa),
$$

其中 $Z_{H_o}=1$ 表示 $H_o$ 内任一目标失守。它比较的是同一态势下双方**首个宏动作**改变后、在共同 continuation 下的滚动时域任务风险；同快照克隆的主要价值是密集覆盖、公平配对和方差缩减，并不是声称其他有完整随机探索支持的数据都无法识别动作效应。

为使主张可验证，首篇论文采用以下最小范围：

- 只研究**上层数量分配**，例如 $x=(2,3,1)$ 表示三个任务分别分到多少单位；
- 具体“哪一个单位去哪个任务”由固定的 Hungarian 匹配器完成，所有方法共用；
- 单位变化以战损造成的数量减少为主；增援可作为扩展测试，不是首篇成立的必要条件；
- 每次只求首个宏步的博弈并滚动重规划，不做多步博弈树；$H_o$ 只提供固定 terminal evaluation；
- 宏步采用同时行动语义：双方可知道历史与对方策略分布，但在本步决策时看不到对方刚采样的具体编组；
- “未知对手”仅指：在双方冻结、版本化的下层策略和固定实体匹配器下，对手当前宏观分配不可见，但其响应被限制在预注册的有限 allocator 候选集；本文不覆盖测试时突然出现的新下层策略、隐藏性格或无限策略空间；
- 主文以防守方为行玩家叙述，交换效用方向后同样可用于攻击方。

## 3. 方法总览

```text
冻结任务执行器 πL
       │
       ▼
同一快照配对 rollout：首个 Hc 施加 x,y，随后统一 κ 延续到 Ho
       │                         S2
       ▼
Ho 窗口二元失守模型 ── 选择器条件的交叉拟合、校准与排序
       │
       ▼
lineage 隔离验证集给出 selector-aware 经验保守修正
（cluster bootstrap；无逐点或最终决策保证）
       │
       ▼
小型悲观收益矩阵 ── maximin/零和 LP ── 数量重编组 x*
                                                │      S3
                                                ▼
                              Hungarian 实体匹配 + πL 执行
```

这个流程只有一条逻辑：**先审计并减少候选搜索放大的假安全，再对预注册的有限对手候选作决策**。结果模型、校准和求解器都服务于同一个上层重编组问题，而不是四个并列创新模块。

## 4. S1：冻结的任务条件执行器（研究条件，不是创新）

下层策略 $\pi_L(a_i\mid o_i,\tau_i)$ 接收局部观测 $o_i$ 与任务令牌 $\tau_i$，完成接近目标、拦截、集火或守点等动作。它可以来自 ALMA/UPDeT/MAPPO 的已有实现，也可以先用稳定脚本实现。训练结束后必须冻结，因为 S2 所学的是**该执行器在不同编组下的能力边界**；若下层继续变化，结果模型的标签含义也随之变化。

本文不声称提出新的下层策略，也不把“可变数量输入”作为创新。实验只需证明：同一个 $\pi_L$ 能接收不同队友数、对手数和任务令牌，并且性能没有差到掩盖上层分配差异。

## 5. S2：选择器校准的双边干预结果模型

### 5.1 同态势双边编组干预

对每个训练快照 $s_g$，生成规模受控的防守候选 $\mathcal X_g$ 与攻击候选 $\mathcal Y_g$。环境恢复到同一个快照，依次施加每个 $(x_i,y_j)$，冻结 $\pi_L$ 先执行 $H_c$ 步，再由双方共享的固定 $\kappa$ 接管后续宏分配直至 $H_o=K_oH_c$，并记录任务结果。相同重复编号在所有候选对上使用同一组外生随机数，以减少候选排序的方差。

主结果只定义为

$$
Z_{H_o}\in\{0,1\},
$$

其中 0 表示结果窗口内所有目标仍存活，1 表示任一目标失守。模型直接输出

$$
\hat p_{ij}=P_\phi(Z_{H_o}=1\mid s_g,x_i,y_j;\kappa).
$$

直接预测“任一目标失守”，可避免把各目标点错误地假设为相互独立，也消除了同一步多个目标失守时“谁先”的标签歧义。首个失守目标、战损或剩余耐久只作数据诊断，不增加预测头，也不进入 S3。在线只执行首个 $H_c$，随后以新态势重新规划；这是带固定 terminal evaluation 的滚动时域决策，而不是承诺执行完整 $H_o$。

### 5.2 为什么要在选择器诱导的分布上训练与校准

规划器不会均匀使用所有候选。它总会反复比较少量“预测最好”“接近决策边界”或“可能是最坏响应”的候选；即使模型在全数据上平均准确，这些被极值选择出来的候选仍可能系统性乐观。

SCORE 采用分组交叉拟合：同一原始对局及其所有克隆干预永远属于同一组；每个折外模型在未见过的组上预测，再由一个冻结的试探性 selector 标记均衡支撑、最坏响应与近边界候选。由此得到的 OOF 权重用于两件事：

1. 用严格 proper 的分布损失学习结果概率，同时对同一快照内的重要候选增加轻量 pairwise ranking 损失；
2. 在独立校准组上，只针对冻结的 pilot selector 重点访问的候选分布拟合一个简单的温度校准器。

所有候选仍保留一个非零的均匀采样权重，以免模型只会预测当前 selector 已经喜欢的动作。

最终结果模型只在 Fit-base 上用 OOF 权重从头训练一次，不把 pilot 访问到的新状态回流训练。模型和 pilot 冻结后，再以预注册的“基础 mixture + pilot”分别采集互不重叠的 Selector-Cal 与 Bound-Validate root lineages；最终 SCORE 的状态访问只在封存 Test 审计。因而 pilot-focused distribution 只是开发期代理，不被称为已知的实际部署分布。

### 5.3 Selector-aware 经验保守修正

校准器和 selector 冻结后，在另一份从未参与训练或调参的 Bound-Validate 数据上计算“真实失守率减预测失守率”的 lineage 组级残差。将候选按 selector 角色分成至多三个预先固定的层，例如核心支撑、近边界和背景候选；对每一层用预注册的 lineage-cluster bootstrap 均值上尾经验分位数得到经验修正量 $c_b$：

$$
p^+_{ij}=\operatorname{clip}\big(\hat p^{\mathrm{cal}}_{ij}+c_{b(i,j)},0,1\big).
$$

$p^+_{ij}$ 是 S3 使用的保守风险分数。这里的统计含义必须诚实限定为：它修正的是与 Bound-Validate 相近的 roll-in 分布中、selector 同一层候选的**平均低估风险**；cluster bootstrap 是经验性有限样本近似，截断和再次选择后没有逐点或最终决策保证。价值只能由独立 Test 上的 selected false-safe 与 regret 下降证明。

> 深度集成的均值与标准差可以帮助诊断或主动采样，但 $\bar p+\beta\sigma$ 本身不是有限样本统计保证，不能作为本文“风险修正”的定义。

## 6. S3：保守风险分数驱动的小型 maximin 重编组

### 6.1 候选保持小而可解释

每个宏步根据当前存活单位数重新生成数量向量。Day-0 小规模 oracle 枚举全部整数拆分；主训练/部署使用固定比例网格，并补入均分、集中、延续上一编组和威胁比例等模板，冻结为 $|\mathcal X|\le16$、$|\mathcal Y|\le8$ 的完整小矩阵。这样每个训练快照可采满全部候选对，避免“方法假设完整矩阵、数据却只有稀疏单元”的不一致。

对每个数量候选，用 Hungarian 算法把实体匹配到带容量的任务槽位。匹配代价只包含距离/到达时间、任务适配和换组代价，规则在训练前固定，且所有基线共用。这样论文研究的是“每组分多少”，不会被实体级组合爆炸拖垮。

### 6.2 构造收益矩阵

将所有候选对一次批量送入 S2。对防守方，最小版矩阵单元只使用整体失守风险：

$$
A_{ij}=1-2p^+_{ij}.
$$

它把不失守与失守分别映射到接近 $+1$ 与 $-1$，无需再叠加战损、距离等多个人工奖励。若要限制频繁换组，优先把最大换组数量写成候选可行性约束，而不是再增加一个可调奖励项。

### 6.3 求解并执行

防守方求解单步零和矩阵博弈

$$
\max_{\mu\in\Delta(\mathcal X)}\min_{j}\sum_i\mu_iA_{ij},
$$

得到混合编组策略 $\mu^*$。部署时从 $\mu^*$ 采样一个数量方案，用 Hungarian 得到实体指派，交给冻结的 $\pi_L$ 执行 $H_c$ 步，随后依据新的存活单位与态势重新求解；$\kappa$ 只用于离线 outcome 标签，不会替代在线重规划。混合策略使对手不能长期利用一个固定的确定性分兵规律；若应用必须确定性执行，应把取最大概率动作作为单独变体报告，而不能沿用混合策略的稳健性表述。

SCORE 不宣称在原始动态博弈中求得纳什均衡。它只是在每个决策时刻，对有限候选集与经验修正后的近似收益矩阵求一个单步 maximin 策略。

若任务实际是“攻击方先看见防守方本步具体分兵，再选择攻击编组”的严格先后手博弈，应改用 Stackelberg 求解并重新定义实验时序；不能把同时行动 maximin 的结论直接搬过去。

## 7. 论文贡献边界在哪里

| 组成 | 本文定位 | 必要证据 |
|---|---|---|
| 双边动态编组的选择失效 | 可证伪的核心研究问题 | 随机候选与选中候选之间存在稳定 selection gap |
| 配对干预数据协议 | 首个 $H_c$ 只改变 $(x,y)$，统一 $\kappa$ 生成 $H_o$ 标签；不主张个体反事实或逐点因果保证 | 取消 CRN 配对、改单边/自然日志的数据协议审计 |
| 校准、ranking、经验修正、maximin/LP | 服务主问题的标准组件，不分别称创新 | 等预算组件消融与强基线比较 |
| 完整证据闭环 | lineage 隔离的 Fit / Selector-Cal / Validate / Test 与选择后审计 | selected false-safe、decision regret 和跨动力学复核 |

论文贡献不是“结果模型 + LP”这一表面拼接，也不是重新发明校准或 maximin，而是把一个通用失效机制在双边动态编组中操作化：**结果模型一旦被规划器用于极值选择，其误差分布可能偏离随机测试误差；配对数据协议和独立审计闭环用于检验并减少这种偏差。**

## 8. 首篇论文的最小闭环

首篇只需完成以下闭环便是一篇自洽的论文：

1. 一个冻结且可接受任务令牌的下层执行器；
2. 一个可精确恢复快照并对双方编组做干预的环境；
3. SCORE 的双边结果模型、pilot-focused 拟合、独立经验修正与 maximin 求解；
4. 在固定下层策略、固定实体匹配器与预注册有限 allocator 候选集内，检验它在未见规模或未见宏观分配上，是否比均分/启发式、点估计 argmax、单边模型、普通全局校准及同预算在线 rollout 获得更低 decision regret 和更好的经验最坏响应收益。

不需要在首篇加入新的下层 MARL 算法、对手策略识别、PSRO 自动扩库、多步搜索或上下层联合训练。这些内容会分散主线，且其中任何一项都足以形成后续论文。

## 9. S4 的唯一定位：第二篇工作

当 $\pi_L$ 更新后，S2 的能力边界会漂移；怎样让下层能力、结果模型和上层 selector 共同适应，是一个独立的非平稳闭环问题。它可以形成第二篇论文，例如研究 planner-induced distribution 下的安全协同更新与漂移检测。**本篇算法、伪代码、主实验和贡献列表中均不出现 S4。**

## 10. 论文式贡献表述

可以将方法贡献压缩为两点：

1. 提出一种双边动态编组的选择失效问题及配对干预数据协议，并通过 lineage 分组交叉拟合，使结果模型的排序与校准对准冻结 selector 重点访问的候选分布；
2. 建立独立选择后审计与 selector-aware 经验保守修正驱动的在线 maximin 闭环，旨在固定下层策略和预注册有限 allocator 候选集内降低选中假安全与决策遗憾；该目标仍需实验验证，不包含逐点风险界或最终决策保证。

**最短价值句**：本文研究如何让多目标防御指挥官在战损后在线重编组时，少选“预测安全、实则失守”的分兵方案。
