# 研究结论与阅读路线

## 1. 最终判断

这个问题有真实价值，但 Claude 版“COGAR 四阶段全部作为创新”的写法不成立。ALMA 已联合学习上层分配和下层执行，近期 DT-GAT-MARL 已覆盖动态节点、分层分配和端到端控制，C2 工作也已采用指挥层/执行层交替冻结再联合训练。因此，**层次架构、动态分兵、结果预测、校准、minimax 和联合优化单独都不能再宣称新颖**。

首篇论文应只回答一个问题：

> 当指挥官会从多个有限候选编组中挑选“预测最好”的一个时，如何避免结果模型的误差被选择过程和对手共同放大，并把经独立审计的预测转化为低遗憾的在线重编组？

核心是定义并验证一种面向双边动态编组的**选择失效问题**：用同态势配对干预数据学习双边结果，对准冻结 pilot 关注的候选拟合与校准，再用独立数据审计最终被选方案，检验这些改善能否转化为低遗憾决策。校准、ranking 和 maximin/LP 都是标准组件，不单独构成创新。

## 2. 一句话与价值

**一句话：本文研究如何让多目标防御指挥官在战损后在线重编组时，少选“预测安全、实则失守”的分兵方案。**

真正价值不是多做一次分组，而是检验并减少一种可能存在的系统性失败：模型在全体候选上平均很准，却因指挥官总挑极值而对最终选中的编组过度乐观，随后被对手利用。论文若能显著降低这类 **false-safe**（高置信判断安全、实际任务失败）和相对真实 rollout oracle 的决策遗憾，就证明了解决方案有用；否则即使平均 Brier/NLL 很好也不算成功。

## 3. 从 Claude 版保留与删除什么

| 内容 | 处理 | 原因 |
|---|---|---|
| 多目标最弱环节攻防 | 保留 | 场景清楚，且 HAD 的“任一目标失守即负”与之吻合 |
| 同态势双边干预数据 | 保留并收紧 | 用于密集覆盖双边候选、配对比较并降低排序方差；不声称是唯一因果识别手段 |
| 选择失效与决策遗憾 | 升为核心 | 直接检验普通预测器为何会被规划器的极值选择放大误差 |
| Deep ensemble、温度缩放、LP | 降为可替换组件 | 都是已有技术，不能占据创新叙事 |
| S1 通用执行器 | 冻结底座 | 可复用 REFIL/UPDeT/MAPPO；不做新网络 |
| S4 联合优化 | 移出首篇 | 直接近邻多、非平稳风险大，足以单独成文 |
| 另造 GuardPoints | 删除 | 已有自有 HAD；重复造环境会浪费时间并削弱可比性 |
| 假想主结果表 | 删除 | 没有实验就不应给出看似真实的均值和方差 |

## 4. 单篇论文的最小闭环

1. 在 Open-HAD 中冻结一个任务条件下层执行器，并证明不同分配确实产生不同结果。
2. 从同一宏观快照分叉出多个双方编组：候选只承诺首个控制周期 $H_c$，随后由固定、版本化且方法无关的 continuation $κ$ 执行到结果窗口 $H_o=K_oH_c$，默认 $K_o=3$。
3. 学习双方**完整分区**条件下 $H_o$ 内“任一目标是否失守”的二元概率：Fit-base 只对冻结 OOF pilot 关注区域加权拟合；模型冻结后，独立 Selector-Cal / Bound-Validate 分别完成校准与经验修正，最终被选方案只在 sealed Test 审计。
4. 用保守风险分数填充一个小型双方收益矩阵，求标准 maximin，在线只执行首个 $H_c$ 后便以新态势重新规划。
5. 在新人数、新伤亡/增援时刻和未见场景上检验 false-safe、选择遗憾、最坏对手收益和闭环成功率。

第 1 步是研究条件，第 2–4 步共同构成面向双边动态编组的数据—决策协议，第 5 步构成完整证据闭环；其中任一标准校准器、ranking loss 或 LP 都不单独算创新。

## 5. 档位判断

| 完成度 | 合理判断 | 仍缺什么 |
|---|---|---|
| 单环境、弱基线、只报胜率 | 普通应用稿或二区不稳 | 标准环境、选择后可靠性、决策 oracle |
| Open-HAD + Open-SMAX-AD、强基线、完整三层证据 | 有竞争力的二区 | 仍以经验贡献为主 |
| 再加选择后风险理论、真实在线漂移、稳定联合适应 | 强二区/一区或强会议规模 | 需要独立的理论与大量额外实验 |

工作量大小本身不决定分区。首篇的关键不是做满四阶段，而是让“干预数据 → 选择后失真受控 → 低遗憾决策 → 任务收益”四个箭头都有独立证据。
