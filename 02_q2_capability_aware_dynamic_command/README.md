# SCORE：动态攻防中的选择后结果预测与在线重编组

> **一句话：本文研究如何让多目标防御指挥官在战损后在线重编组时，少选“预测安全、实则失守”的分兵方案。**

本目录是近期单篇论文的研究规格，不是已经完成的系统。论文暂称 **SCORE**（Selection-Calibrated Outcome-guided REallocation，选择校准结果模型引导的重编组）。原四阶段 COGAR 设想被收缩为一条可证伪的证据链：

```text
同态势双边候选执行首个 H_c → 版本化 κ 延续至 H_o=K_oH_c → pilot-focused 失守预测与经验修正 → 有限候选 maximin → 在线只执行 H_c 后重规划
```

下层任务条件执行器是冻结的实验底座，不作为首篇创新；上下层联合优化不进入首篇主方法，保留为后续论文问题。动态“分组”在本文中严格称为**任务分配/编组**：分到同一目标的单位自然形成子群，不额外设计聚类模块。

## 环境结论

- **主环境：Open-HAD。** 从仓库根目录的自有 `HAD_Env` 适配，只保留打击智能体和多目标点；原始代码在 Git 提交 `abadfcc` 中完整备份。
- **辅环境：Open-SMAX-AD。** 这是基于 SMAX 的 scoped 新资产防御任务扩展，用纯 JAX、显式随机键和双边动作验证方法不是 HAD 特例；它不是现成标准 benchmark。
- **ALMA：复现锚点与 AQL 分配基线。** ALMA 的 `sc2multiarmy` 已是“多支敌军周期性进攻/撤退”的修改版 SMAC，但它是单侧学习、脚本敌方且不能直接状态分叉，因此不作为首篇数据主环境。

主实验以局内伤亡导致的规模缩减为主；环境接口同时支持预先登记的增援事件，增援只作为 OOD 压力测试。这样保留开放人口动机，又不把首篇扩成环境项目。

## 当前状态

本轮交付的是经调研后的研究定义、方法规格、实验协议和论文框架；**尚未实现** Open-HAD 适配器、SCORE 模型、ALMA-AQL 移植或实验结果。文档中的数值均只能是预算、目标阈值或待检验假设，不得在论文中写成实验事实。
