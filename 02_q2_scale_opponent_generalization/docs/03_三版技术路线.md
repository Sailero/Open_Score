# 三版技术路线（重定位后，对应论文第 4 章）

## 0. 共同问题与底座

三条路线均研究同一问题：在团队对抗回合中，阵容 `c_t` 与潜在策略 `p_t` 可以独立变化；对手表示应响应真正策略变化，但不应把战损/增援本身当作策略切换。

共同使用 HPN 风格 backbone：共享实体编码、对称输入聚合、敌方目标等变打分和 CTDE。HPN 负责“集合长度与顺序”，不负责识别对手策略。

现有通用 OC-HPN 统一编码敌方集合摘要：

`m_t = ρ([mean(r_j^t), max(r_j^t), ψ(log(1+M_t))])`，`z_t = GRU(m_t,z_{t-1})`。

它保留为关键基线。由于 `z_t` 同时接收人数、状态分布和行为变化，却没有相应识别约束，它可能混淆阵容与策略。

## 路线 A：CDOC-HPN（推荐，主论文路线）

### A.1 核心思想

把对手上下文拆成两个有不同职责的变量：

- `c_t`：**阵容上下文**，表示敌方人数、类型比例、健康/存活摘要和即时威胁；允许随减员/增援快速变化；
- `z_t`：**条件行为上下文**，表示对手在给定状态与阵容下如何行动；策略变化检测只读取 `z_t`。

阵容分支：

`c_t = f_c(log(1+M_t), type_hist_t, health_summary_t, threat_summary_t)`。

行为分支对每个敌人编码状态条件动作或状态转移：

`b_j^t = φ_b(e_j^t, a_j^t)`，若动作不可见则使用 `φ_b(e_j^t, Δe_j^t, attack_event_j^t)`；

`b_t = ρ_b(masked_mean_j b_j^t)`，`z_t = GRU_b(b_t,z_{t-1})`。

策略网络使用 `[h_i^t,c_t,z_t]` 的门控 FiLM 条件化；变化分数 `d_t` 只由 `z_t` 与历史行为中心的距离计算。

### A.2 训练目标

`L = L_RL + λ_pred L_pred + λ_inv L_inv + λ_sep L_sep`。

- `L_pred`：在当前状态条件下预测敌方动作/下一位移；
- `L_inv`：同一训练策略在成对阵容干预下的 `z` 接近；
- `L_sep`：匹配阵容条件下，不同训练策略的 `z` 至少保持 margin；
- RL 损失负责把更正确的表示转化为有价值的反制动作。

训练时脚本名或 checkpoint ID 只用于构造正负对，不输入 actor；测试时无 ID、无梯度更新。对不完全状态匹配的样本使用软权重，避免强迫同一策略在完全不同战局中表示一致。

### A.3 创新和价值为何成立

创新不在 GRU/FiLM，而在：

1. 把阵容变化对策略识别的污染定义为独立、可测的失败模式；
2. 用 `C×S` 独立干预及误报/延迟/遗憾评估，而不是只看胜率；
3. 对状态条件行为而非原始敌群轨迹施加跨阵容不变性；
4. 用轻量线性集合模型修复，不复刻复杂世界模型。

### A.4 风险

- 同一策略在不同兵力下可能合理地产生不同动作：只对状态匹配的条件行为残差做软不变性；
- 行为不可直接观测：使用相邻帧位移、攻击事件和目标接近率，并明确这是近似；
- 分离改善但胜率不变：若切换后遗憾也不改善，不能作为方法论文投稿；
- 脚本太容易：构造具有单帧状态重叠、延迟显现和回合内切换的策略族。

## 路线 B：条件动作残差 + 经典变化检测（低风险保底）

### B.1 方法

不学习复杂解耦 latent。先训练一个条件动作预测器：

`p(a_j^t | e_j^t, c_t)`。

每步对可见敌人的负对数似然或位移预测误差取 masked mean，得到人数归一化残差 `r_t`。对 `r_t` 使用 ADWIN、Bayesian change-point detection 或简单 CUSUM；检测到变化后，通过一个小型 mixture-of-experts 门控选择反制头。

### B.2 优势与限制

- 优势：可解释、实现快，能直接报告误报与检测延迟；
- 限制：只检测“模型不再解释行为”，未必能形成连续、可泛化的策略表示；
- 定位：若 CDOC 联合训练不稳定，路线 B 可形成偏检测/诊断的 Q2 论文，但胜率上限较低。

## 路线 C：干预式评测基准 + 多模型审计（无新策略网络）

### C.1 方法

把论文转成实证审计：固定 HPN、OC-HPN、OM-TCN/TAO 风格编码器和可能的公开对手模型，在同一 `C0S0/C1S0/C0S1/C1S1` 协议上比较：

- latent 对规模的可预测性与对策略的可预测性；
- composition-only 误报；
- strategy-only 检测延迟；
- 变化后决策遗憾。

提供事件生成器、固定 train/test opponent manifests、指标实现和复现实验脚本。可加入一个极简 residual normalization 修复作为建议，而不声称新算法。

### C.2 何时采用

若多个强基线都表现出混淆，但 CDOC 没有稳定决策增益，路线 C 比堆叠更多网络更诚实。它要求评测覆盖足够广、代码开源和统计严谨，期刊选择也应偏实证/基准类。

## 4. 路线选择矩阵

| 维度 | A CDOC-HPN | B 残差检测 | C 评测审计 |
|---|---:|---:|---:|
| 代码工作量 | 中 | 低 | 中 |
| 方法创新 | **中高** | 中 | 低至中 |
| 问题价值 | **高** | 高 | 高 |
| 决策收益潜力 | **高** | 中 | 不保证 |
| 可解释性 | 中高 | **高** | **高** |
| 8 周完成概率 | 高 | **最高** | 中高 |
| 与 2026 复杂世界模型区分 | **清楚** | 清楚 | 清楚 |

**最终建议**：先做路线 C 中的 P0 审计证明问题存在；通过后实现路线 A。路线 B 只在联合训练不稳定时接管。三条路线不是同时写成三项贡献，而是按证据门逐级选择。
