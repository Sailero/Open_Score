# 项目定位与删减决策（第二次冻结）

**冻结日期**：2026-08-27  
**目标**：8 周内形成一篇可投稿的 JCR Q2 期刊论文  
**推荐题目**：*Do Opponent Models Mistake Attrition for Strategy Change? Composition-Disentangled Online Adaptation in Team-Competitive MARL*

## 1. 最终研究问题

> 在团队对抗博弈中，阵容会因战损、增援、类型比例和可见性而变化，对手也可能在回合内换策略。现有时序对手表示是否会把阵容变化误判成策略变化？能否用阵容—行为分支表示与成对干预训练，得到对阵容变化低敏感、对策略变化高敏感的在线上下文，并改善无梯度适应？

一句话：

> **我们提出规模—策略解耦的在线对手建模，让团队智能体从减员/增援轨迹中分清“敌人变少了”和“敌人换打法了”，从而在无需微调时减少误判并更快适应未见策略。**

## 2. 为什么必须再次收缩

上一版“规模 OOD × 对手 OOD + OC-HPN”仍然太泛，并且方法新颖性不足。HPN 已处理 PI/PE 与变长实体；TAO/OEOM 已处理轨迹上下文和未见对手；OM-TCN、Bayes-OKR 等已处理动态或回合内切换；2026 年 HyperJD2TSSM 还联合处理变化人数、动态意图和策略。继续声称“同时处理规模和策略”会被最近邻直接覆盖。

重定位后的差异不是再增加一种联合模型，而是指出一个具体识别故障：**观测集合的阵容变化与潜在策略变化在普通时序编码器中混在一起**。论文用独立干预协议先证明故障，再用最小方法修复。

完整证据与边界见 `06_研究价值与创新性复核.md`。

## 3. 冻结后的贡献

论文只承诺三点：

1. **诊断问题**：定义“阵容变化—策略变化混淆”，构造 `C0S0/C1S0/C0S1/C1S1` 四类回合内事件，并报告策略误报率、检测 AUROC/延迟和切换后遗憾；
2. **轻量方法**：提出 CDOC-HPN，将即时阵容上下文与规模归一化的条件行为上下文分开，用同策略跨阵容不变性和异策略同阵容分离损失训练；
3. **决策证据**：在公开 MAgent2 Battle 和受控 SwarmBattle 中，验证表示改善是否转化为更少误响应、更快真实切换适应和可接受的计算开销。

## 4. 保留、降级与删除

| 元素 | 处理 | 理由 |
|---|---|---|
| HPN 风格 PI 输入/PE 目标动作 | 保留为 backbone | 解决变长集合的结构合法性，不冒充新贡献 |
| 现有 OC-HPN | 降为关键基线 | 通用 set-GRU 上下文正是要诊断的对象 |
| 阵容/行为双分支 | 新主方法 | 直接对应混淆问题 |
| 成对阵容干预损失 | 新主方法 | 给“同策略、不同阵容”明确训练约束 |
| 四象限规模 ID/OOD × 对手 ID/OOD | 降为补充评估 | 保留外推结果，但不再是论文唯一核心 |
| 回合内减员/增援 | 升为主实验变量 | 用于构造 composition-only 事件 |
| 动态分组、层次指挥 | 删除 | 与核心识别问题无关且增加风险 |
| league/PSRO/开放种群 | 删除 | 训练分布方法会混淆表示贡献且成本高 |
| 大 Transformer/世界模型 | 删除 | 最近邻已很强，本项目强调轻量诊断修复 |
| 理论泛化界 | 删除 | 8 周内难以给出可信可识别性理论 |
| MAgent2 Battle | 公开主环境 | 自然战损与大规模双队对抗 |
| SwarmBattle | 受控诊断环境 | 可精确操纵阵容与策略事件 |

## 5. 四个研究问题

- **RQ1：问题是否存在？** 通用 OC-HPN 的 latent 是否在仅阵容变化时产生虚假策略切换信号？
- **RQ2：表示是否更正确？** CDOC 是否降低 `C1S0` 误报，同时保持 `C0S1` 检测 AUROC 和延迟？
- **RQ3：是否有决策价值？** 表示改善是否降低切换后遗憾并提高最差未见对手胜率？
- **RQ4：代价是否合理？** 参数量是否与实体数无关、计算是否线性、延迟增量是否低于 20%？

## 6. 不允许写进摘要的内容

- “首次处理动态人数和动态策略”；
- “任意规模/任意对手”；
- “因果解耦”或“理解对手意图”，除非补充正式假设与证明；
- 只依据 latent probe 而没有决策结果声称方法有效；
- 在五个独立训练种子完成前写“significantly outperforms”；
- 把现有 OC-HPN 单元测试称为 CDOC 实验结果。

## 7. Go / No-Go

### 第一周 P0：问题门

冻结 HPN/OC-HPN，在四类事件上测 latent change。若 `C1S0` 相比 `C0S0` 没有至少 15 pp 的误报增长，且 change score 与阵容变化幅度的 `|Spearman ρ| < 0.3`，停止 CDOC 主线。

### 第二至三周 P1：方法门

继续完整实验的最低条件：

- CDOC 相比 OC-HPN 的 `FPR_comp` 相对降低至少 30%；
- 策略切换 AUROC 下降不超过 0.02；
- `C1S1` 的切换后遗憾降低至少 15%；
- 训练域胜率下降不超过 3 pp；
- 推理延迟增加不超过 20%。

不达标时依次检查条件行为特征、配对数据质量和损失权重；不得重新加回 SAGA 全套模块“救结果”。
