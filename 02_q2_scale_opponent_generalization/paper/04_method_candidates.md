# 4. Method

Sections 4.1--4.5 define the recommended CDOC-HPN route. Section 4.6 records fallbacks and should not appear as an additional contribution in the submitted paper.

## 4.1 HPN-style policy backbone

Each controlled agent encodes self features and variable ally/opponent entity sets. A shared hypernetwork transforms individual entities and a masked symmetric reducer forms a permutation-invariant input. Fixed action logits are invariant, while opponent-target logits use a shared query--key scorer and are permutation equivariant. The resulting recurrent actor state is `h_i^t`. This backbone keeps parameter count independent of population size and is shared by all baselines.

## 4.2 Instantaneous composition branch

The composition code should describe the physical opponent team and is allowed to change after attrition:

\[
c_t=f_c[\log(1+M_t),\nu_t,\bar\eta_t,\operatorname{threatpool}(E_t^-)],
\]

where `nu_t` is a normalized type histogram and `bar eta_t` summarizes health/survival. Under decentralized execution, each controlled agent computes a local composition code from its visible set and visibility mask. This branch prevents the method from discarding strategically relevant force information in pursuit of invariance.

## 4.3 Population-normalized conditional behavior branch

For each observed opponent `j`, the behavior encoder receives the current entity state and an observed action or transition:

\[
b_j^t=\phi_b(e_j^t,a_j^t)
\]

when actions are exposed, or

\[
b_j^t=\phi_b(e_j^t,\Delta e_j^t,\chi_j^t)
\]

when only successive observations and attack events `chi_j^t` are available. Conditioning on the pre-transition state discourages the encoder from treating a location marginal as a policy. A masked mean produces a per-opponent statistic independent of sample count,

\[
\bar b_t=\rho_b\left(\frac{1}{M_t}\sum_{j=1}^{M_t} b_j^t\right),
\qquad z_t=\operatorname{GRU}_b(\bar b_t,z_{t-1}).
\]

We omit count and raw type histograms from this recurrent branch. Population invariance is not assumed to follow from mean pooling alone; it is trained with paired interventions in Section 4.5.

## 4.4 Policy conditioning and online change score

Both codes affect decisions because an agent must respond to force composition and behavior:

\[
(\gamma_t,\beta_t)=W_f[c_t,z_t],
\]

\[
\tilde h_i^t=(1+0.1\tanh\gamma_t)\odot h_i^t+\beta_t,
\]

\[
g_i^t=\sigma(W_g[h_i^t,c_t,z_t]),\qquad
h_i^{\prime t}=g_i^t\odot\tilde h_i^t+(1-g_i^t)\odot h_i^t.
\]

Policy and value heads consume `h_i'`. The strategy-change score intentionally excludes `c_t`:

\[
d_t=1-\cos\left(z_t,\frac{1}{k}\sum_{s=t-k}^{t-1}z_s\right).
\]

The threshold is frozen using validation compositions and training opponents. The default model uses `d_t` for analysis and a soft response gate; a hard GRU reset is evaluated only as an ablation because false detections could otherwise cause catastrophic forgetting.

## 4.5 Paired objectives

The total objective is

\[
\mathcal{L}=\mathcal{L}_{RL}
+\lambda_{pred}\mathcal{L}_{pred}
+\lambda_{inv}\mathcal{L}_{inv}
+\lambda_{sep}\mathcal{L}_{sep}.
\]

`L_pred` predicts an opponent action or next transition conditional on the current state. For two matched windows generated by the same training opponent policy under composition interventions `c` and `c'`,

\[
\mathcal{L}_{inv}=w(\tau,\tau')\|z(\tau)-z(\tau')\|_2^2,
\]

where `w` down-weights poorly matched state distributions. For different policies under matched compositions,

\[
\mathcal{L}_{sep}=w(\tau,\tau')
[m-\|z(\tau)-z(\tau')\|_2]_+^2.
\]

Script names or checkpoint identities construct pairs during training but are never inputs to the actor and are unavailable at test time. Pair manifests are generated before training and test-policy implementations are excluded from all pairing and model selection.

## 4.6 Fallbacks

**Conditional-residual detector.** Train only the state-conditional action/transition predictor, average its error over visible opponents, and apply CUSUM, ADWIN, or Bayesian change-point detection. This is more interpretable but does not learn a continuous behavior code.

**Diagnostic-only study.** If composition--strategy confounding is consistent across strong baselines but CDOC does not improve decision regret, publish the event protocol and multi-model audit rather than adding unrelated modules. If the confounding itself is absent, stop the project.
