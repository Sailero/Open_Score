# 项目核心分析与论文定位

更新依据：2026-09-23 17:20（北京时间）的 [main0921 唯一正式实验报告](../Open-SCORE/outputs/main0921/实验报告.md)、[固定实验计划](../Open-SCORE/outputs/main0921/实验计划.md) 与 [结果身份登记](../Open-SCORE/outputs/main0921/inventory.json)。本文只记录研究判断和下一步决策；完整配置、逐种子结果、图表与缺口均以正式报告为准。旧 S1、v1–v5 阶段用于确定环境、修复实现并形成消融问题，不能与 main0921 的正式口径混算。

## 1. 项目问题和当前方法

任务是在小规模训练后，让红方多智能体策略面对更多无人机、更多保护目标及二者同时增加。HAD 训练规模为双方各 4/6/8/10 人、目标 1/2/3 个；终评按人数外推、目标数外推和联合外推分组，指标为累计目标损伤 D（越低越好）。当前方法沿用 CTDE 的价值分解和 REFIL 局部分支：先更新实体关系表征，再由每个体以自身状态和历史隐状态为条件读取各轮关系信息，融合后用 GRU 输出动作价值。[实现](../Open-SCORE/open_score/models/entity_encoder.py)与[结构图](../Open-SCORE/outputs/main0921/figures/fig1_architecture.png)给出实际计算路径。

![现行方法的计算路径](../Open-SCORE/outputs/main0921/figures/fig1_architecture.png)

现行正式矩阵已完成 **336/408 个三种子结果格、43/63 个合格 final 身份**。HAD 的 Full、Single、Fixed4、Untied4、TransfQMix 等已有三种子完整终评；KV0 仅 seed 0，M4 决策成本与 SMACv2 六方法仍无完整正式结果。这些缺口不能写成已验证的贡献。

## 2. 最关键的结果与反证

下表为正式报告中各固定配置先等权、再按三个训练种子等权得到的 D 均值；置信区间、每格原值和种子点见[正式报告正文与附录 A](../Open-SCORE/outputs/main0921/实验报告.md)。Untied4 四组值根据附录 A.1/A.4/A.5/A.6 的完整配置逐格均值再等权汇总。

| 方法 | ID | 人数外推 | 目标数外推 | 联合外推 |
|---|---:|---:|---:|---:|
| Full | 0.419 | 0.861 | 1.036 | 1.477 |
| Single | 0.429 | 0.742 | 1.225 | 1.674 |
| Untied4 | 0.321 | 0.486 | 0.860 | 1.165 |
| REFIL | 0.715 | 2.209 | 1.796 | 3.308 |
| REFIL-matched | 0.914 | 2.269 | 2.493 | 4.170 |
| TransfQMix | 2.157 | 6.226 | 6.128 | 10.597 |

Full 相对 REFIL 在四组中均降低损伤，参数匹配的 REFIL-matched 也未消除差距；这是 **HAD 固定预算下整套系统的比较结果**，不能直接归因于循环。Single 已保留大部分收益；Full 对 Single 仅 seed 0 在四组都胜、seed 1/2 都败。[固定四轮与单轮的逐格结果](../Open-SCORE/outputs/main0921/实验报告.md#c-全部执行深度与固定计算读出)也没有“人数越多就应算越深”的单调趋势。

Untied4 的三种子四组均值都低于 Full，且逐对应种子优于 Fixed4；但相对 Full 四组都是 seed 0/2 胜、seed 1 败，现阶段只能说它是值得解释的候选，不能说不共享参数已稳定胜出。Fixed4 有明显的弱 seed；No-count 在目标数与联合外推上三个种子均优于 Full；冻结读出时 Read-1 接近 Learned，而 Read-3/4 与 Uniform 大幅变差。关系探针的随机初始化控制在部分标签上也有竞争力。这些结果共同否定“固定四轮、显式计数和逐轮语义层级均必需”的原先叙事。[机制和探针全表](../Open-SCORE/outputs/main0921/实验报告.md#d-关系探针与必要控制)

## 3. 四个当前决策

**TransfQMix 为什么差。** HAD 三种子在 ID 已落后（2.157 对 Full 0.419），联合外推进一步到 10.597；因此不能只归咎于外推规模。迁移保留了原论文及作者固定提交的 Transformer actor/mixer、历史 token、固定初始 K/V 来源、TD(λ) 和主要超参：嵌入 32、4 heads、2 layers、dropout 0、Adam 0.001、λ=0.6、batch 32、buffer 5000、target 每 200 回合、epsilon 100k。按论文 §4.3 使用 3 个 hyper token，而作者某版 mixer 代码按 agent 数初始化，这一点是有依据的选择，但也说明并非逐行复制。[原论文](https://www.ifaamas.org/Proceedings/aamas2023/pdfs/p1679.pdf)、[作者配置](https://github.com/mttga/pymarl_transformers/blob/2ef0a0726f1f186097b4b560509ceb5a801fdafe/src/config/algs/transf_qmix.yaml)、[本地实现](../Open-SCORE/open_score/algos/transfqmix/__init__.py)、[本版适配清单](../Open-SCORE/outputs/main0921/实验计划.md#transfqmix-来源及适配)。HAD 的实体特征、九动作、伤害奖励、可变规模 mask 与并行采样/更新节奏均改变了原任务；**现有证据没有定位出一个确定的迁移错误，也不能排除适配与优化差异造成劣势**。应把它写成当前协议下的有限预算结果，不用它单独证明本方法的机制。

**SMAC 步数。** 2026-09-23 曾将全部 SMAC 训练登记为 2M 联合环境决策步。2026-09-27 训练中确认 2M 未饱和，修订为 **5M**（仍不是每个规模 5M）。验证间隔保持 40k 步，点数 50→125；终评 8 配置 ×300 局不变。已开跑的 REFIL/SPECTra 从 resume 续训。

**图像刻度。** 原图把 TransfQMix 与宽置信区间压在同一纵轴，低 D 方法差异被压扁。绘图代码已在[主报告绘图](../Open-SCORE/open_score/eval/report0921.py)与[论文图绘制](../Open-SCORE/open_score/eval/paper_report.py)添加低损伤均值放大视图，原图仍显示全范围、种子与 95% 区间。当前拉取内容缺少被 Git 忽略的逐局 CSV，旧 PNG/PDF 尚未重绘；原始数据可用后再按现有生成流程更新同名图片。

**方法价值。** 当前可证的是“实体关系加工后由个体历史条件化读取”这套计算组织在 HAD 固定协议下带来的系统收益，尤其是相对 REFIL 的人数和目标数外推；额外循环深度、层级语义、显式计数与低成本尚未证实。

## 4. 论文定位和独特价值

[ADAPT](https://ojs.aaai.org/index.php/AAAI/article/view/40096/44057) 采用分散训练/执行、对象中心输入、动态一致性和 FINE 动作选择；[TransfQMix](https://arxiv.org/abs/2301.05334) 已采用历史 token 的 Transformer agent 与 Transformer mixer；[HGAP](https://proceedings.mlr.press/v235/lin24m.html) 已研究实体图注意力和迁移，[SPECTra](https://arxiv.org/abs/2503.11726) 已研究可伸缩 actor/mixer。因此，可变实体、attention、GRU、QMIX 或共享循环块单独都不能作为新颖性主张。当前与 ADAPT/TransfQMix 可辨的区别是 **CTDE 价值分解中先加工实体、再用个体历史条件化读取** 的计算分工；尚无同宿主对照证明这一个差别独立导致收益，也没有与 ADAPT 在同一协议直接比较。

> 在 HAD 的统一训练预算下，先加工实体关系、再由个体历史条件化读取的可变规模策略，在人数和目标数外推时比 REFIL 及容量匹配版本取得更低损伤，且单轮版本已保留主要收益。它与 ADAPT 的分散训练及动态一致性、TransfQMix 的 Transformer agent/mixer 路径有明确计算差别；当前不能把优势归因于多轮层级推理，也不能声称跨环境普遍有效。

现阶段按**跨规模实体决策的实证与机制边界研究**组织论文，比宣称“多轮层级推理新方法”更符合结果。若要转向方法论文，需要一个可直接识别的结构增量、同宿主替代和独立任务确认；仅凭整包基线排名不够。投稿时主张、重复实验、不确定性、选择规则和计算开销应与证据一一对应，可参考 [AAAI 复现清单](https://aaai.org/conference/aaai/aaai-26/reproducibility-checklist/) 与 [NeurIPS 论文清单](https://neurips.cc/public/guides/PaperChecklist)。

## 5. 后续顺序与停止条件

1. **完成已登记证据**：KV0 剩余种子、M4 参数/全队决策成本和 SMACv2 六方法正式终评。分析 Full、Single、Fixed4、Untied4、KV0 的逐种子和各外推轴表现，不临时扩种子或预算。
2. **只在需要方法主张时做一个判别对照**：优先同宿主固定训练口径，比较“实体交互前后读取”或“历史只参与读取还是进入实体更新”其中一个问题；预先定义改善条件、计算代价与失败判据。资源竞争反馈仅在原任务中确认可重复的真实失效后再考虑。
3. **按结果收束**：若直接对照无稳定增量，停止独特循环机制主张；若 SMAC 不复现，结论限定 HAD；若深层成本高且收益不稳，以 Single 作为更简洁的主候选。保留 Fixed4 弱种子、No-count 正结果和探针控制，不通过改图轴隐藏反证。
