动态规模攻防：四方法迁移复现方案

打开方法
1. 将整个压缩包解压到一个文件夹。
2. 用支持 Markdown 及 LaTeX 数学公式的阅读器打开 crossscale_report.md。
3. 请保留 figures 文件夹与 Markdown 的相对位置；不要只移动 Markdown。
4. 如不使用 Markdown 阅读器，可单独下载 crossscale_report.html，用 Edge、Chrome 或 Firefox 打开。HTML 已嵌入全文、公式和四张图，不需要联网加载配图。

文件内容
- crossscale_report.md：五章完整报告，四个可复现方法。
- figures/*_overview.png：四张技术方案总览。
- figures/vector/*：可编辑 SVG、矢量 PDF、600 dpi PNG。
- image_prompts.txt：图像生成提示词及图稿说明。

本修复版只调整交付格式、图片路径和压缩方式，未变更研究方案。
ZIP 使用标准无压缩存储方式、英文内部路径，不加密。
