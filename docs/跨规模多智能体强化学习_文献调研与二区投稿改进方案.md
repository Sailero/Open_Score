# 跨规模多智能体强化学习：文献定位与论文思路

## 2026-09-22 更新：从模块组合转向可检验的研究问题

本节是当前建议，覆盖下方 2026-09-12 历史方案的研究定位。文献核查截至 2026-09-22；实验判断使用 main0921 在当日约 21:23 已核验的快照，后续进度以[正式实验报告](../Open-SCORE/outputs/main0921/实验报告.md)为准。本次只更新文献定位和研究思路，没有改动算法、实验队列、种子、训练预算或终评协议。

**结论：Single 与已有实体关系策略属于非常接近的方法家族；当前循环实现也有直接的共享关系推理近邻。现有结果支持方法家族在 HAD 的性能，但尚不足以建立“循环形成语义层级，因而促进规模外推”的中心贡献。不能通过更换术语解决这一缺口。** 这不等于发现了与完整实现完全相同的论文，也不等于现有实验没有价值；它意味着基本操作层面的新颖性风险已经很高，需要把贡献落到具体问题、计算差别及对应证据上。

### 一、Single 究竟与什么已有工作相近

当前 Single 的主要计算是：可见实体嵌入 → 一轮实体间 self-attention/FFN → 自身初始表示与历史 hidden 构造 query → cross-attention 读取 → 与 REFIL 局部表示残差融合 → GRU → 个体 Q；训练仍使用当前 mixer 和辅助目标。它保留时间记忆，取消的是同一环境步内的多轮关系更新。一次关系更新另有一次个体读取，不能把 Single 简单当成仅一次 attention 计算。

下面区分“已有基本思想”和“整个实现相同”。原文页码均指所链接版本，代码证据另行注明。

**最直接的风险来自 HGAP、TransfQMix、SPECTra 与 TETQmix，而不只是最原始的 Transformer。** 当前可辨差别是关系更新、历史条件读取、局部残差与训练宿主的具体组织。共享嵌入、LayerNorm、零初始化、count 输入和使用 QMIX，本身均不宜列为独立创新。

### 四、当前循环与“不同层级信息”的动机为何没有对应起来

当前标准循环在相同实体集合、相同宽度、相同可见性 mask 上重复更新。第一轮已有稠密可见实体交互；后轮没有明确的新对象、新关系尺度、语义角色或子问题。原输入通过初始化和残差有保留通路，但没有独立的逐轮输入锚点；不能把这误写成“原信息必然丢失”。

个体自身与历史构成同一次决策内固定的读取 query，各轮读取结果不再反馈到更新中。因此结构实现的是多次关系加工后读取，而不是围绕暂定决策暴露的不足进行修正。它可能自行形成抽象层次，但没有结构性保证，也没有现有 probe 证据确认。

随机深度与多轮读取允许浅层即可解决任务：Full 在 R=1 批次也必须学习，第 1 轮始终出现，第 4 轮只在 R=4 时出现；浅层读出可直接进入最终决策。共享块仍会通过后轮反传学习，不能说后轮未训练。这是“浅层解容易被接受”的优化假设，不是已证明的梯度饥饿、过平滑或实现 bug。

还需要区分环境规模与协调复杂度：[README](../README.md) 中训练对手 `reactive + rush` 每五步或伤亡时重选一个目标，全队集中攻击。增加 K 并不自动增加同时活跃的子任务；增加 N 还可能改变密度、冗余和任务难度。原来按 N/K 推导“更大规模需要更高层推理”的论证缺少中间证据。

### 五、保留现有数据时，论文目前能讲到哪里

现在可成立的表述是：在 HAD 的既定预算与终评协议下，ReGIR 家族具有较好的表现；单轮版本已复现完整方法的大部分优势；额外深度的收益不一致，需结合训练方式、共享约束和读取方式判断。

以下证据改变论文重心：

- Full/Single 的均值接近且各有胜负；Full 的目标数/联合外推均值优势明显受 Single seed 0 影响，另外两种子方向相反。不能称普遍稳定提升，也不能宣称统计等价。
- No-count 在目标数与联合外推的三个对应种子均更好，显式数量注入不宜作为核心贡献。No-REFIL 联合移除局部 attention 与 imagined loss，不能分别给两者下结论。
- M1 不支持持续增加深度持续改善；M2 中 Read1 已较接近 Learned；M3 没有支持逐轮关系可读性增强。冻结读取崩溃不等于重训替代读取必然失败。
- 9月22日晚补核：Fixed4 seed 0 已完成7200局终评。按报告逐格舍入值等权平均，其ID/人数/目标数/联合外推约为0.322/0.523/1.141/1.884；Full同seed为0.330/0.778/1.078/1.576。人数外推改善约33%，联合外推反而变差约20%。这是外推轴之间可能存在取舍的单种子线索，不是固定深度全面胜出。Fixed4其余种子与Untied4尚未完成；KV0、成本和SMACv2还不足以形成相应主张。
- TransfQMix 在 ID 上已明显落后，整包 OOD 差距不能独立证明 actor 的规模泛化机制。

**当前现版本适合的论文定位是方法实证与机制边界研究，方法层面新颖性尚未确立。** 如果只改变写法，不能把这套证据升级为强循环创新。已有方法的合理组合也可能有价值，但需要明确问题、公平近邻与可复现收益，不必声称每个模块都绝对不可替代。

### 六、推荐重新组织的研究问题与候选方法

建议保留“可复用的关系处理支持跨规模协作”这一大动机，把需要验证的问题缩小为：

> 当多个威胁竞争同一批可用防守资源时，仅依据本地可见实体与历史，策略能否估计自己尚需补充的覆盖，并通过修正这种估计改善未见关系组合下的决策？

这是一条待验证方向，不是检索后确认的空白。区别不能仅靠“不通信”或“加任务 token”，而要落在具体估计量、更新规则、信息边界和因果证据上。

**层级应由对象和关系定义，轮次应由修正过程定义。** 可考虑三个表示对象：实体及可达性；威胁/拦截机会的候选覆盖；多个机会对同一防守资源的竞争。一次完整更新可经过这些对象，重复更新修正上一轮的覆盖判断。不能把第 1/2/3 轮直接命名为实体/小组/全局，也不保证第 4 轮比第 3 轮更好。

候选计算只保留一项实质变化：让下一次更新显式依赖上一轮估计的覆盖不足或重复投入。示意为“可见实体与历史 → 候选覆盖关系 → 估计剩余需求/重复覆盖 → 修正个体偏好”。在定义前不把普通向量叫作资源、概率或需求；需要明确时间窗口、单位和重复计入规则。某个 agent 内部对他者的预测不是共享的真实意图，也不能保证不同 agent 已达成一致。完全相同的局部信息无法凭内部循环恢复不可观测事实。

与近邻相比，必须回答：它比 HGAP/Single 的扁平关系表示多了什么；比 ALMA/结构预测的任务分配少依赖什么信息；比 ToM2C/LIAM 多解决什么问题；比 KDD 2023 意图反馈多了什么具体机制。任一问题只有“使用不同 attention”或“应用于 HAD”作答时，仍不应宣布方法创新已经成立。

两条路线的选择如下：

| 路线 | 现在能做出的判断 | 何时值得继续 |
|---|---|---|
| 保留现版本，研究关系更新与历史读取的分工 | 风险较低、复用结果多；整体架构与已有工作较近 | 同宿主对照能揭示明确且跨环境可复现的贡献，接受实证研究定位 |
| 显式覆盖竞争与迭代修正 | 更贴近实际协调问题，但机制与新颖性均未确认；推荐作为下一项有边界的研究假设 | 先证明当前任务存在对应失败，并能预先写出区别于近邻的更新规则与反证条件 |

不推荐同时增加层级、门控、动态停止、辅助语义损失与新 mixer。那会增加优化自由度，却让正结果无法归因。也不推荐恢复旧 S2＋搜索体系来弥补当前主张，历史预测改善未必转化为决策改善的问题仍在。

### 七、怎样把机制实验改成能决定方向的证据

保留已约定的 Fixed4/Untied4/KV0/M4/SMACv2与原统计协议，但研究决策分阶段进行：Fixed4/Untied4三种子终评一齐即可先判断深度训练与共享约束，不必等KV0和SMAC全部结束才思考。已有数据和Single留作基线，不悄悄把已看OOD上获胜的变体改名为Full。当前用户要求不再改动训练，本轮不启动任何新算法或机制训练。

下一步只保留三个问题：Fixed4相对Full的改善是否跨种子且跨外推轴成立；Untied4相对Fixed4的差别是否主要落在ID拟合或OOD迁移；KV0是否保留Full的表现。训练内验证曲线只用于判断优化状态，不用它预测并宣告OOD胜负。若多轮版本都不能稳定超过Single，就结束“额外轮次必要”的主张，并以Single作为后续结构研究基线。

现在即可准备的工作是利用既有轨迹定义可测的协调失败和反证条件，而非再开一组大训练：在固定N/K下，以几何和动力学可达性定义哪些防守者能及时处理哪些威胁，检查候选集合重叠时是否出现重复投入与可避免遗漏。只有这一失败确实存在并影响损伤，才值得实现一个显式覆盖不足反馈的最小原型；若普通单轮结构已解决它，就停止多轮修正主张。当前最可信的是浅层关系处理已有主要收益；训练深度可能改变外推偏好，仍属待确认假设。

若保留当前结构主张，按拟主张选择一个最直接的对照：保留同一宿主，比较“未交互实体读取”和“交互后实体读取”；若主张历史选择，再固定实体更新、比较自身 query 与自身＋历史 query。也可用相同宿主的历史 token 更新作近邻参照。无需默认把所有组合全部训练；信息、attention 次数、参数和计算差别必须披露，不能只说均为一层。

若选择覆盖竞争方向，应先给出与模型成绩无关的场景条件：固定 N/K，区分候选防守集合几乎不重叠和明显重叠的拦截机会；用实际几何/动力学条件定义，不能按 Single 表现差筛场景。集火对手下也可能存在这种竞争，但目前尚未证明。若必须改变对手才能出现，应把它列为新的统一协议，所有方法同样评估，原结果继续保留。

最小证据链是：

1. **现象**：在明确的竞争条件下，现有策略出现可测的重复投入或遗漏，同时影响任务损失；最近距离标签不够。
2. **结构作用**：同结构单轮对照区分显式关系组织的收益，多轮关闭/冻结反馈对照区分反馈的收益；冻结干预与重训替代回答不同问题。
3. **计算作用**：与相近计算量的不共享堆叠比较，判断改善是否需要复用修正规则，而非仅多算几次。
4. **外推作用**：在未用于设计的关系组合和规模上确认，保留简单场景与失败场景；不能只选对多轮有利的任务。

不要求每个状态逐轮单调改善，不靠 attention 热图、层编号或 probe 可解码性证明因果。若引入训练辅助目标，只能在定义具体待估量后决定；不得为获得漂亮层级图而规定每轮预测不同几何标签。新增假设须用新的确认评估检验，已看过的 OOD 不能重新称为未参与设计。

停止条件也应提前明确：若同结构单轮足够，则停止多轮必要性主张；若反馈去除后结果仍相近，则停止反馈机制主张；若只有中央状态/通信版本成功，则限定信息设定；若在原任务中没有发现覆盖竞争失败，就不因沉没成本强行改环境来维护循环。

### 八、论文如何重新组织

当前写作题目可暂用 **《实体关系加工何时有助于跨规模多智能体决策？》**，作为研究问题而非最终品牌。只有覆盖竞争机制得到证实后，才考虑 **《面向跨规模协作的局部覆盖竞争建模与迭代决策修正》**。题目中暂不使用已证明层级、通用推理、收敛或必然泛化等措辞。

引言按四步展开：实际部署存在规模变化 → 可变长实体网络已经存在 → 当前实验证明浅层关系结构很强、盲目增深缺少一致收益 → 需要定位额外协调计算的具体条件。不要虚构所有现有方法都只能独立看实体、没有历史或不能处理变规模。

实验正文仍按用户要求围绕结果叙述：先主结果，再同宿主结构/深度比较，再计算成本与一个核心机制问题。附录放完整配置、逐种子结果、原 M1–M3 的完整正负证据及实现/协议。不要因为旧 probe 不支持主张而隐藏它；也不要用大量相关性图替代一个直接反证实验。

贡献表述分两层：**已成立的是特定协议下的性能与深度收益边界；待建立的是具体协调状态及修正规则的新增价值。** 若后者不成立，可以保留前者完成实证论文，但不能用叙述把候选假设写成已实现、已验证的算法贡献。

最值得保留的四条经验是：

1. **先确认输入、动作和训练目标的有效性，再解释算法排名。** 历史 v3 的计数适配和跨规模 v2 的 mixer 问题都说明这一点。
2. **预测精度不等于决策价值。** S2 的 Brier/MAE 改善，没有自动变成可靠的同状态候选排序；再次采用 S2，必须有与实际候选选择对应的证据。
3. **分层结构必须每一层都有可验证作用。** 上层分配如果没有实质改变下层条件，或者任务标签本身错误，增加网络数量不会产生协作。
4. **信息权限与总计算量决定比较是否成立。** 使用真实模拟器搜索、教师轨迹、中央分配或专门任务奖励时，必须把这些条件写进对照表。

### 3.2 必须分开写的三个回报

物理奖励与报告指标为：

\[
r_t=-\Delta D_t,\qquad R_{\mathrm{report}}=\sum_t r_t=-D.
\]

而当前所有主线方法共享势函数塑形，`shaping_coef=1.0`，learner 使用 `gamma=0.99`：

\[
r'_t=r_t+\gamma\Phi(s_{t+1})-\Phi(s_t),\qquad
J_\gamma(\pi)=\mathbb E_\pi\sum_t\gamma^t r'_t.
\]

在正确处理终态与截断边界时，势函数项的折扣和只差初始状态常数；这个结论针对**相同折扣目标**，并不说明折扣优化与未折扣 −D 等价。理论来源为 Ng、Harada、Russell 的原始论文。[奖励塑形论文](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)。

因此论文应明确：采用折扣的塑形奖励学习，采用原始累计伤害选模与报告。仅看 D 变好不能说明塑形是新算法创新；仅延后伤害也可能改变折扣价值而不降低最终 D。若主张“直接最小化完整累计伤害”，还需要统一有限/无限时域定义与时间边界，再对相关方法统一处理，不能只对拟提出方法改变 gamma。

红方全灭后，底层仍继续物理演化；当前训练包装器把无后续可控动作的尾段折扣奖励折叠到最后决策转移，并结束红方决策过程。这里存在“物理自然终止”“采样截断”“决策尾段折叠”三个概念。特别是尾段运行到采样上限时，代码会退还末端势并终止决策；这不能被描述成已经得到无穷时域的全部伤害。现有终评确有非自然终止样本，例如 REFIL 在 6,900 局中有 111 局，因此时间边界不是纯理论细节。

### 3.4 投稿前需要解决或限定的真实问题

1. **报告状态聚合。** 训练步、best 步、评估状态分别统计；均值表附真实训练种子数；更新原报告生成逻辑，避免修一份 Markdown 后下次自动刷新又错。
2. **ALMA 执行随机性。** 上层提案采样与任务嵌入置换在评估模式仍有随机调用；环境种子不自动决定策略 RNG。正式评估需记录并固定策略随机流，或明确对随机策略采样取均值，不应宣称完全确定的 greedy policy。
3. **ALMA 宏时间目标。** 上层目前使用片段奖励和除以 `action_length`，自举折扣为 gamma；这不是“物理步折扣严格一致”的标准半马尔可夫目标。可保留作者算法约定并披露；若研究精确宏时间折扣，应把修订版单列，不能悄然改基线。
4. **ALMA 子任务先验。** 最近目标归属是公开几何启发式，不是蓝方真实意图；硬分组和五步分配可能遗漏跨任务关联。它是潜在局限，尚无正式训练数据证明它实际导致失败。
5. **置换声明的作用范围。** 现有固定任务 mask 下的动作 Q 等变检查，不足以证明 ALMA 完整自回归随机分配过程严格等变。论文只声明有对应数学或实验证据的部分。
6. **配置与版本证据。** v2 模型已删除，v3 某些早期中止轮也仅余文字；这些状态必须在可复现性说明中如实记录。当前 best、最终/恢复状态与统一原始数据按现有目录保留。

这些工作是可解释、可比较实验的基础，不计作新方法贡献。本次交付是研究方案；不把尚待修改、训练或正式评估的项目描述成完成。

## 4. 文献已经解决了什么，还留下什么问题

### 4.1 核心方法比较

下表的“与本项目关系”属于研究判断；原方法事实由所链接的论文支撑。正式发表与预印本分开标注，不使用不同论文的成功率作跨环境排行榜。

| 方法、发表信息 | 原工作核心内容 | 对本项目的启示与创新边界 |
|---|---|---|
| [QMIX，ICML 2018](https://proceedings.mlr.press/v80/rashid18a.html) | 单调混合个体动作价值，使联合最大化与个体贪心一致 | 基础理论与算法来源。变负偏置、掩码正确性不是新价值分解理论 |
| [Mean Field MARL，ICML 2018](https://proceedings.mlr.press/v80/yang18d.html) | 用群体平均影响近似多体交互 | 说明大规模协作已有经典近似；是否适合少量关键任务与异质局部负载需单独判断 |
| [结构预测分配，NeurIPS 2019](https://arxiv.org/abs/1910.08809) | 学习任务分配评分并通过集中优化求解，研究从小实例向更多智能体和任务迁移；全文已有容量和任务间耦合 | “容量约束＋任务分配＋跨规模”不能单独作为新贡献；与原始运动动作端到端学习的区别要具体说明 |
| [DCG，ICML 2020](https://proceedings.mlr.press/v119/boehmer20a.html) | 个体效用和成对 payoff，max-sum 消息传递选择联合动作 | 适合比较显式协作关系；不是普通 GNN 编码器，不应混淆两者 |
| [REFIL，ICML 2021](https://proceedings.mlr.press/v139/iqbal21a.html) | 随机实体分组，用想象因子重构团队价值，辅助多任务价值学习 | 最直接的改进母体；原始动机主要是跨任务复用与样本效率，不等于已经解决任意数量 OOD |
| [UPDeT，ICLR 2021](https://arxiv.org/abs/2101.08001) | Transformer 实体表示与策略解耦，支持任务和动作配置迁移 | 可变输入和动作头已有先例；当前固定 9 动作无需为了“对齐”强行改成实体指向动作 |
| [CASEC，ICLR 2022](https://arxiv.org/abs/2106.02886) | 依据 payoff 变化建立上下文相关的稀疏协调图，并学习动作表示 | 关键关系筛选、动态稀疏图已有研究；新分解应解释训练因子的信息保留，不能只是另起边权名称 |
| [ALMA，NeurIPS 2022](https://papers.nips.cc/paper_files/paper/2022/hash/2f27964513a28d034530bfdd117ea31d-Abstract-Conference.html) | 高层分配与任务条件低层联合学习，复用可组合子任务 | 是分层路线最直接对照；原论文已包含基地防御及消防任务，不能宣称首次防御任务分解 |
| [TransfQMix，AAMAS 2023](https://arxiv.org/abs/2301.05334) | Transformer 个体网络与 mixer，同一参数支持团队数量变化 | 可扩展 Transformer mixer 也已有先例；与 SPECTra 覆盖相近部分，不必两者一开始全部实现 |
| [DT2GS，NeurIPS 2023](https://papers.nips.cc/paper_files/paper/2023/hash/f7d3cef7ff579f2f903c8f458e730cae-Abstract-Conference.html) | 可扩展子任务编码与自适应语义，促进跨任务一致性 | 可复用任务/技能语义并不是空白；新方案需指出数量、负载和分解误差的额外问题 |
| [SPECTra，2025 预印本](https://arxiv.org/abs/2503.11726) | 单查询注意力、可扩展超网络和 mixer，并结合课程，实验含 SMACv2、GRF | 当前最相关的近期架构基线。轻量注意力、置换性质、可变数量和课程的组合已被覆盖；本次未核实正式录用 |
| [MA2RL，2025 预印本](https://arxiv.org/abs/2502.17046) | 对掩码实体状态进行重建，促进可泛化技能表示 | “实体掩码＋辅助损失＋泛化”本身不新；其重建目标与 REFIL 的辅助价值目标不同 |
| [ADAPT，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40096) | DTDE 的对象集合、本地任务上下文、动态一致性训练和零样本迁移指标 | 直接限制“任务条件实体表示”这一宽泛创新叙事；需要讲清项目 CTDE 与其 DTDE 的设定及目标差别 |

有两条较新的证据进一步收紧了可投稿问题：

- **2026 年 GR-MAPPO 应用论文**已经研究 GraphSAGE、GRU、固定规则对手和跨团队数量的防御任务，并按规模扩展地图以控制交互密度。因此“GNN＋RNN＋固定对手防守＋跨规模”也不是充分的新颖性描述。其具体任务与当前 HAD 不同，不能搬用其数值比较。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13298309/)。
- **2026-09-03 的离线 MARL 预印本**报告任务多样性对零样本迁移的重要作用。它不能直接证明在线 REFIL 也一样，但提醒本研究必须控制训练分布，避免把更丰富训练任务的收益归于新网络。[作者论文](https://arxiv.org/abs/2609.03667)。

另有 TETQmix 与 GIRA 等任务实体/种群编码线索，分别可见[作者代码](https://github.com/YuanhengZhu/TETQmix/)和[出版社 DOI](https://doi.org/10.1016/j.neucom.2026.134437)。TETQmix 的在线年与卷期年需分开；GIRA 的直接出版社全文本次未能读取、检索卷期还指向晚于本次截止日的日期，因此不据此断言算法细节或列作已完成的核心文献结论。正式提交前需更新这些最近邻工作。

### 4.2 数量信息值得研究，但不是新的发现

标准归一化聚合可保留元素分布而弱化总量。以所有 key/value 同时复制 m 倍为例，单纯 softmax 加权平均满足：

\[
\frac{\sum_j e^{a_j}v_j}{\sum_j e^{a_j}}
=\frac{\sum_j m e^{a_j}v_j}{\sum_j m e^{a_j}}.
\]

这是一个表示能力反例，**不证明当前 REFIL 对人数完全不敏感**。真实网络还含类型、相对几何、有效性 mask、mixer 和循环状态；实际物理局面也不等于精确复制实体。可检验的问题是：它是否容易把不同总负载但相似局部分布的状态混为一类。

集合/图聚合的辨别力已有充分先例；GIN 分析了聚合表达能力，PNA 结合多种聚合器和度数缩放。因此“加 count、sum、mean 或 degree”应先作为低成本强对照，而不是直接命名为新的理论贡献。[GIN 原文](https://arxiv.org/abs/1810.00826)；[PNA 正式论文](https://proceedings.nips.cc/paper_files/paper/2020/hash/99cad265a1768cc2dd013f0e740300ae-Abstract.html)。

### 4.3 可以争取的贡献边界

一个可能成立的论文问题是：

> 在同一任务内，实体数量与局部任务负载同时变化时，怎样构造数量信息明确、结构关系可追踪的辅助价值分解，使小规模训练得到的协作模式在未见规模上仍然有效？

它比“提升多智能体泛化”更具体，也允许得到否定结论。相对于 REFIL，改的是随机因子构造与所保留统计；相对于 ALMA，不要求在执行时硬性划分每个单位的子任务；相对于 CASEC，不以执行期稀疏 max-sum 图作为主要机制；相对于 MA2RL/ADAPT，不以实体重建或动态上下文一致性作为训练目标。

这些区别只是**研究空间的界定**。只有正式实验显示区别确实产生稳定、可解释的收益，才有理由把它写成论文贡献。若最终只是已知技术在 HAD 上的组合，应按应用改进或系统性实证研究定位。

| DCG/CASEC 的协作图 | 可显式建模成对协作 | 高；联合推断及权限不同，当前训练更慢 | 关系建模对照，不同时扩展为第二主线 |
| 旧 S2＋搜索＋分层重建 | 历史排序证据不足，旧代码与新任务差异大 | 很高；需重新解决预测、规划与底层适配 | 暂缓 |
| MAPPO/GNN/RNN 重新搭建 | 有现成外部文献；本地新增一套训练体系成本高 | 高；未对应 REFIL 已知缺口 | 不作为首批工作；第二任务需要时再决定 |

“REFIL 已经最好”并不等于永远只能改 REFIL。合理的换线条件是：补齐种子后优势消失，或 ALMA 在同信息、同物理预算下显著优于 REFIL，且其剩余问题能由少量、明确的新机制处理。现在没有这些结果，直接押注 ALMA 上层创新过早。

### 5.2 主线假设与最小方法设计

拟研究方法暂称**数量与任务负载保真的 REFIL 分解**。不要在获得机制证据前固定一个夸大的算法品牌。首版只引入两个相互关联的部件 C 与 G，不叠加教师、S2、MCTS、额外奖励和新策略优化器。

**C：显式保留数量与任务负载统计。** 在现有共享实体表示旁补充有效红、蓝、目标数量，以及由同一公开实体表形成的任务组成统计。采用 log-count、比例和分类型均值等连续表示，避免按训练上限裁剪人数或使用测试槽位专属 one-hot。一个可讨论的表示形式是：

\[
z_i=\big[h_i^{\rm attn},\{\mu_{i,c},\log(1+n_{i,c})\}_c,\ell_i\big],
\quad
\mu_{i,c}=\frac{\sum_j m_{ij,c}\,\phi(e_j)}{\max(1,n_{i,c})},
\quad n_{i,c}=\sum_j m_{ij,c}.
\]

这里 c 表示公开实体类别或已定义的任务类别，m 是与本分支可见性一致的掩码，ℓ 是同输入可计算的任务组成/负载上下文；零实体类别显式用有效性位区分。红/蓝/目标三类可以固定拼接；可变数量的任务统计应先经过共享任务编码，再用集合聚合，不能把 K 个任务槽直接接到固定全连接层。均值与数量联合比均值单独表达更多总量信息，但有限维表示仍不能保证对所有集合单射，也不保证训练外的任意数值都能泛化。

**先把 C 当作强简单基线。** 主方法与 `REFIL+C` 使用完全相同的新增统计。若后续结构分解没有额外收益，就接受“简单输入已足够”的结果，不能把 C 与 G 的收益混在一起。对 imagined 分支，仅使用该分支应可获得的局部统计；若还提供全局总量，应对全部比较方法一致提供并单列说明，避免辅助分支通过完整信息绕过想象任务。

**G：结构相关但仍保留随机性的实体分解。** 改动 REFIL 的训练辅助掩码生成，而非改变动作空间或在执行时增加硬分配。建议首版复用现有公开任务归属作为结构信号，生成相关的随机实体二分：同一任务的实体更可能被分在相同组，同时保留原始随机二分的概率。采用：

\[
p_{\eta}(g\mid E)=(1-\eta)p_{\rm random}(g)
+\eta p_{\rm structure}(g\mid E),\quad 0\leq\eta<1.
\]

首版的可执行定义是：在序列初态，用现有公开几何为每个红/蓝实体确定唯一最近目标标签，目标标记自身；相同距离使用固定且披露的平局处理。结构分支对每个目标簇抽取二元组标签，簇内共享标签；K≥2 时条件于两侧均含目标簇，K=1 时退回原随机分组。该标签仅用于训练期辅助分解，不是执行时的任务命令，也不是蓝方真实意图。不能直接套用当前 ALMA 初始任务 mask，因为其中每个红方同时关联所有活跃任务。

每个有效实体由此唯一属于一侧；within/cross 在当前有效且可见的实体关系上互补，死亡/padding/不可见关系在两条分支都遮蔽；按实体身份在同一回放序列中保持分组一致。死亡与 padding 不计入当前数量，死亡发生后更新存活计数，但不触发其余实体重新分组。η=0 时分组分布回到原 REFIL；没有 C 时整个变体才回到原网络。固定初态分组可以避免循环状态与逐帧随机标签错位，但可能无法覆盖后续任务变化。若这一限制实际重要，再研究有明确时间语义的动态分组，不同时加入第二个学习系统。这个原型本身是启发式结构采样，是否足够构成方法贡献须由机制证据决定。

不能把 G 说成“从环境删掉实体后得到无偏反事实”。真实转移和奖励仍来自完整环境，两个 imagined 因子合成后学习同一个完整 TD 标签。REFIL 原本已有 within/cross 通路，因此也不能笼统声称原方法丢掉了所有跨组关系；待验证的是**随机因子是否更难表达任务相关总量和组合交互**。

训练目标保持清晰：

\[
y_t=r'_t+\gamma(1-d_t)Q_{\bar\theta}
\big(s_{t+1},\arg\max_{\boldsymbol a}Q_\theta(s_{t+1},\boldsymbol a)\big),
\]
\[
\mathcal L=(1-\lambda)\mathbb E[(Q^{\rm full}_\theta-y_t)^2]
+\lambda\mathbb E_{g\sim p_\eta}[(Q^{\rm imagine}_\theta(g)-y_t)^2].
\]

这是简化记号；实际沿用对应 learner 的 mask、Double Q、死亡和尾段语义。辅助系数先沿用现有 λ=0.5；η 的选择只使用开发验证，不观察确认集来调参。C/G 不额外引入对目标的监督标签、蓝方私有分配或真实模拟器反事实样本。

**仍须保留完整分支。** 结构子任务可能并不独立，C/G 的目的是改善共享表示的学习偏置，而不是宣称整个任务可无损拆成互不影响的局部问题。全局 mixer 继续保留非负混合权重与允许有符号输出的状态偏置；新增状态统计不能依赖待优化的联合动作，否则原有单调性解释需要重新推导。

### 5.3 什么才算机制证据

| 假设 | 需要看到的证据 | 能否定它的结果 |
|---|---|---|
| H1：数量/负载统计表达不足参与外推退化 | `REFIL+C` 在预定义的数量/负载变化配置上有重复性提升；同时相似均值、不同数量状态的价值/表征区别更合理 | C 没有稳定收益，或只提高训练池拟合而不改善 OOD |
| H2：随机分解与任务结构错配 | 在 C 相同、分组大小分布相近的条件下，G 减少相关辅助残差并改善 OOD；结构被打乱后收益下降 | 随机分组经过同样组大小匹配即得到同等收益，说明不是结构信息作用 |
| H3：改善来自新分解而非更大模型/更多更新 | 同观测、同网络容量或参数量报告、同更新次数及物理步下仍有提升 | 加宽的原 REFIL 或额外训练即可解释全部差异 |
| H4：学到可迁移规律 | 新确认配置与第二任务/受控扰动中保持主要趋势 | 仅在已反复查看的 23 配置或单一开局批次有效 |

辅助残差、计数与分组统计优先从未来已经授权的训练批次/评估轨迹中记录，不另设无边界的诊断运行。现有每配置只保留极少数完整轨迹，足够作例子，不足以估计所有行为机制的发生率。

可写的理论内容应限于可证明的性质：有效集合的置换不变/动作等变、统计量的数量辨别反例、互补掩码的完整性，以及新增状态条件不破坏 mixer 对个体 Q 的单调性。**这些性质都不等于泛化保证。** 若要写价值分解误差界，必须明确任务间耦合的假设并给出推导；不能把实验曲线包装成理论界。

### 5.4 何时考虑 ALMA 备选路线

先完成当前 ALMA 的同协议结果，再决定是否改进。只有当结果和轨迹支持“硬任务边界或固定分配周期是主要限制”时，才考虑软任务上下文、共享跨任务信息或事件式分配中的一个机制。

采用事件式分层时，宏动作持续 τ 个物理步，其标准目标需明确写为：

\[
R_t^{\rm macro}=\sum_{j=0}^{\tau-1}\gamma^j r'_{t+j},\qquad
y_t^{\rm macro}=R_t^{\rm macro}+\gamma^\tau(1-d) V(s_{t+\tau}).
\]

这可作为新方法的时间定义，但不能反过来声称当前 ALMA 已采用该公式。基线保持作者算法约定时应披露差异；比较时再区分“时间目标修正”与“新分配机制”。若 ALMA 低层无论有无有效分配都接近同一表现，优先处理条件化和任务定义，而不是继续叠加预测网络。

## 6. 达到可投稿证据强度，还需要哪些实验

以下是后续研究的建议范围，不是本次已执行内容或自动扩大的运行授权。首先收齐当前计划，再按顺序启动新增研究，避免重复历史上的多路线并进。

### 6.1 第一优先：完成可用基线矩阵

保留当前正式五臂、各 3 个训练种子、每种子 1M 物理步、50 次池内验证、当前 23 配置各 300 局。首先补齐 QMIX-Atten/REFIL seed 1、2，完成 DCG/SPECTra seed 2，并取得 ALMA 正式结果。不能根据暂时落后提前删去主表中已约定的方法。

各臂保留真实优化器、TD/TD(λ)、探索和上层计算差异，给出适配表；“同预算”明确指物理步，而不是所有优化细节相同。共享塑形和公开观测保持一致。近期方法至少保留 SPECTra 的完整迁移对照；ADAPT/MA2RL 等是否增加实现，由最终贡献是否与它直接重合决定，不能把文献清单全部变成训练清单。

### 6.2 第二优先：四臂机制比较

| 实验臂 | 数量/负载统计 C | 结构分解 G | 用途 |
|---|---|---|---|
| 原 REFIL，当前修正版 | 无新增 | 原随机分解 | 母体 |
| REFIL+C | 有 | 原随机分解 | 检查简单额外信息能解释多少收益 |
| REFIL+G | 无新增 | 有 | 分离结构分解的独立作用 |
| REFIL+C+G | 有 | 有 | 检查组合是否超过各单项 |

首轮每臂沿用 3 种子、1M 物理步；原 REFIL 可复用协议一致的已有结果。若 G 没有新增学习参数，说明它的额外成本是训练掩码构造；若后来引入学习分组网络，则须补参数量匹配与同信息对照。

**投稿前至少保留一项直接否证 G 的结构对照：**将任务关联打乱，同时尽量匹配实体类型和组大小分布，再使用相同 C 与辅助计算量。只有 full 优于这种对照，才能把收益归于任务结构而不是分组大小或一般正则化。这一臂在四臂出现信号后才运行，不预先启动更多排列组合。

若想把“REFIL 想象机制不可替代”写入贡献，需要有同 C 的无想象版本；当前 QMIX-Atten 可提供基础参照，但只有它也获得相同新增信息时，才能严谨回答这一点。这个问题若不作为主张，可不新增该臂。

### 6.3 把已查看测试集与确认集分开

目前 23 配置已经用于发现退化并选择改进方向，属于**已知基准/开发证据**。虽然训练 checkpoint 没有直接用外推选优，后续算法设计已经受到这些结果影响，因此不能再把同一批结果称为从未查看的最终确认集。

建议在新方法与超参数冻结后，另设一个有限确认集合。例如在现有 40/40/6 接口内，预先固定：24v24 K2、36v36 K2；12v24 K2、18v36 K2；12v12 K5、24v24 K5。它们不在当前已核对的 31 配置记录内，分别覆盖数量、比例、目标数变化。对应开局种子必须与现有训练、验证、9000–9299 测试批次及其他已用批次不交叉。

这六配置只是明确的预算方案，实施前将完整名单、种子与指标写入同一实验版本配置。优先确认原 REFIL、最强可用对照和最终方法，共三方法×三种子×六配置×300局＝**16,200 次策略终评**；规则/随机若沿用 NDS，需要另补六配置×300×2＝**3,600 局锚点**。没有必要让所有消融都进入这个最终确认集。

如果不增加确认集，就应把论文表述限定为既定 benchmark 上的开发后验证，降低“未见任务普遍泛化”的主张强度，不能仅更换一批开局就声称消除了配置层面的选择影响。

### 6.4 规模、密度、负载和对手的区分

当前 NDS 是同配置的参照归一化，不能因果排除密度或任务负载影响。主论文至少清楚分列三类配置：相同任务数的数量变化、相同人数的目标数变化、红蓝比例变化；不要全部压成一个平均分。

若要进一步主张“数量与负载解耦”，需设计有限的受控对照：在固定 N 下改变任务组成，在相近每任务人数下改变 N/K，再比较相同 N、不同空间密度的条件。直接按 √N 放大地图也会改变距离和事件时间，因此应记录几何、时间尺度与物理参数，不能把“地图放大了”就叫作纯密度控制。外部 HAD 的任何配置/接口扩展属于新的实验版本设计，本次不实施。

对手泛化只在论文确实声称时作为必需证据。固定 reactive/rush 可作为主协议，另选一个已有不同规则或规则参数范围做少量冻结评估即可检验策略专属性；不必扩成自博弈、对手种群或新攻击策略工程。若没有该证据，题目与结论明确固定规则对手即可。

### 6.5 第二任务与外部有效性

对于以“通用跨规模 MARL 方法”为标题的投稿，建议至少补一个独立任务族；对于范围收敛的 HAD 应用论文，多种受控场景与公开环境可降低成本，但说服力通常较弱。**这是本课题投稿建议，不是所有二区刊的硬性条款。**

优先利用已有 ALMA 主干中的 Firefighters 作为低接入成本的第二任务：智能体、非智能体实体与任务组合都存在，也更容易检查提出的分解是否脱离 HAD 专用特征仍有效。但它与 ALMA 来源相同，应承认独立性有限；若最终选算法导向期刊，SMACv2 或其他广泛使用的合作任务更有外部说服力。SMACv2 强調随机生成与闭环决策，能够避免仅记忆固定场景就取得高分的问题。[SMACv2 原论文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/764c18ad230f9e7bf6a77ffc2312c55e-Abstract-Datasets_and_Benchmarks.html)。

第二任务必须重新定义可公开获得的任务组成统计，不应把 HAD 专有几何字段硬塞入通用方法。训练/评估预算按该任务已有标准或小范围适配决定，不能直接假定 HAD 的 1M 步足够所有环境。

## 7. 评价、统计与结果展示

### 7.1 指标定义

主要报告原始累计伤害 D、按初始蓝方数归一化的 ρ=D/N_B，以及同配置锚点得分：

\[
\operatorname{NDS}(c)=\frac{\bar D_{\rm random}(c)-\bar D_\pi(c)}
{\bar D_{\rm random}(c)-\bar D_{\rm rule}(c)}.
\]

同一配置内用 D 或 ρ 得到相同 NDS。NDS=0 对应随机，1 对应规则，大于 1 允许出现；它不是胜率、没有天然 [0,1] 取值约束，规则也不是理论最优上界。分母接近零时指标不稳定，应报告原始 D 和差值而不硬设一个稳定分数。ρ 也不是伤害事件的概率，多目标范围伤害下不保证上界恰为 1。

用于论文主结论的第一指标可预定为 OOD 配置宏平均的配对 D 改善或 ρ 改善，另按三条轴分别给出 NDS；不要等看到结果再在 D、NDS、胜率之间选择更好看的一个。宏平均对配置等权，避免较多局数或较大编队主导结论。ID 表中仍保留原始 D，防止外推提升以损失基础能力为代价。

辅助指标限制为与假设相关的少数项：同队碰撞死亡占比、拦截占比、自然终止/截断比例、逐目标伤害分布，以及 C/G 对应的计数与分解残差。只展示能解释具体结论的行为图，不把注意力热图直接当作因果解释。

### 7.2 训练随机性与开局随机性

三百个评估开局不能代替多个训练种子。统计应分别保留训练种子和环境种子；对随机上层还需记录策略随机流。相同环境种子形成配对初态，但不同策略可能触发不同事件顺序，因此不能宣称拥有完全相同的未来扰动轨迹。

建议报告逐训练种子结果、跨种子均值与标准差；主要方法差值用分层重采样置信区间，先以训练种子为独立训练重复，再在每个配置内按共同开局配对重采样。置信区间应包含训练不稳定性，不只重采样同一模型的 300 局。可参照 RL 统计评估论文的方法，报告区间和稳健汇总，而非仅用一个点估计排名。[Agarwal 等，NeurIPS 2021](https://arxiv.org/abs/2108.13264)。

三种子是当前合理起点，仍可能不足以判断小幅差异。如果主要优势接近跨种子波动，后续优先把**最终方法与最强基线**补到五种子，而不是所有方法一律扩种子。是否值得扩充取决于预定最小实用效应与置信范围；“五种子”同样不是录用保证。

可把相对强基线 OOD ρ 降低 10%、ID 不退化超过预设容忍量，作为项目内部继续投入的示例门槛；这些数值需要在新结果出来前固定，不能写成期刊标准，也不应为了达标重新定义配置集合。

### 7.3 论文需要的图表

建议正文保留六类核心图表：

1. 方法图：全实体分支、C、G、互补想象分支及共享 TD 标签；明确哪些只在训练出现。
2. 学习曲线：物理步对 ID 指标，每条曲线标实际种子数；训练信号与评估回报分开标注。
3. 三轴 OOD 图：原始 D/ρ 与 NDS 配合，标出训练支持边界和确认配置。
4. 四臂消融与结构打乱对照：让读者直接判断 C、G 及二者交互作用。
5. 与假设对应的行为/残差图：同一配置和相同采样规则比较，避免挑选成功轨迹。
6. 计算代价表：训练物理步、模型更新、实际总墙钟、参数量、执行信息权限和推断成本；不把单 observer 的注意力复杂度当作整个团队总复杂度。

现有图片可继续在原实验目录更新，不另造重复结果体系。正式版本仍保持一份 Markdown 实验主报告，方法结果作为其中章节；本文件是跨版本的研究与投稿方案，不代替各版本结果报告。

## 8. 实施顺序、预算与停止条件

### 8.1 先做什么，后做什么

| 阶段 | 工作 | 进入下一阶段的依据 | 暂不做的扩展 |
|---|---|---|---|
| P0：结果收齐与口径确定 | 完成当前已规划的五臂三种子；明确奖励、终止、名称、实际 seed 数和 best/训练进度 | 每个主要比较有完整同协议结果；关键方法的学习行为可解释 | 不重跑历史版本，不改正在运行任务的定义 |
| P1：冻结研究问题 | 根据完整结果决定 REFIL 或 ALMA 母体；写定 C/G、开发集、确认集、主指标、预算 | 明确一个可否定假设；与最近工作有具体差异 | 不同时开两条完整算法路线 |
| P2：最小机制实现 | 在现有主干实现 C 与 G；首先比较四臂，记录实际额外计算 | G 在同 C 条件下有超过噪声的信号，ID 能力没有明显受损 | 不加 S2、教师、搜索或额外奖励来补救无效机制 |
| P3：因果解释与确认 | 做结构打乱对照；必要时补容量匹配；冻结后执行有限新确认集 | 新结构关联与收益一致；结论不依赖单种子或已知配置 | 不反复看确认集再微调方法 |
| P4：外部有效性与投稿 | 第二任务/受控场景；整理方法性质、限制、成本与论文材料 | 贡献与证据匹配；候选刊范围与分区口径核实 | 不把制作网页、平台或更多工具当作论文成果 |

如果在 P0 后 REFIL 的跨种子优势消失，先修正选择依据，不沿用 seed 0 排名。若 C 有收益而 G 无收益，保留 C 作为结果，但放弃“结构分解创新”叙事。若只有修改训练分布才能取得提升，应转为“训练分布与规模泛化”的受控实证问题，并与 2026 年任务多样性研究明确区分。

若新方法只在同一个 HAD 场景好、第二任务无收益，可以收敛为应用论文；若不能稳定超过强简单基线，则目前证据不支持以新算法冲击预期投稿层次。此时继续扩大计算通常不如重新检查假设有效。

### 8.2 可核算的预算

预算按物理步和独立评估局数分开，1M=1,000,000 物理步。以下只是后续方案，不在本次调研中启动。

| 项目 | 规模 | 额外量 |
|---|---|---|
| 当前五臂三种子收齐 | 总训练预算 15M；截点已完成 6M，两个运行种子共约 1.573M | 尚余约 **7.427M**，其中 7M 对应尚未开始的七个种子；已有运行进度继续保留 |
| REFIL 四臂主消融 | 三个新臂×三种子×1M；原 REFIL 复用同协议三种子 | **9M**；按原协议另有 45,000 局池内验证、62,100 局终评 |
| 结构打乱对照 | 一个新臂×三种子×1M，仅在前项有信号时 | **3M**；另 15,000 局验证、20,700 局终评 |
| 六配置确认集 | 最终三方法×三种子×六配置×300局 | **16,200 局**；若报告 NDS，另 3,600 局规则/随机锚点 |
| 关键方法从三补到五种子 | 原 REFIL 与最终方法，各补两种子 | 条件性 **4M**，不是默认扩大全部方法 |
| 第二任务 | 选定任务后按相应学习难度与标准确定 | 单列预算，不假装已有可靠的绝对步数估计 |

前面前三项合计尚需约 19.427M 物理步，包含当前计划的剩余量与新增方法/对照；它不是要求立即全部执行的订单。先完成 P0、P2 的证据门槛，再决定是否值得支付 P3/P4 成本。若修改了共同奖励、感知权限或物理协议，相关基线需要按新协议对齐，不能继续按“全部可复用”计算成本。

本机已有日志显示：REFIL seed 0 在首次达到 1M 附近累计约 12,903 秒，QMIX-Atten 约 11,032 秒；DCG 完整日志约 55,086–57,433 秒，SPECTra 约 37,254–37,777 秒。不同记录截点、验证/终评包含范围、并发负载和训练 padding 不同，只能用于粗排期，不是独占吞吐排行榜。[原始进度](../Open-SCORE/outputs/main_v3/progress.csv)。

以 REFIL 的约 3.6 小时/1M 历史累计时间粗估，9 个新种子基础成本约 32 小时；若新增部件带来 1–2 倍总时间，则约 32–65 小时，另需计终评与实现调试。这个区间是排期情景，不是已测新方法速度。ALMA 的本地旁路记录不能直接换算正式 GPU 全程预算。

人力安排可以按约四到六周规划：第一周收齐与统一协议，第二周最小实现和四臂初步证据，第三至四周完成多种子与确认，随后整理第二任务和稿件。若基线不稳定或主要假设被否定，进度应由证据决定，不能承诺固定周数后一定达到录用标准。

## 9. 后续代码改动应落在哪里

优先修改现有实现与配置，以清晰的实验臂字段区分。不要为每个变体复制整个项目；一个新实验版本只使用一个输出目录，数据合并存储，保留一份正式结果报告。

| 工作 | 现有落点 | 必须保持的接口/证据 |
|---|---|---|
| 数量与任务统计 C | [features.py](../Open-SCORE/open_score/envs/features.py)、[entity_encoder.py](../Open-SCORE/open_score/models/entity_encoder.py) | 公开信息来源一致；死亡/padding 不计数；无训练上限裁剪；统计在完整/想象分支中语义明确 |
| 结构分解 G | [agent.py](../Open-SCORE/open_score/algos/pymarl/modules/agents/agent.py) 的想象分组部分 | η=0 恢复原方案；序列内身份一致；within/cross 掩码互补；不更改真实动作与奖励 |
| 辅助价值目标 | [q_learner.py](../Open-SCORE/open_score/algos/pymarl/learners/q_learner.py) | 同完整 TD 标签；不能让各子组各自领取一遍完整回报再相加；保留 filled/终止语义 |
| 数量条件 mixer | [flex_qmix.py](../Open-SCORE/open_score/algos/pymarl/modules/mixers/flex_qmix.py) | 非负动作价值混合权重、有符号状态偏置；不重引入 v2 的负值下界问题 |
| 配置与实验臂 | [refil.yaml](../Open-SCORE/configs/refil.yaml)、[算法入口](../Open-SCORE/open_score/algos/__init__.py)、[train.py](../Open-SCORE/scripts/train.py) | 在同一框架下显式保存 C/G/η 等设置；已有旧权重不冒充新架构训练权重 |
| 评估协议与统计 | [protocol.py](../Open-SCORE/open_score/eval/protocol.py)、[report.py](../Open-SCORE/open_score/eval/report.py)、[logging.py](../Open-SCORE/open_score/utils/logging.py) | 训练步与 checkpoint 步分列；按明确 checkpoint/配置集合汇总；真实种子数、策略 RNG、确认集身份可追溯 |

未来研究验证采用直接对应改动的最小证据：掩码与计数语义、算法退化关系、同一序列的循环状态、明确目标与输出之间的通路。它们应随具体实现和已批准实验安排确定，本方案不据此创建额外测试项目、性能探测或文件哈希体系。

## 10. 投稿定位与候选期刊

### 10.1 可以写成什么论文

若主线成功，一个合适的暂定题目是：**“数量与任务负载保真的实体分解用于多智能体协作的跨规模泛化”**。若只有 HAD 证据，题目进一步限定到固定规则对手的模拟任务。不要使用“首次”“通用最优”“任意规模”“强鲁棒”这类超出实验支持的词。

正文贡献建议保持三项：

1. **问题与现象：**在明确的数量、比例与目标数组合变化中，展示现有强实体方法的实际边界，并分清接口支持、任务难度与泛化能力。
2. **方法：**提出并精确定义数量/负载信息保留的结构随机分解，说明它与 REFIL、ALMA、CASEC、近期任务条件方法的区别，并给出真正能证明的结构性质。
3. **证据：**在同信息和明确预算下，通过多种子、简单计数对照、结构打乱、确认集合与第二任务，证明收益与该机制相关，报告失败配置与成本。

只有第一项和方法接入，没有第二、三项的可靠证据，当前更接近复现实验/工程分析；只有一个 seed 的漂亮图，也不能补齐这条证据链。

## 11. 建议的论文结构与当前结论

论文可按以下顺序展开：引言提出“数量变化并非仅是输入尺寸变化”；相关工作区分实体网络、随机分解、任务分层与结构泛化；问题定义明确观测、动作、奖励和三轴分布；方法给出 C/G 与训练目标；性质分析限定于置换、计数辨别和价值混合；实验展示同协议主表、OOD、消融、确认与成本；讨论说明固定对手、全实体感知、密度混杂和失败范围。

当前最合理的决策是：**先补齐当前 v3 正式结果，以 REFIL 为第一改进母体，优先验证“额外数量信息是否足够”和“结构分解是否还有独立贡献”。** ALMA 的正式结果决定是否转向分层路线；旧 S2 与真实模拟器搜索暂不重启。

达到预期投稿水平，需要的是一条完整证据链：真实缺口 → 明确机制 → 与最近文献的区别 → 公平多种子收益 → 必要消融与确认 → 适用边界。现有项目已走到“有可信候选母体和明确开发现象”的阶段，尚未走到“已证明新方法可投稿”的阶段。
