**探索阶段已终止。**停止确认时间为 **2026-09-08 16:00:19 +08:00**。调度器、3 个训练进程及 6 个采样子进程均已停止；原定剩余训练、评价和诊断取消。清理前探索 final 为 Git `cc2ab86`。本报告依据停机后的数据库整理，没有重新训练或评价。

## 研究问题与共同设置

在已知 reactive 对手、固定 `rule_group_v1` 底层上，分别检验目标人数分配、成员身份分配、同目标组划分与局部能力信息。主要关注完整任务的原生成功率，不以局部预测误差代替在线效果。

本轮改用独立 HAD Workbench：历史环境 Git `f4cb2cb98c9d9f4e3fa34e7029ba099c97416459`，CORE_VERSION 为 `had-workbench-1.0.0`，物理协议 `legacy-snapshot-order-boundary-fix-v1`。该环境含边界修复，与 v5 不同；不同版本的胜率不直接归因为算法差异。

每局最多 50 物理步，每 5 步及非终止伤亡事件重新决策；无四人上限、后备配额或强制部署。任一目标毁坏为失败；消灭 Blue 或守住时限的成功及同时终止条件优先级遵循原生引擎。历史 v6 包装保留零 Red 后的逐次真实事件，此包装已随研究代码退出当前接口。

## 六条方法的具体实现

| 方法 | 目标分配与组划分 | 求解／学习方式 |
|---|---|---|
| BLOTTO_Count（G1） | 枚举各目标及后备人数，距离解码身份，每目标一个大组 | 冻结局部 S2 成功概率取 log 后跨目标求和 |
| BLOTTO_Group（G2） | 与 G1 相同目标归属，再改变目标内分区 | 固定归属后评分 64 个不同完整分区，使用相同 S2 代理 |
| ALMA_Alloc（R1） | 自回归选择每个成员的目标或后备，每目标一个大组 | proposal 生成候选，长期动作 Q 选择，replay TD 与当前赢家轨迹 NLL 学习 |
| MAPPO_Intent（R2） | 成员共享策略，同时选择目标／后备，读取旧意图 | 集中价值学习与 PPO 更新；没有原论文的 A* 路径通信 |
| ALMA_Group（R3） | 自回归联合选择目标归属与队友分区 | 项目扩展的 AQL 联合动作评价 |
| ALMA_S2（R4） | 同 R3，并向全局 Q 提供冻结局部 S2 能力 | 项目扩展；S2 不随 RL 更新，只读取成功概率 |

共有 128 维、4 头、两层实体编码。AQL 每次生成 32 候选，每批抽 64 事件，每新增 16 事件更新 Q/proposal，RMSprop 学习率 0.0005，回放最多 5,000 完整回合。MAPPO 使用共享 actor 与集中 critic，候选／动作合法性沿用研究协议；完整优化参数在配置快照中。

六方法在线选动作均不访问真实模拟器反复试选；真实终局分支仅用于 S2 离线标签及原计划有限诊断。G2−G1、R3−R1、R4−R3 分别是拟检验的分区、联合学习和 S2 机制比较；这些完整比较没有完成。

### 输入、动作与更新的实现落点

本节依据 Git `cc2ab86:Open-SCORE/src/open_score/research_v6/learning.py` 与 `local_value.py` 还原已经实现的计算流程；已实现不等于已完成训练或正式评价。具体超参数以 [原配置](../Open-SCORE/outputs/v6/config.json) 为准。

- **状态表示与动作合法性。** `EntityEncoder` 读取公开的实体位置、速度、生命、时间、旧目标和组关系；目标是可变长集合，不为固定目标数建立独立输出头。每名存活 Red 只能归属一个有效目标或后备，同目标成员再组成分区。内部自回归 token 不推进物理时间，完整编组构造完后一次提交给环境。
- **ALMA 三臂。** `PointerProposal` 按成员逐一指向目标或后备；R3/R4 额外选择加入同目标已建组或新建组。`GroupQ` 将候选内的成员、接触 Blue、目标、组及后备关系编码为 token，汇聚后输出一个团队 Q。`AQLLearner._update` 从回放中取历史动作，以原生奖励加潜势差作为事件奖励；后继候选由在线网络选优，再由目标网络给出 bootstrap 值，终局不 bootstrap。proposal 的监督教师是本次 Q 更新前、当前状态候选中的赢家，损失为完整赢家序列 NLL 加熵正则并按存活人数归一化；不是把所有成功轨迹直接做行为克隆。
- **MAPPO。** `IntentActor` 对所有成员同时根据相同旧意图做目标／后备分类，选完后每目标合成大组。`MAPPOLearner.learn` 收齐同一 actor 版本的 10 个完整回合，构造 5 个事件的累计奖励加目标 critic 的 bootstrap，不使用 GAE。每批更新 4 epoch，按成员概率比做 0.2 裁剪；所有成员共享团队优势，critic 则对团队事件做 MSE。每 200 批硬更新目标 critic；评价仍按分类分布采样，因此“固定模型”不意味着每个事件都取 argmax。
- **冻结 S2 的接入。** R4 把每个候选目标的局部成功概率拼到该目标 128 维向量后，经 `129→128` 层送入全局 Q；S2 不向 proposal 输入，也不接收 RL 梯度。G1 使用人数非负分拆枚举（含后备）和匈牙利距离分配解码成员，跨目标相加 `log p`；G2 在 G1 归属上按合并、几何二分、移动与交换展开分区。它们使用代理评分，不具备局部独立性或全局最优保证。

潜势塑形在实际事件上计算 `r' = r_native + 0.5 × (Φ_next − Φ_current)`，`Φ` 是相对开局总生命的 Blue 生命损耗比例，真终局取零。因 gamma=1，完整回合中间的潜势差抵消；非终止采集块边界不清零。这解释训练中可能出现正塑形奖励而原生成功仍为零，不能据正塑形数量宣布任务训练成功。

## S2：从 binary_v1 到 joint_v2

### 旧二分类版本

binary_v1 只有 600 母回合族、1,706 状态。第一种子训练 40 epoch，验证选优 epoch 27；测试 343 状态、仅 36 非平局状态，Brier 0.0710、ECE 0.0315、非平局排序 55.83%、平局率 95.87%。很小的非平局支持不能证明可靠选组。

依赖旧模型的 ALMA_S2 已在 **8,919 物理步**后终止；其完整恢复点仍为 **0 步**，不能声称保存了这 8,919 步的优化器和 replay。旧数据、权重及指标按 `binary_v1` 字段／文件名保留，不与新修订拼接。

### 新联合模型的方法与实际数据

joint_v2 保留局部物理状态、完整候选组关系与成员身份映射，联合预测原生结局和剩余 0～50 物理步（2×51 类）。按候选目标归属选择局部 Red，按共同公开威胁归属选择 Blue；使用真实单目标物理投影，先执行候选至下一个真实指挥事件，随后采用大组续行到原生终局。跨目标物理耦合不在局部世界中，输出不能直接当作无误差的全局胜率。

共享采样配额为单目标 6,000＋多目标 6,000 母回合族；规则、大组、合法随机控制器自然采样，不过滤失败或平局。每族最多 3 状态、每状态最多 8 不同候选；候选间固定局部成员、改变分区，每候选一条配对终局续行，把预算用于增加独立局面。按母回合族拆为 train/validation/test=7,200/2,400/2,400。

实际已采满 **12,000 族、34,114 状态、171,425 候选**；包含 3,985 非平局状态、24,312 全零状态、5,817 全一状态。母回合执行 **289,163 物理步**，标签续行 **2,680,279 模拟物理步**；采集记录耗时 4,414.625 秒。三个初始化共用这份数据，不计成三份独立样本。

训练使用联合 NLL，按族、状态、候选等权，完整状态候选一起入批，每批 8 状态；AdamW 学习率 3e-4、权重衰减 1e-5，各 40 epoch。没有成功重加权或排序损失，以验证成功 Brier 选模；时间输出只做联合监督，G1/G2 评分与 R4 输入仍仅使用边缘成功概率。

实现上，`local_value.py::GroupLocalS2` 先编码局部实体，再对每个候选组池化其 Red、所负责 Blue 和目标表示，拼入成员数、Blue 数及组中心等 5 个统计量，经 `3×128+5→128` 层形成组 token。全局、目标及组 token 经两层关系注意力并掩码平均，最后输出 102 个 logits。类别索引为 `y×51+t`，表示原生结局 `y∈{0,1}` 与剩余物理步 `t∈{0,…,50}` 的联合事件。

网络对超过当前剩余时限的时间类置为不可选；非终局不能选择 0 步，已经原生终止的状态只能选择 0 步。训练对实际 `(y,t)` 做联合负对数似然；部署时对所有成功时间类求和得到 `p_success = Σ_t P(y=1,t)`，不是减去时间惩罚，也不是分别估计多个小组成功率后直接相乘。旧组特征在局部输入中统一为大组，当前候选分区通过显式组关系进入网络，避免把旧编组误当作当前待评分方案。

## 结论、取消项与证据位置

下面的只读查询可在两份正式评价库分别还原本文 A–E 的成功分子和分母；用 `family` 跨方法对应共同开局，用 JSON `checkpoint_physical_steps` 查询真实训练步数。本次核对共 2,000 局：FrozenRule 73 胜、MAPPO 64 胜；这些是含辅助 E 的数量，主场景结论仍按 A–D 单独统计。

```sql
SELECT method, checkpoint, json_extract(value, '$.scenario_id') AS scenario,
       COUNT(*) AS episodes, SUM(json_extract(value, '$.success_native')) AS wins
FROM episodes
WHERE split = 'test'
GROUP BY method, checkpoint, scenario;
```
