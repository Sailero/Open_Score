## Stage3：未知上层策略的统一协议

### 如何判断是否有效

- 方案一：轨迹推断＋短期验证：知情差距门槛 未通过；知情差距置信区间门槛 未通过；两种底层各自差距门槛 未通过；相对两基线至少 +5 pp 通过；校正后显著改善 未通过；各规模 P95 ≤3 秒 通过。
- 方案二：轨迹推断＋二次调整：知情差距门槛 通过；知情差距置信区间门槛 通过；两种底层各自差距门槛 通过；相对两基线至少 +5 pp 通过；校正后显著改善 通过；各规模 P95 ≤3 秒 通过。

这是一轮集中验证，不替代多训练种子和外部最先进算法对照。旧方法使用公开的快速求解预算，不是把旧协议的历史胜率直接放进新表。知情参照与对应方案共用实现、候选规则和预算；预算在计算边界检查，超时率与退回代理方案的比例保存在 JSON 中，不声称硬实时保证。
环境在决策计算时等待，胜率尚未计入观测过期造成的损失。未达到门槛时保留负结果，不把局部误差、候选覆盖和未来价值估计统称为训练不足。
