# main0928：无 count 的 Looped 战役

本目录是 `remote_train` 分支上的唯一正式实验输出。机器可读矩阵见同目录 `experiment.json`（首次 `start` 写入）。**没有试训、没有 A-B-C 闸门、没有 IAR。**

## 主方法

- 代码键：`regir_sg`（论文名 **Looped**）
- 协议：未锚定共享参数循环 + `global_query_detach_memory` + **`skip_count_inject=True`**
- 唯一 +count 变体：`regir_count_sg`（只在 HAD 上，不进 SMAC）

消融与模块对应：−宿主 = NoREFIL；−实体交互 = R0；−多轮 = R1；−记忆 = NoMem；−跨轮加权 = Last；−随机深度 = Fixed4；锚定替换 = ARR；解绑参数 = Untied4。

## 矩阵（全部 3 种子）

**HAD 新训（10 × 3 = 30）**

- P0：Looped、NoREFIL、R0、R1、NoMem
- P1：Last、Fixed4、ARR、Untied4、+count

**HAD 导入（不重训）**：main0921 的 7 个外部基线（REFIL / REFIL-matched / QMIX-Atten / DCG / SPECTra / ALMA / TransfQMix）× 3 种子的 `final.pt` 与终评/锚点切片，打包在 `imported/`。`prepare` 展开后 inventory 为 complete，且不进入训练队列。

**SMACv2 新训（8 × 3 = 24）**：P0 Looped / REFIL / SPECTra / TransfQMix / 1-round；P1 QMIX-Atten / ARR / Untied4。无历史终评可复用。无 SC2 的机器上这些任务保持 pending。

**机制**：训练出 `final.pt` 后自动入队。HAD 终评 24×300、协同 dup、执行深度（Looped / ARR / Fixed4 / Untied4，10/30/50v K2，R=1–6）、读出干预（Looped）、探针 coverage / dynamics / deep_rounds / global_probe（Looped、R0、R1、ARR、Untied4、REFIL）、M4 成本。SMAC 终评 + Looped 执行深度（10/15/20v × R=1,2,6）。

## 多机

所有机器挂同一 `outputs/main0928`。每台先配环境（默认复用名为 `sarc` 的 conda 环境），再 `start`。逐步命令、变量和排错见 [远程操作说明.md](远程操作说明.md)。

```bash
conda activate sarc          # 已有相近环境时
bash scripts/setup_farm.sh
bash Open-SCORE/outputs/main0928/run_all.sh start
```

GPU 由本机 `nvidia-smi -L` 发现。任务通过 `cluster/claims/{task_id}/` 的 `mkdir` 占坑；心跳 `cluster/workers/{host}.json` 每 15s；120s 无心跳则释放，别的机器从该目录 `resume.pt` 续训。`status` 在任意一台都能看共享 inventory 与集群块。

命令：`start | stop | stop all | resume | status | report | bundle | retry`。无 `select` / `decide`。`stop` 只停本机（写 `cluster/stop.{host}.request`）；`stop all` 才写共享 `stop.request`。进程在完整 batch 后存 `resume.pt` 并释放 claim。

## 报告与下载

训练中每约 1–5 分钟会根据已写入的 CSV **重写** `实验报告.md` 和 `figures/`（缺格显示 —，不插值）。任意时刻也可手动：

```bash
bash Open-SCORE/outputs/main0928/run_all.sh status    # 实时进度面板
bash Open-SCORE/outputs/main0928/run_all.sh report    # 立刻刷新报告
bash Open-SCORE/outputs/main0928/run_all.sh bundle    # 立刻打 zip（训练中也可以，内容是当前快照）
```

全部任务 complete 后流水线自动再出一次报告，并写两个 zip（不含 `resume.pt` / 控制台 / `cluster/`）：

- `main0928_analysis.zip`：报告、图、CSV、JSON、探针、各 run 的 `config.json`
- `main0928_results.zip`：上面全部 + 各 run 的 `final.pt`

本机下载：

```bash
scp USER@HOST:/path/to/Open_Score/Open-SCORE/outputs/main0928/main0928_analysis.zip .
scp USER@HOST:/path/to/Open_Score/Open-SCORE/outputs/main0928/main0928_results.zip .
```
