# 研究结论与阅读路线

> **一句话：我们学习可跨人数复用、对策略差异敏感的小规模单目标攻防能力，再用可校准的局部博弈模型驱动双方滚动分组，从而检验其能否在伤亡、增援、未知对手和未见总规模下提高最坏全局胜率。**

![Open-SCORE总体方法图](figures/01_open_score_overall.svg)

## 1. 本轮最终修正

| 用户关切 | 最终决定 | 直接原因 | 当前动作 |
|---|---|---|---|
| SMAClite 是否可用 | 作为第二环境，建立独立 SMAClite-AD | 高效、易改，但原版只有单边控制和 SMAC 动作 | stock 锚点与 AD 扩展均已跑通 |
| S1 动作语义 | 27 个纯加速度量化向量 | QMIX 需要离散动作，不能塞入“朝敌人”规则 | 已改代码 |
| 网络是否过重 | DeepSets + 64 维 GRU + 小 mixer | 1–4 对 1–4 不需要 Transformer | 已缩小配置 |
| 是否用 PSRO | 代码保留，当前 S1/S2 轮次推迟 | 对手过拟合是真问题，但 BR 训练显著增加预算 | 不作为本轮验收门槛 |
| S1 场景 | 单目标随机、训练六个严格红>蓝规模 | HAD 攻击单位开火即自毁，平衡/劣势配置会混淆语义 | 三算法训练闭环已运行 |
| S2 是否需要 ALMA/Set Transformer | 不需要；采用规范化输入的小 MLP ensemble | 局部最多 4v4，预测任务明确 | 已改代码 |
| S2 是否需要对手/策略条件 | 需要记录局部策略对或行为上下文 | 否则同人数下的克制关系会被平均掉 | 数据契约与真实 HAD pilot 已实现 |
| S3 应建模为什么 | 受限开放人口随机分配博弈 | LP 只是单状态阶段求解器，长期性来自转移与未来价值 | 已修正文档，代码仍为 $L=1$ 骨架 |
| S3 组合爆炸怎么处理 | 人数分配 + 个体匹配 + 双边列生成 | 完整候选数及双方笛卡尔积才是主成本 | 待实现 oracle/gap |
| 未知对手如何进入决策 | 在线上下文/信念决定 ambiguity set，开集时回退全 maximin | 不能把“对手未知”仅当测试标签 | 待实现 |
| S4 到底做什么 | 先做宏观价值残差，再有条件地追加 S1 最佳响应 | 结果对齐不等于全链路反传 | 已有残差骨架，outer loop 未实现 |

## 2. 四阶段最直观的输入输出

```text
S1  Local Game Executor
输入：HAD 的六个严格红>蓝小规模，或独立 SMAClite-AD 配比
输出：规则策略和共享动态规模 QMIX/VDN/MAPPO checkpoint；PSRO 为后续项

S2  Strategy-Conditioned Local Game Model
输入：某个目标附近的规范化状态 + 给定敌我子群 + 策略对/行为上下文
输出：防守胜率、短窗失守率、预计剩余步数及经审计的不确定性上界

S3  Restricted Stochastic Grouping Commander
输入：全局态势、对手信念、双方受限候选、逐目标 S2 输出和可选未来价值
输出：分组混合策略、最坏响应、列生成 gap、实际分组及诊断矩阵

S4  Outcome-Aligned Co-Adaptation
输入：完整系统轨迹和最终整局胜负
输出：优先修正宏观价值；通过门控后才新增 S1 PSRO 策略并刷新 S2
```

## 3. 价值判断

这项工作的价值不在“第一次使用 QMIX、PSRO、MLP、层次决策、双方联盟或 Blotto”。相关单点和相近组合都已有工作。可信价值在一个更严格的可检验假设：**策略条件化的小规模单目标能力能否作为可复用原语，被可校准的局部博弈模型量化，再由受限动态双方分组博弈组合成对未见总规模和未知对手更稳健的全局策略。**

它不保证优于端到端 MARL。预期优势只应放在以下四点：

1. 局部 1–4 对 1–4 的策略对经验可以跨总人数和目标数复用；
2. S2/S3 给出可审计的胜率、时长、校准上界、最坏响应和候选 gap；
3. 对手上下文直接改变稳健集合，而不是只输出一个不可操作的类型标签；
4. 人口变化后可即时重建候选并求解，不必等待整网重新训练。

若同分布固定规模上端到端方法更强，这是合理结果；论文必须证明 Open-SCORE 在未见规模、未见对手或人口事件后的最坏表现更好，才能成立。

## 4. 当前开发目标

本轮锁定 S1 与 S2：

- HAD 每局一个随机目标，只注册 `2v1、3v1、3v2、4v1、4v2、4v3`；
- 用规则策略以及共享 QMIX/VDN/MAPPO 检验固定规模和动态规模，严格区分管线、学习信号与收敛；
- 在未经修改的 SMAClite stock 场景运行官方 ePyMARL 三算法，再在独立 SMAClite-AD 协议做同一组小预算训练；
- 用真实前向推演数据完成 S2 数据、监督学习、校准和直观评估器；
- PSRO、S3 与 S4 本轮冻结，不让额外博弈训练掩盖 S1/S2 的基础问题。

当前 S2 工程可使用规则 rollout 先验收；在接入后续智能 checkpoint 前，不能把它的 pilot 指标写成完整系统证据。
