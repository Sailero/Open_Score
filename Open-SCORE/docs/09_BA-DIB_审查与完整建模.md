版本：2026-09-05。本文保留原计划的漏洞审查与工程修订记录。面向读者的当前方法以 [07：MVP 完整方法](07_MVP完整方法_S1-S3.md) 为准，执行设置、基线定义与结果解释以 [08：MVP 实验协议](08_S3实验执行与分析协议.md) 为准。本文提及的扩展信息阶梯、代理排序和 reserve 消融属于备选诊断；本轮默认关闭，不表示已经执行或通过。当前实现效果尚待完整评估，唯一综合结果报告为 `outputs/stage123_unknown_upper_v1/experiment_report.md`。

## 1. 审查结论

论文主问题收敛为：**底层固定、上层意图未知时，信念驱动的长期身份分组能否接近知情 oracle？** Stage1/2 冻结为共同实验条件；动态规模是上层动作可行域随伤亡变化的条件，不另立通用伸缩系统创新。论文贡献和最近工作差异见 [论文框架](../paper/论文框架.md)。不以打通三阶段通路替代上层方法创新。

原方向能回应“已知 Blue 底层控制、未知 Blue 上层、动态规模、长期分组”的需求，但原计划不能直接作为严谨实验协议。以下问题需要实质修订。

| 问题 | 代码/理论依据 | 本轮修订 |
|---|---|---|
| 原 Blue 没有持续隐藏类型 | `evaluate_stage3_identity._run_episode` 每次求均衡并 `sample_profile` | 整局固定上层程序，程序根据公开状态和历史产生宏动作 |
| 当前动作泄漏 | `HADStage3Adapter.global_state/agent_states/snapshot` 含分配、环境 RNG | 不向规划器传 adapter/snapshot；只传不可变 PublicState；从公开字段重建分支环境 |
| 只推断类型不足 | 一个类型可随机产生多个当前动作；持续执行的旧动作仍未知 | 维护类型/潜码与当前宏动作的联合粒子权重，逐物理步更新 |
| 将推断与下一动作预测混淆 | 同时决策的新动作含有尚未公开的随机性，已知程序也未必达到 80% 预测准确率 | 当前分配的轨迹滤波 F1 与下一动作预测 F1 分列；事后计算同状态已知程序的预测上限 |
| “类型→人数→动作”不嵌套 | 类型与人数可能各自提供另一种没有的信息 | 比较“无信息→类型→类型+人数→完整动作”；人数单独列支路 |
| 无 channel 接口缺少显式拦截选择 | `(target, red_ids)` 只决定保护目标和成员 | 增加基于公开 Blue 身份的 interception intent；由中立匹配器解析冲突 |
| 局部风险被当作任务真值 | S2 在单目标、在轨状态上训练，不能刻画共享射击/碰撞/巡逻 | 冻结 S2 只筛候选；实际 HAD 分支重排序，并检验重分组反事实排序 |
| `log(1-q+epsilon)` 在 q=0 给正奖励 | 可能奖励多分组；分组不是独立任务 | 使用目标级 `log(max(1-q_t,epsilon))`，明确条件独立仅是代理假设 |
| 短期窗口仍被称为长期 | 两层五步最多看十步，可能完全看不到稍晚突破 | PUCT 到叶节点后续演至全局终局/50 步；终局胜负为规划回报 |
| 伤亡事件与固定五步时钟不一致 | 12 步发生伤亡，下一固定重规划为 15，不是 17 | 搜索遇公开伤亡提前停；否则到下一个绝对五步时钟；S2 五步风险仅是该短窗口的上包络 |
| 置信度低不等于新策略 | 潜码可重叠、闭集类型可能不可辨识 | 本轮只做整局固定类型，关闭 novelty bucket 和相应混合 |
| “共用 seed”不等于相同动作或未来 | Red 造成状态/伤亡/事件变化，Blue 也随状态改变 | 配对初始场景与独立随机流；Blue 流按物理时刻索引，不依赖 Red 方法名 |
| 小规模完整证书不能推广 | 无 channel 匹配引入跨组耦合，旧可加 MILP 分解不再直接成立 | 新方法在完整合法宏动作候选矩阵上求解/搜索；小博弈枚举仅验证小域 |
| 预计空间和时间不是已验证资源保证 | QOM 新轨迹与 2,400 局原始记录会继续增长 | 报告实际磁盘/墙钟时间；清理后的历史证据容量不等于未来总量 |

旧 identity 的配对胜率差为 −13.3 pp，95% CI [−28.3,1.7] pp；SALDAE 相对 MILP 为 +6.7 pp，CI [−10.0,23.3] pp。两者都不支持“已显著解决未知上层策略”。原始记录与负结果保留。

## 2. 完整问题定义

### 2.1 状态、时钟与信息

一局初始固定目标集合 J，数量为 2、4、5；Red/Blue 初始身份集合分别为 R_0、B_0。在时刻 t，R_t、B_t 是由死亡动态收缩的存活身份集合。目标身份和位置固定；任一目标被击破即 Blue 全局获胜，Blue 全灭或 50 步仍无目标被击破则 Red 获胜。伤亡后结束的局部组不意味着删除目标。

物理状态 x_t 包括身份、位置、速度、血量、固定目标与已知底层规则 ell∈{rush,split_rush}。所有运动和血量在本轮设为公开。历史 H_e 包括截止事件 e 的这些公开观测和 Red 已执行的动作；不包括 Blue 的目标标签、组标签、策略名称、随机种子或环境未来 RNG。

Blue 上层策略类型 theta 在整局固定，本轮只运行四种闭集策略，不运行 feint_switch 或局中类型切换。固定规则可以依据公开位置、伤亡重新计算分组，因此“类型固定”不等于“所有身份与目标绑定整局”。未知量是本局的固定类型及其当前随机行动；不再增加阶段切换或私有策略记忆的推断问题。

事件 t_e 包括绝对时刻 0,5,10,… 和公开伤亡时刻；局部 roster 改变重置相应 Stage1 控制器。当前实现不使用包含隐藏目标分配的 `battlefield_resolved` 事件来触发未知上层规划，避免通过事件标签泄漏。物理接触变化仍随轨迹与伤亡体现；若未来加入纯接触事件，必须只由公开几何关系定义并同步修改训练/分支协议。

### 2.2 身份动作与显式拦截意图

Blue 动作为若干 `(目标, Blue身份集合)`，每组 1–4 人，每个存活 Blue 身份恰好出现一次，无 reserve。

Red 动作为：

```text
IdentityUpperAction(
    groups=[(protected_target_id, red_member_ids), ...],
    reserve_ids=[...],
    intercepts=[(red_member_ids, intended_public_blue_ids), ...]
)
```

Red 每个存活身份恰好进入一个 1–4 人活跃组或 reserve。每个 interception intent 引用一个自身活跃组和至多四个公开 Blue 身份；同一 Blue 身份不能被多个意图重复占用。意图不是“已知 Blue 真实组”：它是 Red 基于观测/信念指定的拦截偏好，可以猜错。未提交意图的组使用中立默认匹配。旧基线保留无意图动作。

双方同时提交后，中立匹配器先按保护/攻击目标分开，再按意图与 Blue 标准组的身份重合数量、到达时间差、质心距离、身份序确定性匹配。每个实体只被执行一次；未匹配组产生 0vB 或 Rv0，不存在虚拟 channel 占位资源。当前匹配是确定性贪心规则，不宣称全局最优运输匹配。

对 rush，Blue 同目标身份先按 ETA/身份排序，稳定切为至多四人标准组；更改无运动意义的输入分组边界不会改变匹配或效用。对 split_rush，保留确实影响侧向航线的原始组边界。Blue 的航线分组只由自身动作确定，不随 Red 匹配结果改变。

reserve 采用公开威胁巡逻，参与真实共享世界交战；诊断另跑惯性执行（inert）对照。代理不为 reserve 发明一个可加的独立收益。

### 2.3 信念与同时决策

核心决策时序是：

1. 读取截止当前事件的公开历史；消费此前窗口新增观测。
2. 将后验传播到本次 Blue 宏动作的预测分布。
3. Red 只依据该预测分布决定动作；Blue 独立根据自身固定程序采样动作。
4. 同时提交、匹配、执行；真实 Blue 标签只进入评估器的事后日志。

若省略可由历史确定的记忆，预测分布为

\[
p(a_e^B\mid H_e)=\sum_\theta b_e(\theta)\,\pi_\theta^B(a_e^B\mid x_e,H_e,\ell).
\]

已执行 Red 动作必须进入观测生成条件。完整类型更新应为

\[
b_{e+1}(\theta)\propto b_e(\theta)
\sum_{a_e^B}\pi_\theta^B(a_e^B\mid x_e,H_e,\ell)
\,p(o^B_{t_e+1:t_{e+1}}\mid x_e,a_e^R,a_e^B,\ell).
\]

当前实现将候选 `(theta,a_e^B)` 作为窗口内持续的粒子，逐物理步积累似然；窗口结束时边缘化为类型后验，下个事件再生成动作粒子。不得逐步重新采样同一窗口的隐藏目标，再把重叠历史重复计入后验。

有限类型模型枚举人工策略的动作支持；QOM 用潜码和每码四个动作粒子近似。运动似然利用已知 27 个加速度原语、限速与公开速度增量；以协方差 N·sigma² 的高斯误差做保守建模，N 是可观测存活 Blue 数、sigma=8。过滤可省略与假设无关的密度归一化项；输出的运动惊异是省略同一公共常数后的 NLL，不能当作跨不同观测模型可直接比较的绝对密度。

这一观测模型和少量粒子都是近似；不保证后验真实校准或类型收敛。相同公开轨迹的类型应保持不可区分，目标动作预测准确度比强行识别策略名称更直接。

### 2.4 真正优化的长期目标

定义终局回报 Z∈{−1,+1}，任务目标是

\[
\max_{\pi^R}\;\mathbb E[Z\mid H_0,\pi^R,\theta\sim b_0].
\]

在事件状态 `(x_e,b_e,H_e)` 上，这是带未知对手策略的 Bayes-adaptive 最佳响应问题。形式上的事件 Bellman 递推需对 Blue 动作、物理转移和未来观测积分，并用更新后的信念继续决策；不能令 Red 在树里直接看到抽样 theta 后选择响应。事件时长可变，应按实际物理步推进，终局判定保持一致。

Blotto 的作用是身份资源分配、联盟划分与双方受限动作对抗结构；本轮在线阶段不是对完整动作空间计算 Nash 均衡，也没有新的全局均衡定理。零和矩阵仅是当前候选域的局部辅助问题。

### 2.5 Stage2 的准确用途

冻结联合接口返回 `[batch,2,10]`，Red/Blue 两类，每个 bin 五个剩余物理步。原温度与胜负边际风格校准保留：校准后按 outcome 缩放条件时间分布，保证与原 `predict_red_win` 边际一致，不重新训练。

在完整五步窗口内，局部代理风险取 Blue 的第一时间 bin：

\[
q_g^5=P_{S2}(Y=Blue,T\le5\mid x_e,C_R,C_B,\ell).
\]

若距下一事件不足五步，不进行无根据的 bin 内线性插值；五步概率仅作为保守筛选值。对 0vB，用当前位置、Blue 速度上界 300 与攻击半径 500 判断窗口可达性，作为保守风险包络，不称为精确击破概率。按照目标聚合局部风险，再计算

\[
\widetilde q_j=1-\prod_{g\in j}(1-q_g),\qquad
\widetilde U=\sum_{j\in J}\log\max(1-\widetilde q_j,\epsilon).
\]

条件独立、单目标价值迁移、0vB 可达包络均可能失准。它们不替代真实全局终局目标。代理先生成/筛出最多八个共同候选；四次五步分支保持候选宏动作，伤亡后只裁剪 roster 并重置控制器，使用公开目标健康/Blue 剩余量做短期重排序。MCTS 另按真实事件重规划，叶节点以公开威胁策略续演到剩余回合终局。

## 3. 四条可检验路线

| 路线 | 对手模型 | 动作选择 | 能验证什么 |
|---|---|---|---|
| ER-IDB | 无在线类型识别，受限候选 Blue 对抗分布 | 事件风险矩阵的 minimax 支持，经物理分支重排序 | 修正效用、匹配和共享物理能否改善旧方法 |
| FT-BBR | 四个显式程序的动作支持与公开运动 Bayesian 过滤 | 后验响应＋四次五步分支 | 简单可解释的策略库推断是否已足够 |
| QOM-BBR | 动态实体编码＋GRU＋8×32 VQ 潜码 | 潜码/动作后验响应＋同样短期分支 | 学习表征相对人工策略库的贡献 |
| QOM-MCP（BA-DIB 工作主方法） | 同 QOM 信念 | 32 次 PUCT、两层真实宏事件、终局续演 | 在部分信息下规划未来反应与任务结果的贡献 |

QOM 的轨迹编码器在离线训练可读取完整公开训练轨迹；在线解码器仅消费公开前缀。隐藏目标/同组标签只用于训练损失或事后指标，不进入编码器输入。实体与目标使用可变长度掩码，不使用数字 ID 或固定槽位的可学习 embedding。解码出的目标概率和同组概率，经唯一身份、至多四人约束转成合法宏动作。

这些是适配实现，并非原论文 QOM/OMIS/POTMMCP 的逐行复现。本轮没有另行训练 QOM 原文的完整 Red 元策略库；候选动作矩阵和公开 rollout 策略承担其部分作用。VQ codebook 可能塌缩、编码可能更关注场景而非上层程序，必须保留 code usage 和 held-out 指标。

搜索每条完整模拟只抽一次类型/潜码；树节点由 Red 自身动作与公开观测历史形成，不包含真实/抽样类型标签。连续观测采用明确的几何离散化，实际过滤仍使用观测到的速度；有限搜索和观测抽象不继承无限预算收敛证书。

本轮关闭 novelty bucket、开放集阈值校准及相应 ER 混合，直接验证整局固定类型下的推断和规划。低分配置信度仍是 posterior 不确定性，不解释为对手已更换类型。

FT-MCP 已作为同预算消融接入。后续是否增加粒子处理、候选局部搜索或跨训练种子复验，由正式结果定位的瓶颈决定；不可看到本轮测试结果后悄悄改主方法再复用同一 test 结论。

## 5. 统一实验与验收

### 5.1 数据和对照

冻结 Stage1/2，校验三个固定 SHA256；Stage2 保留 19,200 局、101,366 状态，不重训。QOM 轨迹为 4 上层 × 2 底层 × 3 规模 × 2 Red 探测策略 × 50 局 = 2,400 条，按唯一 episode seed 分为 1,680/360/360 条训练/验证/测试。三个集合和正式评估 seed 不相交；本轮没有开放集阈值选择。

Blue 程序为均衡分配、优势目标集中、70/30 双线、受限身份 Blotto 均衡，每局固定其中一种。最近目标程序保留预注册的小概率次选目标分支；“known_upper”知道该随机程序，不知道当前随机样本。strategic_equilibrium 使用公共状态候选博弈，不读取真实 Red 当前动作。

正式核心网格：3 规模 × 2 底层 × 4 整局固定上层 × 8 Red 方法 × 10 局 = **1,920 局**。每个单元的十个 episode seed 跨方法共同使用，共 240 个独立配对 episode。加下述消融，正式物理评估总量为 2,400 局。

八个方法为 balanced_identity、legacy_idb、event_risk_idb、finite_type_bbr、qom_bbr、qom_mcp、known_upper_mcp、revealed_blue_action_br。legacy_idb 用旧 channel 求解器输出，再经共同匹配执行，所以同协议重跑与保留的历史原始结果分别解释。SALDAE 是旧求解器消融，不冒充未知上层推断方法。

为论文机制归因，另注册 **finite_type_mcp、prior_mcp 各 240 局，共 480 局**。FT-MCP 将四类型 posterior 接入同一 MCP；Prior-MCP 在真实决策前恢复均匀类型先验，保留当前物理状态和搜索中的观测更新。它们与 QOM-MCP/known-upper 共用候选、32 次 PUCT、事件深度和终局续演，分离学习表征、历史信念积累、长期搜索的作用。QOM-MCP 仍是预注册主方法。

主要 oracle 为 known_upper_mcp；它和 QOM-MCP 使用同一候选生成函数、8 候选、4 次重排序、32 次 PUCT、两层事件与同一终局 rollout。不同信息可产生不同搜索路径，但预算上限一致。不能声称八个结构不同的方法具有相同计算量：简单基线按实际成本计时。revealed_blue_action_br 只提供“本次动作可见”的短期信息参照；它不知道所有未来动作，也不是长期真实胜率的理论上界。

### 5.2 自动诊断

正式开始前只运行必要的公开接口/身份约束检查和一次小域枚举；每个正式动作继续校验身份、目标与规模。扩展中间诊断（额外物理分支、信息阶梯、代理排序、候选扩张、reserve 消融及独立计时）默认关闭，避免延迟正式运行。规划时间从真实注册实验逐事件记录，失败后按具体问题再定点分析。

正确性失败阻止正式实验；推断/排序/耗时差是负结果，不被伪装为程序成功或自动删除。预先的少量计时样本不用于声称稳定 P95；正式逐事件记录才用于耗时分布。分支种子与正式未来随机流独立；HAD 有大量确定性转移，四次相同结果不等于获得四个独立信息样本。

### 5.3 指标、归因和结论

Stage1 报告训练、局部胜率和泛化；Stage2 必须保留 Brier/ECE/时间误差，不能被“四类正文指标”规则删掉。Stage3 正文集中于胜率、oracle gap、推断和规划时间，其他诊断进入 JSON/CSV。

效果门槛：第二事件起当前分配的身份目标 micro-F1≥0.80；主方法相对 known_upper 的胜率差≥−10 pp，配对 95% CI 下界≥−20 pp；相对 legacy 和 ER 点估计至少 +5 pp。身份/固定目标检查全通过，1,920 核心与 480 消融全完成且无不可行执行。本轮没有 open-set AUROC 验收。micro-F1 在单目标类别预测中等于身份准确率。

这里 ≥0.80 对应**第二个命令起，消费公开物理转移后，对正在执行的分配进行滤波**。决策前预测本次新抽样命令另报 forecast-F1；它有不可约随机性，不能套用同一硬阈值。评估器在 Red 动作提交之后用真实上层程序的分布计算同状态 oracle 预测准确率上限，绝不将该程序或上限传回 Red 决策器。QOM 当前分配滤波使用完整的 `(code, action)` 粒子权重，不能只更新 code 后丢掉同一 code 内的行动证据。

此外，rush/split_rush 各自的 oracle 点估计差都不能低于 −10 pp，正文分别报告。QOM 360 条独立测试轨迹在模型固定后运行同一在线滤波器，记录当前目标 micro-F1、下一动作预测和同组 pair-F1；测试标签仅用于事后评分。

本轮结论仅针对四种整局固定的上层类型，不声称处理局中策略切换或任意库外策略。

胜率差在场景/底层/上层内按 episode seed 分层配对 bootstrap。两个主要优越性比较加 Holm 校正；只有配对 CI 排除 0 且校正检验通过，才声称显著改善。240 对不保证检出 +5 pp；扩大样本需预先注册后续独立 seeds。

失败分别检查：公开推断错误、共同候选遗漏、S2 新分组排序失准、短期/长期规划差异；诊断关联不证明唯一因果机制。尤其“接近弱 oracle”可能是双方同受八候选限制，而非问题解决。单 QOM 训练 seed 也不足以衡量训练方差。

## 7. 面向 oracle 差距的可证明边界

以下是用于检查逻辑的有限域基本性质，不作为新的博弈收敛定理。

**公开观测等价并不要求类型可辨。** 在给定公开历史及 Red 干预下，若两个类型对未来公开转移和任务收益诱导相同分布，则对当前决策它们等价；posterior 无须集中在唯一名称。反之，初始观测相同但要求相反防守的两个等概率类型，若只能保护一个目标且错误决策即失败，则未知方最优胜率为 1/2、已知类型方为 1。增加神经网络训练量不能消除这种信息缺失。因此本项目的接近性目标是注册分布上的经验目标，不是逐场景保证。

**有限候选决策误差分解。** 固定事件、公开历史、一个不额外使用隐藏信息的后续策略类，令 Q(a)∈[0,1] 是真实期望终局成功率，A 为合法动作域，C⊆A 为候选域；估值满足 sup_C |Q−Qhat|≤ε，搜索输出满足 max_C Qhat−Qhat(ahat)≤η。则

\[
\max_{a\in A}Q(a)-Q(\hat a)
\leq \underbrace{\max_A Q-\max_C Q}_{\Delta_{candidate}}+2\epsilon+\eta.
\]

证明只需在 max_C Q−Q(ahat) 中加减对应的两个估计值，用两次 ε 及一次 η 上界。如果对手行动/轨迹分布 p 与 phat 的总变差不超过 δ，且条件收益在 [0,1]，固定动作的期望误差不超过 δ；在额外的物理估值误差 ε_value 下，可取 ε≤δ+ε_value。这里 δ 必须针对影响价值的联合未来分布，不能用单身份目标 F1 简单替换。

这一不等式解释为什么高分类准确率、接近共同小候选 oracle、短期代理高 AUC 都不足以保证终局优势。它不是整个 BA-DIB 的已认证误差界：全域候选损失、联合未来分布误差和有限 PUCT 搜索误差目前都没有可计算的全局证书。若改与全程知道类型的 oracle 比较，还必须另外计入未知信息造成的最优策略差距，不能将其全部记为算法训练误差。

当前优化顺序是：公开信息正确性 → 共同状态下的身份分组候选覆盖和真实物理排序 → FT/QOM 在相同规划器下的差距 → 多步搜索对终局胜率的增益。只有验证证据支持时，才增大模型或扩大搜索预算；不通过削弱 oracle 来满足接近性目标。
