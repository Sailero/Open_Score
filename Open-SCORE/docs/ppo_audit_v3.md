# PPO、动作空间与训练预算审计

审计对象：`grouping/policy.py`、`grouping/training.py`、根目录 v2 研究方案，以及本轮六个 100,000 环境步任务的实际日志。以下区分已确认事实与改进假设；本报告不把正确执行代码等同于方法成功。

## 已确认的实现与训练事实

- 原策略联合 log probability 是所有被学习的选人、STOP 和重建条件概率之和；evaluate_action 按记录的前缀重放合法掩码。独立随机处理顺序没有学习型概率因子，符合 v2 方案，不应通过除以序列长度冒充标准 PPO 概率比。
- 原模型每个 PPO minibatch 的 16 个样本逐一执行 `evaluate_action`，最后堆叠损失；没有批量 attention。每轮 rollout 只有 64 个上层事件，默认更新两轮、熵系数 0、target KL 0.05、Adam 学习率 3e-4。初始 128 维、2 层、4 头来自方案的实现起点，方案明确称其为未验证的启动值；batch 16 和 rollout 64 不是已经验证的最优配置。
- 原任务奖励只有终局成功 1，其余都是 0。环境 50 步期限是真正终止，gamma=1，SMDP GAE 使用实际 delta；PPO Actor/Critic 都是上层，冻结下层只做前向推理。
- 六个模型各累计训练 15.2～26.2 分钟；三个主算法分别约 20.2、25.8、25.9 分钟，约 3.37～3.60 万上层事件、528～564 次更新。相比底层三小时训练，本轮确实没有进行同等时长的充分优化；不同网络/环境的小时数不能直接等价为有效样本量。
- 主算法三个种子约 3,900～4,050 局训练，只分别出现 206、91、172 个成功回合。更详细的 update 无成功比例、KL、entropy、样本量见 `old_training_metrics.json`。旧 v2 的训练和评估都使用随机采样策略，训练期间策略持续变化，且训练/测试种子分布不同，二者成功率不能直接混为同一个估计。新 v3 的评估才统一采用 greedy 解码。
- 20260905 主算法前 50 次更新平均联合 entropy 7.98，最后 50 次只有 0.508；rule 20260906 和 20260907 分别降至 0.000115、0.000556。20260907 主算法相反从 9.87 升至 18.01，说明不能笼统认定所有种子都探索塌缩。
- 主算法平均 clip fraction 为 17.6%～18.8%。20260906 和 20260907 分别有 75/528、103/547 次更新的平均 KL 超过 0.05。这是优化波动的直接证据；由于记录的是多个 minibatch 的均值，不能还原每次早停的确切轮数。
- 主算法 20260906 训练前后半成功回合数 59→32，20260907 为 100→72；20260905 为 94→112。仅最后两个数字不能证明全面收敛或长期趋势，但不存在三个种子一致改善的证据。

## 能够支持的解释

本轮失败不能归因于“PPO不适合强化学习”或“49万参数必定不够”。更贴近证据的组合解释是：终局稀疏信号、小 rollout、无显式熵鼓励、初始自由组合空间很大，且联合自回归动作概率对多个条件概率的改变敏感。在训练成功率约 2%～5% 时，每个仅包含约 7 个完整回合的 rollout 经常没有任何真实成功奖励，Actor 仍会根据不准确的价值估计产生更新。后备队与大量单人组提供了容易重复的极端行为。本轮日志和轨迹支持这些现象存在，但尚未用受控消融证明每项的独立因果贡献。

原 v2 方案第 5.5 节和启动参数部分已警告联合动作长度、KL、裁剪和熵聚合问题；工程实现的可运行性不足以验证研究假设。更长训练值得提供，但若动作域和执行器输入支持范围有问题，单纯从 10 万加到百万也可能延长退化。

## 三条过夜路线的合理性与边界

共同使用公开状态生成的候选池，含真实旧组保持、局部修复、空间紧凑 2～4 人组、威胁或均衡分配、小比例后备，以及已实测的 `compact_action`。后者精确复现“先 Hungarian 均衡目标分配，再每目标空间聚 4 人”的纯规则，保留每个目标尾部可能出现的单人组，避免修改已经测过的规则后继续引用旧结果。初始状态的“全后备”仅是未分配占位，不加入候选；后续真正已执行的旧组仍保留，以免隐藏退化。候选池最多 24 个，每个事件只选择一个候选，直接消除原解码长度导致的联合比率问题。它研究的是**受限候选空间中的动态分组**，不能宣称已经解决原方案任意自由编组。候选池优劣本身需要纯规则对照检验。

1. 候选 PPO：从头学习，较大 rollout 和真实批量更新，并保留非零熵系数。rollout 512～1024、minibatch 128～256、4 次 epoch、学习率 1e-4～3e-4、熵系数 0.01 向 0.003 退火，可以作为待验证起点。不能声称论文已证明这些数字适合本任务。
2. 教师初始化后 PPO：用相同物理快照、相同 RNG 的候选短程续行给排序/BC 标签，再由 PPO 学长期回报。教师的短程代理可能偏置策略，不能当真实最优 Q；标签全相同时不能任意选择第一个当唯一正解，宜跳过或保留软均匀标签；采样要包含学习策略访问的状态，降低仅模仿规则状态产生的分布偏移。教师成本计入同一 8 小时预算。
3. 候选 Double DQN：相同网络评分视作 Q，在线网络选下一动作、目标网络估值，使用 replay、target updates 和 epsilon 探索，提供不同于 on-policy PPO 的样本复用路径。Replay 必须保存完整 DecisionState（包括下层 memory 64、last action 27、previous grouping、时间）及当时/下一状态候选，不能只保存候选编号并假设它永远代表同一编组。终止目标没有 bootstrap，gamma=1；clip 梯度并监控 Q 值幅度，避免 max 估值漂移。

三条路线同时训练扩大了工程尝试多样性，但不是三个随机种子的统计鲁棒性证据。每条一个种子适合今晚筛选可行性，获胜路线仍需要后续多种子复验。

## 潜势奖励的约束

采用 `r' = r + gamma**delta * Phi(next_state) - Phi(state)`，其中 Phi 是固定、有限的公开状态函数，所有真正终止（包括 50 步期限）强制下一潜势为 0。则有限完整轨迹的 shaped return 只比原回报差起始潜势，与之后动作无关；gamma=1 时仍保留相同初始分布下的最终成功率目标。训练 rollout 截断只是 bootstrap 边界，不能强制终止潜势为 0。不能在训练中随意改变潜势权重/归一化而继续声称严格等价。潜势不保证有限样本优化更好；不合适的代理和 critic 近似仍可能减慢学习。

## 批量网络与 GPU 实测

新增 CandidateNetwork 为隐藏维度 256、3 层、8 头、**2,269,442 个参数**。实体 memory、last actions、此前组关系进入 padding attention；候选成员与目标 embedding 按身份映射后做批量 gather/组编码，ID 数值不作为学习特征。候选组向量的均值/最大值、后备成员汇总与全局 context 决定分数。规模可变不等于任意大规模效果已经验证。

单进程、CPU 1 线程、16v16、22 候选的一次短微测试：完整 batch 128 forward/backward/Adam 平均 CPU 1.272 秒、CUDA 0.322 秒；batch 32 为 0.381/0.088 秒。单状态带 autograd forward 为 CPU 5.86ms、CUDA 6.28ms。这支持 GPU 用于新批量训练；不证明三个进程并发时端到端速度相同。实际采样时间还包括候选生成和冻结下层推理，最终需要端到端吞吐测量。

候选生成经过共享距离矩阵优化，单 CPU 20 次均值：8v8 3.04ms、16v16 5.32ms、32v32 10.79ms、64v64 21.78ms；原 16v16 为 16.6ms。这次候选微测速发生在额外加入 `compact_action` 之前；最终端到端预算应采用最终代码的训练测速。`compact_action` 与原诊断脚本在 4/8/12/16/24/32 规模、18 个真实开局完全一致。

`tests/test_overnight_policy.py` 的 13 项测试涵盖实体/候选换序、身份重命名不变、batch 与 single 输出及梯度一致、mask、memory/action 输入敏感性、成员划分敏感性、1～64 人合法 forward、初始至少部署 87.5% 成员和规则尾部单人组。`tests/test_overnight_learning.py` 的 6 项测试包含手算交错环境 GAE、真终止切断 bootstrap、50 步及提前终止潜势望远镜求和、在线网络与目标网络 argmax 不一致时的 Double DQN 目标、真实候选 PPO 更新 attention 参数并保持 padding 合法。合计 19 项通过；它们证明接口/梯度/目标性质，不证明训练后胜率。

## 原始资料

- [PPO 原文，Schulman 等 2017](https://arxiv.org/abs/1707.06347)：PPO 通过采样、裁剪概率比和多轮随机梯度优化更新策略，不限定必须采用大网络或某种硬件。
- [MAPPO 原始研究，Yu 等 2022](https://arxiv.org/html/2103.01955v4) 第 5.3、5.5 节：batch 大小和样本复用对结果有明显影响，过小和过大都可能不好；其合作多智能体实验不等于本任务的中央上层策略。其 [官方实现](https://github.com/marlbenchmark/on-policy) 同样要求核对 rollout、episode length、epoch、minibatch 和 clip，不能只复制学习率。
- [Ng、Harada、Russell 1999 潜势塑形原文](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)：潜势差形式是奖励塑形保持策略目标的基础；本项目有限时域及宏观 delta 的边界处理如上。
- [Double DQN 原文，van Hasselt 等](https://arxiv.org/abs/1509.06461)：将动作选择和估值分离以减轻最大化导致的过估计，不保证候选池包含优秀动作。
- [DAgger 原文，Ross 等](https://arxiv.org/abs/1011.0686)：顺序决策中的模仿分布偏移应被重视；这里仅借鉴风险分析，短程教师初始化并非 DAgger 的完整复现。
