# v2.0 方法实现与实验口径

本文件描述已知固定对手下的动态分组实现。研究假设与文献依据见 [研究方案](../../固定对手下动态分组研究方案_v2.md)。B0–B6 对应实现已经建立；实验是否支持选择性重构的优势，必须由真实运行结果决定。

## 1. 环境与动作

实验在同一个 HAD 物理环境中运行。两个任务点整局固定，一局最多 50 个物理步。红方下层 REFIL-QMIX 和蓝方完整规则冻结。上层动作包含若干 `Group(target, members)` 与后备成员集合 `reserve`；组没有语义化数字标签，成员身份只负责跟踪，不作为可学习的能力编号。

每个存活红方身份恰好属于一个活动组或后备队，活动组包含 1–4 名成员，目标必须有效。同一目标允许多组；局部观测与执行器输入随真实组关系变化。所有成员仍在同一世界中运动、交火和受损，红方动作不强制指定哪个蓝方与哪个红组交战。后备执行统一的物理规则。

决策状态包含位置、速度、健康、剩余时间、上一编组，以及按红方真实身份维护的循环下层记忆和上一底层动作。死亡成员从编组和记忆中移除，重命名组或重新构造标签不会触发额外记忆清空。

已知对手为三个固定规则之一：`reactive` 根据公开红方物理覆盖和蓝方行程给目标分配概率；`concentrated` 集中最近目标；`balanced` 均分成员。三者下层均为 `rush`。红蓝从同一个决策前状态生成上层命令，再共同提交；不能读取对方本轮尚未公开的选择。

## 2. 宏观转移与训练目标

上层命令持续到下一个绝对 5 步周期、非终止减员事件或任务结束。事件在完成一个物理步后检查，同一步多名成员阵亡合并处理，因此每次宏观转移的 `delta` 至少为 1。网络内部选择和修复步骤不推进物理时间。

任一关键目标失守为失败；消灭全部蓝方或守住 50 步时限为成功。成功终局奖励 1，其余奖励 0，默认 `gamma=1`。原生时限属于真实任务结束，禁止继续 bootstrap；仅训练采样批次在非终局状态结束时使用下一状态价值。GAE 的 lambda 按宏观事件计算，折扣使用 `gamma ** delta`。

训练预算主要记录真实物理交互步数，同时报告上层事件、释放/解码量和墙钟时间。不同策略引发的减员次数可以不同，不能仅靠更新次数宣称数据预算相同。

## 3. 选择、重建与 PPO

策略共享实体与组关系编码、合法重建头和全局状态价值。默认两层注意力、128 隐藏维度、四个注意力头；这些是实现起点，不是经实验选出的最优参数。

首个决策强制处理所有成员，处理顺序采用与参数无关的随机排列。后续 B4 依次从尚未选过的存活成员与 STOP 中采样，得到释放序列。STOP 可以立即结束，也允许释放全部成员。修复时在工作副本中移除这些成员，再按记录的顺序选择加入未满组、新建带目标的组或进入后备队。工作副本不提交环境；最后只提交完整合法动作。

未释放成员的任务和组关系保持不变。释放成员可能回到原组，因此释放数量与实际变化量分别统计。实际队友关系变化忽略任意组标签，后备成员不视为一个共同作战组。

采样保存全部随机选择及所需前缀。训练对同一轨迹重算联合 log-prob，所有可学习选择的概率相加；初始强制释放和外生随机顺序不计入可学习概率。不按释放人数除以联合 log-prob。PPO 直接执行生成动作，主算法不增加候选重排序；优势和固定价值目标对应一次宏观动作。条件熵沿采样轨迹相加，不称为完整自回归动作分布的精确熵。

## 4. 统一比较方法

| 方法 | 决策与训练 | 解释范围 |
| --- | --- | --- |
| B0 `static` | 首次均衡分配并按容量成组，以后仅删除死亡成员 | 衡量主动调整的必要性；补充同初始化配对诊断 |
| B1 `dlom` | 合法候选池，已知蓝方分布下局部代理期望最高者 | 局部代理搜索，不代表真实长期最优 |
| B2 `full` | 每次释放全部成员，其他网络、critic、PPO 与 B4 一致 | 必须读取原编组，用于隔离选择机制 |
| B3 `random` | 按冻结的释放人数分布均匀选人，共用学习修复头 | 正式比较从训练数据匹配人数分布 |
| B4 `selective` | 学习释放对象、STOP 和合法修复，联合 PPO | 待验证的主方法 |
| B5 `alma` | proposal、动作 Q 选择、重放 TD 与当前赢家轨迹 NLL | ALMA 风格接口适配，不是严格复现 |
| B6 `rule` | 按受损组/邻近关系释放，共用学习修复头 | 检查学习选择是否优于普通局部调整 |

B1 仅在评分中为同目标红蓝局部组做几何匹配，再用冻结 DLOM 给局部存活分数；没有对应红组时使用明确的保守可达性代理。局部存活 log 分数聚合后，按已知蓝方动作概率求期望，选择候选最高分。该匹配不写回环境，也不屏蔽物理交互。候选池含原编组、均衡配置、同任务不同成员划分、集中及后备变体，始终执行完整合法性验证。

B5 的 Q 读取当前实体、原编组、下层记忆及候选动作组关系。默认生成 8 个候选并选择 Q 最大的动作。TD 使用在线 Q 选择下一状态候选、目标 Q 评价所选动作，终局样本不 bootstrap。训练 proposal 时，在 replay 保存的状态重新抽取当前候选，以当前在线 Q 选赢家，对其构造轨迹训练联合 NLL；不直接复制历史赢家。默认累计至少 16 个新宏观转移且 replay 足够后才更新，目标网络缓慢跟随在线 Q。候选筛选改变实际行为分布，因此 B5 使用独立训练流程，禁止套用 proposal 概率作为 PPO 行为概率。动作生成随机性统一服从每回合的 Torch 随机种子。

## 5. 资产支持与证据边界

冻结下层为已有 REFIL-QMIX checkpoint，训练种子 20260831。DLOM 为 `DynamicHADOutcomeNet`，10 个时间箱、每箱 5 步，并携带冻结温度与底层风格校准。文件及完整 SHA-256 见 [资产清单](../assets/frozen/manifest.json)。运行前后核对模型哈希。

DLOM 数据由 19,200 个局部回合、101,366 条状态记录组成，直接覆盖 1–4 红方对 1–4 蓝方，使用当前存活组的局部续行标签。它不是重新编组反事实数据，也不是全局长期动作价值。因此只供 B1 参考，不作为主策略的真实奖励或评测环境。B4 反馈来自共享物理世界。

冻结下层使用变长实体输入，但接口可接受更多蓝方不等于在所有接触规模都有足够能力。先用执行诊断定位动作是否生效、接触情况和任务难度，再判断上层学习效果。

## 6. 诊断、评估与恢复

优先完成三个诊断：E1 固定状态及任务归属、只改变同目标成员划分，检查真实执行影响；E2 共同候选池使用固定续行策略，分开候选覆盖与代理排序误差；E3 在相同信息、修复能力和评估预算下比较完整、规则、随机和学习释放。筛选与最终评价使用独立续行随机批次，不能将池内最佳称为整个动态任务的全局最优。

主指标是最终成功率，补充批量为 1 的在线决策时间中位数/P95、释放比例、任务变化、队友关系变化和约束违规率。受控失效诊断与自然减员分别报告。不同方法共享测试初始状态与外生随机种子，允许动作引发轨迹分叉。评估时间耗尽时，只比较已完成的配对单元，并给出实际完成数。

`smoke`、`briefing`、`minimal` 用于开发和有限验证；首轮采用单种子、最多 2,000 个物理步及 5 分钟训练预算，获得可检查结果后依据吞吐和学习趋势追加。`formal` 为单独协议：五个独立训练种子，每核心测试配置先 200 个评估回合；预算冻结后再启动，不能将开发回合当作正式多种子结果。统计区间需要保留训练种子层级。

首次训练前保存初始化快照，完成更新后保存最近 checkpoint；训练与回合日志持续写出。恢复要求代码、配置及冻结资产一致，恢复模型、优化器、随机状态和计数，从新回合开始，未完成 rollout 丢弃。B5 还恢复 Q 目标网络和 replay。恢复可追加预算，但不是中断处逐物理步完全续接。

若训练中断，优先加载最近完成更新的模型做独立评估，再生成已有证据的报告。报告必须区分未训练快照、已更新模型、完成评估回合与未完成任务。没有提升或样本不足时保留对应结论，不能用损失下降替代任务成功率证据。

运行命令与恢复例子见 [项目 README](../README.md)。
