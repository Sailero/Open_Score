# 论文主线：未知对手意图下的信念驱动长期身份分组

研究目标为一篇以**上层对抗分组决策**为核心的期刊论文。Stage1 局部控制器和 Stage2 局部代理固定，作为实验条件和实现工具；不把三阶段工程整合写成三项方法创新。当前为方法与实验设计稿，正式效果尚待注册实验完成。

建议英文题目：**Belief-Aware Long-Horizon Coalition Allocation against Unknown Opponent Strategies**。方法沿用 BA-DIB；题目和摘要以核心决策问题为先，Blotto 是建模工具。

## 1. 一个研究问题

当对手的底层运动规律已知、上层意图隐藏时，如何从公开运动历史形成对未来上层行动的预测，并将这种不确定性转化为有利于整局防守的身份分组？在相同局部控制器和规划预算下，能否接近知道对手上层程序的 oracle？

这里的“动态规模”是伤亡引起的存活身份集合与可行分组变化，不另做一个通用多智能体伸缩框架；“长期”是优化终局任务成功，不仅优化下五步存活。新增实验不研究未知底层控制，也不新增 Stage1 训练算法。

尤其区分“用轨迹识别正在执行的意图”与“预测下一次随机上层行动”。前者用于推断 F1 验收；后者与同状态下已知程序的可达预测上限比较。二者都服务于最终胜率，不能因下一动作含不可预测的随机性就误称推断算法失败。

## 2. 研究差异与贡献边界

不能宣称上层对抗/联盟形成尚无人研究。[K-serial coalition](https://arxiv.org/abs/2305.15729) 已研究大规模机器人动态捕获与资源防御的联盟优化；[动态联盟学习](https://arxiv.org/abs/2412.20397) 已结合 MAPPO、意图共享与任务修订；[SCoBA](https://arxiv.org/abs/2005.13109) 已研究不确定性下的层次任务分配及 oracle 对比。因此“有分组、有动态规模、有层次结构”不单独构成新颖性。

[QOM](https://proceedings.neurips.cc/paper_files/paper/2025/hash/24f10950306c98815e70ff2e41a9c5d1-Abstract-Conference.html) 和 [POTMMCP](https://arxiv.org/abs/2306.06067) 已提供潜在对手策略与在线信念规划依据；本项目不能把 VQ、Bayesian posterior、PUCT 各自重新命名后当作原创算法。

基于目前核查，本文应论证的具体差异是：**隐藏、持续的对手上层程序 + 不可交换的物理身份 + 组规模/身份唯一约束 + 对终局价值敏感的在线重分组**。检索差异不等于全领域首创证明。正文只保留下列两项相连的方法贡献，以及一项实验分析：

1. 将意图不确定性表示为未来身份目标/同组行动的分布，在公开历史下进行持续更新；通过显式拦截意图和确定性物理匹配接入身份动作，保证模型中的动作差异具有执行含义。
2. 在可行分组候选上进行信念条件化的长期响应：冻结 Stage2 筛选、共享物理环境校正、公开历史树上的事件搜索与终局续演。重点验证“如何使用信念做决策”，不以策略名称分类准确率代替决策质量。
3. 使用信息受控、预算受控的 oracle 对比和机制消融，定位何时可接近知情策略、何时受不可辨识性或候选覆盖限制。实验协议与负结果是支撑证据，不替代方法贡献。

完整变量、滤波公式、动作约束与实现对应见 [建模文档](../docs/09_BA-DIB_审查与完整建模.md)。这是适配性的研究方案；若同预算消融显示只有现成 MCTS 起作用，不能把工程组合包装成独立的新推断方法。

## 3. 方法选择围绕效果，而非堆叠模块

| 路线 | 要检验的作用 | 论文角色 |
|---|---|---|
| ER-IDB | 没有持续意图推断时，修正事件风险的收益 | 强无信念参照 |
| FT-BBR / FT-MCP | 候选程序库上的显式 Bayesian 推断；短期与长期响应 | 可解释的强参照、分离搜索贡献 |
| QOM-BBR / QOM-MCP | 不直接查询程序名称，用公开轨迹学到的行动表征响应 | BA-DIB 学习版本及预注册主方法 |
| Prior-MCP | 每次真实事件恢复均匀类型先验，保留当前物理状态和同一搜索器 | 分离历史信念积累的作用 |
| Known-upper MCP | 真类型已知，当前随机动作隐藏 | 核心 oracle |
| Revealed-action BR | 当前完整动作可见 | 单独的信息参照 |

若 FT-MCP 接近 oracle 而 QOM-MCP 没有达到，说明本问题的建模/规划可能成立，学习表征尚未成功；必须保留这一结论。正式测试不可用于挑选主方法或超参数。需要改方法时，改动与选择只用训练/验证集，并将后续独立测试登记为新版本。

## 4. 论文实验应回答的三个问题

**RQ1：能否在未知上层条件下接近知情 oracle？** 固定 30/40/50 人与 rush/split_rush，4 个整局不切换的隐藏上层类型，原八方法每单元 10 个共同种子，完整 1,920 局。报告总体、两个底层分别的胜率与配对 oracle gap；不能仅报告总体平均。知情和未知 MCP 共用候选生成、8 候选、4 次物理重排、32 次 PUCT、2 层事件与终局续演。

**RQ2：接近 oracle 的收益来自哪里？** 新增 FT-MCP、Prior-MCP 各 240 局，共 480 局，直接配对原核心实验。FT-MCP 对 Prior-MCP 检验信念积累；QOM-MCP 对 FT-MCP 检验学习表征；QOM-MCP 对 QOM-BBR、FT-MCP 对 FT-BBR 检验长期搜索。预注册 QOM-MCP 优越性检验仍仅针对 legacy/ER，其他机制对比报告差值及区间，避免挑选有利结果。

**RQ3：什么条件下失败？** 将难例沿公开推断误差、候选遗漏、局部代理排序和长期规划四条路径检查。rush 的无意义分组变化必须不改变结果；split_rush 的真实编队变化则保留。本轮先运行正式结果，扩展中间诊断默认关闭；共同八候选可能造成弱 oracle，若实际结果提示该问题再定点诊断。本轮不包含 feint_switch、类型切换或开放集泛化结论。

关键主图宜为：同协议胜率/配对 oracle gap；随观测推进的身份目标预测与决策差距；30/40/50 人规划时间与可行性。Stage1 的训练过程和 Stage2 大量指标放实验设置或附录，统一报告仍保留全部三阶段证据。

## 5. 什么结果足以支撑论文结论

正确性要求零身份覆盖/规模/信息泄漏错误。效果目标保持 QOM-MCP − known_upper 胜率差不低于 −10 pp，配对 95% CI 下界不低于 −20 pp，并额外要求 rush/split_rush 各自的点估计差不低于 −10 pp。对 legacy/ER 的点估计提升至少 5 pp；只有配对区间和预注册校正检验支持时才声称统计显著。

“点估计接近 10 pp”不等于通过 10 pp 非劣检验；若宣称非劣于 10 pp，必须让相应单侧置信下界也超过 −10 pp。当前 240 对不保证检出 5 pp 的效应。发表前还需根据初轮验证决定是否预注册更多独立种子、至少三个 QOM 训练种子与更强候选域 oracle；这些尚未完成，不能写成已有结果。

当前工作完成的判据是获得可复核、能解释机制的上层决策证据；若学习方法未胜过显式 Bayesian 参照，论文应相应收缩贡献，继续优化真正的瓶颈。

## 6. 暂不扩展的范围

本轮冻结 Stage1/2；不做 PSRO 全策略库扩张、未知底层识别、端到端同时重训三阶段或全指数动作空间 Nash 求解。已有唯一入口完成共同验证，避免维护多个互不相容的实验通路。Stage4 的优先级低于完成上述论文证据。
